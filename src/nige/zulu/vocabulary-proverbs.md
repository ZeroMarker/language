# 祖鲁语谚语与习语

祖鲁语谚语（izaga）在南非文化中非常重要，用于传递智慧和道德教诲。

## 常用谚语

| 祖鲁语 | 直译 | 含义 |
|--------|------|------|
| Indlela ibuzwa kwabaphambili. | 路向走在前面的人问。 | 不耻下问。 |
| Umuntu ngumuntu ngabantu. | 一个人通过他人成为人。 | 人在社会中成长。 |
| Ikhanda linyela wonke umuntu. | 头对每个人都重要。 | 每个人都有自己的想法。 |
| Akukho sikhathi esingcono kunanamhlanje. | 没有比今天更好的时间。 | 把握当下。 |
| Isalakutshelwa sibona ngomopho. | 不听劝告的人通过血来学习。 | 不听老人言，吃亏在眼前。 |
| Ukhuni lunye alwashi. | 一根柴烧不起来。 | 团结就是力量。 |
| Inyoni izozala eqanda. | 鸟会下蛋。 | 事情会自然发生。 |
| Kuhle ukufunda emakhanda abanye. | 从别人的头上学是好的。 | 借鉴他人经验。 |
| Igazi liyathethelela. | 血会原谅。 | 血浓于水。 |
| Akukho gqiza elingapheliyo. | 没有不结束的舞蹈。 | 天下没有不散的筵席。 |

## 常用习语

| 祖鲁语 | 直译 | 含义 |
|--------|------|------|
| Ukubeka phezulu | 放在上面 | 尊重 |
| Ukuphonsa itshe | 扔石头 | 批评 |
| Ukugibela ihhashi | 骑马 | 抓住机会 |
| Ukuvula umlomo | 打开嘴 | 说话 |
| Ukubamba iqhaza | 抓住部分 | 参与 |
| Ukushaya izandla | 拍手 | 鼓掌、庆祝 |
| Ukuphefumula | 呼吸 | 休息 |
| Ukudla ikhandlela | 吃蜡烛 | 浪费时间 |

## 文化意义

- 谚语在祖鲁文化中是智慧的传承方式，长辈常用谚语教导晚辈。
- 许多谚语与自然和动物相关，反映南非的自然环境。
- 学习谚语有助于理解祖鲁语的思维方式和文化价值观。
- 谚语在日常对话中频繁使用，是语言学习的重要部分。

## 学习建议

- 先理解谚语的字面意思，再理解其文化含义。
- 在适当场合使用谚语，可以增加语言的地道性。
- 注意谚语的发音和语调，有些谚语有特定的节奏。
