# 斯瓦希里语动词前缀系统

斯瓦希里语动词包含多个前缀，按固定顺序排列，构成完整的动词形态。

## 动词结构

```
主语前缀 + (时体标记) + (宾语中缀) + 词根 + (后缀)
```

## 主语前缀

| 人称 | 前缀 | 例句 |
|------|------|------|
| mimi（我） | ni- | Ninakula. |
| wewe（你） | u- | Unakula. |
| yeye（他/她） | a- | Anakula. |
| sisi（我们） | tu- | Tunakula. |
| ninyi（你们） | m- | Mnakula. |
| wao（他们） | wa- | Wanakula. |

## 宾语中缀

| 人称 | 前缀 | 例句 |
|------|------|------|
| mimi | -ni- | Ananipenda.（他喜欢我。） |
| wewe | -ku- | Ninakupenda.（我喜欢你。） |
| yeye | -m- | Ninampenda.（我喜欢他/她。） |
| sisi | -tu- | Anatupenda.（他喜欢我们。） |
| ninyi | -wa- | Ninawapenda.（我喜欢你们。） |
| wao | -wa- | Ninawapenda.（我喜欢他们。） |

## 方向中缀

| 方向 | 前缀 | 含义 | 例句 |
|------|------|------|------|
| -ni- | 向我 | 给我 | Ninipe（给我） |
| -ku- | 向你 | 给你 | Nakupa（我给你） |
| -m- | 向他/她 | 给他/她 | Nampa（我给他/她） |
| -tu- | 向我们 | 给我们 | Natupa（我给你们） |
| -wa- | 向他们 | 给他们 | Nawapa（我给他们） |

## 后缀

| 后缀 | 含义 | 例句 |
|------|------|------|
| -a | 一般现在 | Nasoma |
| -e | 目的/祈使 | Nisome（让我读） |
| -i | 被动 | Nasomiwa（被读） |
| -wa | 被动 | Naandikwa（被写） |

## 动词词根示例

| 词根 | 含义 | 现在时 | 过去时 | 将来时 |
|------|------|--------|--------|--------|
| -soma | 读 | Nasoma | Nitasoma | Nisome |
| -andika | 写 | Naandika | Niliandika | Nitaandika |
| -kula | 吃 | Nakula | Nilikula | Nitakula |
| -enda | 去 | Naenda | Nilienda | Nitaenda |
| -kuja | 来 | Nakuja | Nilikuja | Nitakuja |
| -ona | 看见 | Naona | Niliwona | Nitaona |
| -jua | 知道 | Najua | Nilijua | Nitajua |
| -penda | 喜欢 | Napenda | Nilipenda | Nitapenda |
