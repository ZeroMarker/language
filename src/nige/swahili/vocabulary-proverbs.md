# 斯瓦希里语谚语与习语

斯瓦希里语谚语（methali）在东非文化中非常重要，用于传递智慧和道德教诲。

## 常用谚语

| 斯瓦希里语 | 直译 | 含义 |
|-----------|------|------|
| Haraka haraka haina baraka. | 匆忙匆忙没有祝福。 | 欲速则不达。 |
| Asiyesikia la mkuu huvunjika guu. | 不听长辈话的人会摔断腿。 | 不听老人言，吃亏在眼前。 |
| Penye nia pana njia. | 有意愿的地方就有路。 | 有志者事竟成。 |
| Mtoto wa nyoka ni nyoka. | 蛇的孩子是蛇。 | 有其父必有其子。 |
| Mvumilivu hula mbivu. | 有耐心的人吃熟果。 | 耐心等待终有回报。 |
| Kila ndege huruka na mbawa zake. | 每只鸟用自己的翅膀飞。 | 自力更生。 |
| Maji yakimwagika hayazoleki. | 水泼出去收不回来。 | 覆水难收。 |
| Msema kweli ni mpenzi wa Mungu. | 说真话的人是上帝的朋友。 | 诚实为上。 |
| Hasira hasara. | 愤怒就是损失。 | 生气会带来损失。 |
| Akili ni mali. | 智慧就是财富。 | 知识就是力量。 |

## 常用习语

| 斯瓦希里语 | 直译 | 含义 |
|-----------|------|------|
| Kuvunja mtego | 打破陷阱 | 揭露阴谋 |
| Kuweka sawa | 放好 | 整理、解释清楚 |
| Kupanda mbegu | 播种 | 开始某事 |
| Kuvua samaki | 抓鱼 | 获得成功 |
| Kupasua kichwa | 劈开头 | 很难理解 |
| Kupoteza njia | 迷路 | 搞错方向 |
| Kupanda gari | 上车 | 乘车 |
| Kushuka gari | 下车 | 下车 |

## 文化意义

- 谚语在日常对话中频繁使用，尤其在长辈教导晚辈时。
- 许多谚语与自然和动物相关，反映东非的农耕和畜牧文化。
- 学习谚语有助于理解斯瓦希里语的思维方式和文化价值观。
