# 斯瓦希里语文化背景

## 东非文化简介

斯瓦希里语是东非最重要的通用语言，使用者分布在坦桑尼亚、肯尼亚、乌干达、刚果民主共和国等国。

### 地理分布

| 国家 | 斯瓦希里语地位 | 使用人口 |
|------|--------------|---------|
| 坦桑尼亚 | 官方语言 | 约 6000 万 |
| 肯尼亚 | 官方语言 | 约 5000 万 |
| 乌干达 | 官方语言 | 约 1000 万 |
| 刚果（金） | 官方语言 | 约 2500 万 |
| 莫桑比克 | 通用语 | 约 100 万 |
| 卢旺达 | 通用语 | 约 50 万 |

### 斯瓦希里语在非洲的地位

- **非洲联盟官方语言**：2004 年成为非洲联盟官方语言之一。
- **最广泛使用的非洲语言**：母语和第二语言使用者合计超过 1 亿。
- **唯一真正的非洲通用语**：跨越多个民族和国家。
- **联合国工作语言候选**：正在争取成为联合国官方语言。

## 文化特点

### 问候文化

- 问候在斯瓦希里文化中非常重要，不问候被视为不礼貌。
- 长辈问候需要更正式，使用敬语。
- 问候通常包括询问健康、家庭和工作。

### 饮食文化

- 主食：ugali（玉米糊）、wali（米饭）、nyama choma（烤肉）
- 饮品：chai（茶）是日常必备，kahawa（咖啡）也很流行
- 用餐习惯：右手取食，左手被认为不洁

### 音乐与艺术

- **Bongo Flava**：坦桑尼亚流行音乐
- **Taarab**：桑给巴尔传统音乐，融合阿拉伯和非洲风格
- **Muziki wa Dansi**：舞曲音乐

### 节日与传统

| 节日 | 时间 | 含义 |
|------|------|------|
| Eid al-Fitr | 斋月结束 | 开斋节 |
| Jamhuri Day（肯尼亚） | 12月12日 | 独立日 |
| Nane Nane（坦桑尼亚） | 8月8日 | 农民节 |
| Maulidi | 伊斯兰历 | 先知诞辰 |

## 学习建议

- 了解东非文化有助于理解斯瓦希里语的语境和用法。
- 斯瓦希里语深受阿拉伯语影响，许多词汇来自阿拉伯语。
- 学习时结合当地文化习俗，效果更好。
