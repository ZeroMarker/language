# 印度文化简介

## 概述

印度是世界四大文明古国之一，拥有超过5000年的历史。印度文化以其宗教多样性、哲学思想、艺术传统和丰富美食闻名于世。

## 宗教与哲学

### 主要宗教

| 宗教 | 信徒比例 | 特点 |
|------|----------|------|
| 印度教 | ~80% | 多神教，种姓制度，轮回观念 |
| 伊斯兰教 | ~14% | 一神教，逊尼派为主 |
| 基督教 | ~2.3% | 天主教、新教等 |
| 锡克教 | ~1.9% | 一神教，强调平等 |
| 佛教 | ~0.8% | 由印度传入亚洲各地 |
| 耆那教 | ~0.4% | 非暴力，苦行 |

### 重要哲学概念

| 概念 | 印地语 | 含义 |
|------|--------|------|
| 达摩 | धर्म | 法则、责任、正道 |
| 业 | कर्म | 因果报应 |
| 轮回 | पुनर्जन्म | 转世重生 |
| 解脱 | मोक्ष | 脱离轮回 |
| 非暴力 | अहिंसा | 不伤害任何生命 |

## 社会结构

### 种姓制度

传统上分为四个等级：

| 等级 | 印地语 | 职责 |
|------|--------|------|
| 婆罗门 | ब्राह्मण | 祭司、学者 |
| 刹帝利 | क्षत्रिय | 武士、统治者 |
| 吠舍 | वैश्य | 商人、农民 |
| 首陀罗 | शूद्र | 仆人、劳工 |

## 印地语与乌尔都语关系

### 共同起源

印地语和乌尔都语都源自**克里波利语**（खड़ी बोली），是同一语言的两种标准化形式。

### 主要区别

| 方面 | 印地语 | 乌尔都语 |
|------|--------|----------|
| 文字 | 天城文（देवनागरी） | 波斯-阿拉伯字母 |
| 词汇来源 | 梵语借词多 | 波斯语、阿拉伯语借词多 |
| 官方邦 | 北方邦、比哈尔邦等 | 无特定邦（全国通用） |
| 文学传统 | 梵语文学影响 | 波斯文学影响 |

### 词汇对比

| 中文 | 印地语 | 乌尔都语 |
|------|--------|----------|
| 学校 | विद्यालय | مدرسة (madrasa) |
| 书 | पुस्तक | کتاب (kitāb) |
| 水 | जल/पानी | پانی (pānī) |
| 爱 | प्रेम | محبت (muhabbat) |
| 你好 | नमस्ते | السلام علیکم (assalāmu alaikum) |

### 日常通用词

许多日常词汇两者通用：
- दोस्त/दोस्त (dost) — 朋友
- दुनिया/दुनिया (duniya) — 世界
- किताब/किताब (kitāb) — 书（通用）
- बाज़ार/बाज़ार (bāzār) — 市场
