# 印地语阅读练习

## 初级阅读

### 短文 1：自我介绍

> मेरा नाम राहुल है। मैं बीस साल का हूँ। मैं दिल्ली में रहता हूँ। मैं छात्र हूँ। मैं हिंदी और अंग्रेज़ी बोलता हूँ। मुझे पढ़ना बहुत पसंद है।

**生词表**

| 印地语 | 中文 |
|--------|------|
| मेरा नाम | 我的名字 |
| बीस साल का | 二十岁 |
| रहता हूँ | 住 |
| छात्र | 学生 |
| बोलता हूँ | 说 |
| पढ़ना | 读书 |
| पसंद है | 喜欢 |

**理解问题**
1. राहुल कितने साल का है?（拉胡尔多大？）
2. वह कहाँ रहता है?（他住在哪里？）
3. उसे क्या पसंद है?（他喜欢什么？）

## 阅读技巧

1. **先读标题**：了解文章主题
2. **找关键词**：名词和动词提供主要信息
3. **注意后置词**：को、में、पर、से 等帮助理解句意
4. **利用上下文**：通过前后文猜测生词含义
5. **识别动词时态**：词尾 -ता/-ती、-आ/-ई、-ऊँगा/-ऊँगी 提示时态
6. **注意性别一致**：动词和形容词的词尾与主语性别一致
