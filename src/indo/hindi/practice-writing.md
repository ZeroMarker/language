# 印地语写作练习指导

## 基础写作练习

### 练习 1：自我介绍

**任务**：用 5-8 句话介绍自己。

**模板**：
> मेरा नाम ___ है। मैं ___ साल का/की हूँ। मैं ___ में रहता/रहती हूँ। मैं छात्र/छात्रा हूँ। मुझे ___ पसंद है। मैं ___ बोलता/बोलती हूँ।

**参考词汇**：

| 中文 | 印地语 |
|------|--------|
| 学生 | छात्र/छात्रा |
| 教师 | शिक्षक/शिक्षिका |
| 工程师 | इंजीनियर |
| 医生 | डॉक्टर |
| 读书 | पढ़ना |
| 音乐 | संगीत |
| 运动 | खेल |
| 旅行 | यात्रा |

---

### 练习 2：描述日常生活

**任务**：描述你典型的一天。

**时间表达**：
- मैं ___ बजे उठता/उठती हूँ.（我___点起床。）
- मैं ___ बजे स्कूल/ऑफ़िस जाता/जाती हूँ.（我___点去上学/上班。）
- दोपहर को मैं ___ खाता/खाती हूँ.（中午我吃___。）
- शाम को मैं ___.（晚上我___。）
- मैं ___ बजे सोता/सोती हूँ.（我___点睡觉。）

**常用动词**：

| 印地语 | 中文 |
|--------|------|
| उठना | 起床 |
| जाना | 去 |
| खाना | 吃 |
| पीना | 喝 |
| पढ़ना | 读/学习 |
| सोना | 睡觉 |
| काम करना | 工作 |
| नहाना | 洗澡 |
| घूमना | 散步 |

---

### 练习 3：写信

**任务**：给朋友写一封简短信。

**模板**：
> प्रिय ___,
>
> कैसे/कैसी हो? मैं यहाँ ठीक हूँ। मैं तुम्हें बताना चाहता/चाहती हूँ कि ___। कल मैंने ___. यह बहुत अच्छा था/थी।
>
> अच्छा, फिर मिलेंगे।
>
> तुम्हारा/तुम्हारी,
> ___

**信件词汇**：

| 印地语 | 中文 |
|--------|------|
| प्रिय | 亲爱的 |
| कैसे हो? | 你好吗？（对男性） |
| कैसी हो? | 你好吗？（对女性） |
| बताना चाहता हूँ | 想告诉你（阳性） |
| बताना चाहती हूँ | 想告诉你（阴性） |
| अच्छा | 好的 |
| फिर मिलेंगे | 再见/下次见 |

## 中级写作练习

### 练习 4：描述图片

**任务**：看一张图片，用 10 句话描述。

**句型参考**：
- इस तस्वीर में मैं ___.（在这张图片中我看到___。）
- ___ है.（有___。）
- ___ कर रहा/रही है.（___正在做___。）
- ___ पहने हुए है.（___穿着___。）
- मुझे लगता है कि ___.（我认为___。）

---

### 练习 5：写日记

**任务**：每天用 5 句话写日记。

**日记开头**：
- आज ___ (日期) है.（今天是___。）
- आज का दिन ___ था.（今天是___的一天。）
- आज मैंने ___.（今天我___。）
- एक दिलचस्प बात यह हुई कि ___.（一件有趣的事是___。）

---

## 高级写作练习

### 练习 6：表达观点

**任务**：对一个话题表达你的看法（80-100字）。

**连接词**：

| 印地语 | 中文 |
|--------|------|
| सबसे पहले | 首先 |
| इसके अलावा | 此外 |
| लेकिन / परंतु | 但是 |
| इसके विपरीत | 相反 |
| अंत में | 最后 |
| कुल मिलाकर | 总之 |

---

### 练习 7：翻译练习

**任务**：将以下中文句子翻译成印地语。

1. 我叫拉胡尔，我来自中国。
2. 今天天气很好。
3. 我每天早上六点起床。
4. 她正在读一本很有趣的书。
5. 明天我们一起去市场吧。

**参考答案**：
1. मेरा नाम राहुल है, मैं चीन से हूँ।
2. आज मौसम बहुत अच्छा है।
3. मैं रोज़ सुबह छह बजे उठता हूँ।
4. वह एक दिलचस्प किताब पढ़ रही है।
5. कल हम सब बाज़ार चलेंगे।

## 写作检查清单

- [ ] 名词性别使用正确（阳性 -ा，阴性 -ी）
- [ ] 动词变位与主语一致（性、数、人称）
- [ ] 及物动词过去时与宾语一致
- [ ] 后置词使用正确（को、में、पर、से、से...तक）
- [ ] 所有格 का/की/के 与被修饰名词一致
- [ ] 敬语级别恰当（तू、तुम、आप）
- [ ] 标点符号使用正确
- [ ] 检查拼写
