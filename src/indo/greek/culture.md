# 希腊文化简介

## 概述

希腊是西方文明的摇篮，拥有超过3000年的历史。希腊文化对世界哲学、民主制度、戏剧、奥林匹克运动和科学产生了深远影响。

## 古希腊文明

### 重要贡献

| 领域 | 贡献 | 代表人物 |
|------|------|----------|
| 哲学 | 西方哲学奠基 | 苏格拉底、柏拉图、亚里士多德 |
| 民主 | 雅典民主制 | 克利斯提尼 |
| 戏剧 | 悲剧和喜剧 | 埃斯库罗斯、索福克勒斯、阿里斯托芬 |
| 史学 | 西方史学之父 | 希罗多德、修昔底德 |
| 科学 | 几何学、物理学 | 欧几里得、阿基米德 |
| 医学 | 医学誓言 | 希波克拉底 |
| 建筑 | 多立克、爱奥尼柱式 | 帕特农神庙 |
| 奥林匹克 | 古代奥运会 | 奥林匹亚 |

### 重要城邦

| 城邦 | 特点 |
|------|------|
| 雅典（Αθήνα） | 民主、哲学、文化中心 |
| 斯巴达（Σπάρτη） | 军事强国、纪律严明 |
| 科林斯（Κόρινθος） | 商业繁荣 |
| 底比斯（Θήβες） | 军事强国 |

## 现代希腊文化

### 节日与传统

| 节日 | 时间 | 活动 |
|------|------|------|
| 复活节（Πάσχα） | 春季 | 最重要的节日，烤羊肉、红鸡蛋 |
| 独立日 | 3月25日 | 纪念1821年独立战争 |
| 圣诞节（Χριστούγεννα） | 12月25日 | 家庭聚会、甜点 |
| 狂欢节（Απόκριε） | 大斋期前 | 化装舞会、游行 |
| 圣母升天节 | 8月15日 | 全国放假 |

### 饮食文化

| 食物 | 说明 |
|------|------|
| 穆萨卡（Μουσακάς） | 茄子、肉末、白酱千层饼 |
| 苏富拉基（Σουβλάκι） | 烤肉串 |
| 希腊沙拉（Χωριάτικη σαλάτα） | 番茄、黄瓜、橄榄、羊奶酪 |
| 菲洛面饼（Φύλλο） | 酥皮点心 |
| 乌佐酒（Ούζο） | 茴香烈酒 |
| 希腊咖啡（Ελληνικός καφές） | 浓郁的煮咖啡 |

### 社交礼仪

| 习俗 | 说明 |
|------|------|
| 贴面礼 | 朋友间亲吻两颊 |
| 待客热情 | 希腊人非常好客 |
| 碎盘子 | 婚礼和庆祝时摔盘子（现代已减少） |
| 眼神交流 | 说话时保持眼神交流表示尊重 |

## 古希腊语与现代希腊语差异

### 主要变化

| 方面 | 古希腊语 | 现代希腊语 |
|------|----------|------------|
| 发音 | 有长短元音区分 | 元音合并（ι/η/υ/ει/οι 都读 /i/） |
| 语法 | 五个格 | 四个格（呼格使用减少） |
| 动词 | 更多时态和语态 | 简化，使用助动词 |
| 词汇 | 古典词汇 | 大量借词（土耳其语、意大利语、法语） |
| 文字 | 大写字母为主 | 小写字母为主 |
| 重音 | 有音高重音 | 变为力度重音 |

### 词汇对比

| 中文 | 古希腊语 | 现代希腊语 |
|------|----------|------------|
| 水 | ὕδωρ (hýdōr) | νερό (neró) |
| 火 | πῦρ (pŷr) | φωτιά (fotiá) |
| 太阳 | ἥλιος (hḗlios) | ήλιος (ílios) |
| 书 | βιβλίον (biblíon) | βιβλίο (vivlío) |
| 城市 | πόλις (pólis) | πόλη (póli) |

### 现代希腊语中的古典元素

- 学术和科学术语大量使用古典词根
- 官方语言（Katharevousa）曾长期使用古典化形式
- 1976年后，口语化希腊语（Dimotiki）成为官方标准
