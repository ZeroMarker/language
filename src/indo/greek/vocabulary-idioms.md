# 希腊语常用谚语与习语

## 经典谚语（Παροιμίες）

| 希腊语 | 中文 | 含义 |
|--------|------|------|
| Ο δρόμος γίνεται περπατώντας. | 路是走出来的。 | 实践出真知 |
| Αργά και σταθερά κερδίζει την αγώνα. | 慢而稳者赢得比赛。 | 稳扎稳打 |
| Η γλώσσα κόκαλα δεν έχει, αλλά κόκαλα τσακίζει. | 舌头没有骨头，但能碎骨。 | 言语力量大 |
| Όποιος δεν έχει ταξιδέψει, πιστεύει ότι η μητέρα του είναι η καλύτερη μαγείρισσα. | 没出过门的人认为妈妈是最好的厨师。 | 井底之蛙 |
| Στα χέρια του Θεού. | 在上帝手中。 | 听天由命 |
| Κάθε αρχή είναι δύσκολη. | 万事开头难。 | 万事开头难 |

## 常用习语（Ιδιωματικές Εκφράσεις）

| 希腊语 | 字面意思 | 实际含义 |
|--------|----------|----------|
| Τα λέμε | 我们再说 | 回头见 |
| Τι κάνεις; | 你在做什么？ | 你好吗？ |
| Καλή όρεξη! | 好胃口！ | 请慢用 |
| Στην υγειά σου! | 为你的健康！ | 干杯 |
| Πάμε! | 我们走！ | 加油/出发 |
| Ελα! | 来吧！ | 真的吗？/天哪 |
| Δεν πειράζει. | 没关系。 | 没事 |
| Τι να πω... | 我能说什么…… | 真是的…… |
| Μην ανησυχείς. | 别担心。 | 放心吧 |
| Είναι το ίδιο. | 这是一样的。 | 无所谓 |

## 俚语表达

| 希腊语 | 含义 | 使用场景 |
|--------|------|----------|
| Γεια! | 干杯/你好 | 喝酒时或见面时 |
| Μπράβο! | 好样的 | 称赞 |
| Ωραία! | 好/漂亮 | 表示赞同 |
| Αστείο! | 有趣 | 觉得好笑 |
| Τέλεια! | 完美 | 表示满意 |
| Πολύ καλά! | 很好 | 表示认可 |
| Μα... | 但是…… | 表示惊讶或质疑 |
| Α, ναι! | 啊，对！ | 想起来了 |

## 场景应用

### 表达感谢
- Ευχαριστώ πολύ!（非常感谢！）
- Σ' ευχαριστώ!（谢谢你！——非正式）
- Σας ευχαριστώ!（谢谢您！——正式）

### 表达歉意
- Συγγνώμη.（对不起。）
- Με συγχωρείτε.（请原谅。）
- Δεν το ήθελα.（我不是故意的。）

### 表达同意/不同意
- Συμφωνώ.（我同意。）
- Διαφωνώ.（我不同意。)
- Ίσως.（也许。）
- Βέβαια!（当然！）
- Δεν νομίζω.（我不这么认为。）
