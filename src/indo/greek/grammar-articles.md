# 希腊语冠词变化详解

## 概述

希腊语有定冠词（确定的）和不定冠词（不确定的）。定冠词使用频率极高，是希腊语语法的核心。

## 定冠词（Οριστικό Άρθρο）

### 变化表

| 格 | 阳性 | 阴性 | 中性 |
|------|------|------|------|
| **单数** | | | |
| 主格 | ο | η | το |
| 属格 | του | της | του |
| 宾格 | τον | τη | το |
| **复数** | | | |
| 主格 | οι | οι | τα |
| 属格 | των | των | των |
| 宾格 | τους | τις | τα |

### 定冠词用法

**1. 特指已知事物**
- **Ο** γιατρός είναι εδώ.（那个医生在这里。——双方都知道是哪个医生）

**2. 抽象概念**
- **Η** αγάπη είναι σημαντική.（爱很重要。）

**3. 泛指类别**
- **Ο** σκύλος είναι καλό ζώο.（狗是好动物。——指所有狗）

**4. 与专有名词连用**
- **Η** Ελλάδα（希腊）
- **Ο** Γιάννης（扬尼斯——人名）

**5. 表示时间**
- **Το** πρωί（早上）
- **Το** βράδυ（晚上）

## 不定冠词（Αόριστο Άρθρο）

### 变化表

| 格 | 阳性 | 阴性 | 中性 |
|------|------|------|------|
| 主格 | ένας | μία/μια | ένα |
| 属格 | ενός | μιας | ενός |
| 宾格 | ένα(ν) | μία/μια | ένα |

### 不定冠词用法

**1. 首次提及**
- Βλέπω **έναν** σκύλο.（我看到一条狗。——第一次提到）

**2. 数量"一"**
- Θέλω **ένα** καφέ.（我要一杯咖啡。）

**3. 泛指某一个**
- **Μια** γυναίκα μίλησε σε μένα.（一个女人和我说话。）

## 零冠词

希腊语在以下情况不使用冠词：

| 情况 | 示例 |
|------|------|
| 职业表述（首次） | Είμαι γιατρός.（我是医生。） |
| 感叹句 | Ωραία μέρα!（多美好的一天！） |
| 某些固定搭配 | Καλημέρα!（早上好！） |

## 常见错误提示

- ❌ Είμαι **ο** γιατρός.（首次提及职业时不用冠词）
- ✅ Είμαι γιατρός.
- ✅ **Ο** γιατρός είναι καλός.（特指某个医生时用冠词）
