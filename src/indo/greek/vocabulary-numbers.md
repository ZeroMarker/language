| 0 | μηδέν | midén |

| 3 | τρία | tría |
| 4 | τέσσερα | téssera |
| 5 | πέντε | pénte |
| 6 | έξι | éxi |
| 7 | εφτά / επτά | eftá / eptá |
| 8 | οχτώ / οκτώ | ochtó / októ |
| 9 | εννιά / εννέα | enniá / ennéa |
| 10 | δέκα | déka |

## 分数（Κλασματά）

| 分数 | 希腊语 |
|------|--------|
| 1/2 | ένα δεύτερο / μισό |
| 1/3 | ένα τρίτο |
| 1/4 | ένα τέταρτο / τέταρτο |
| 3/4 | τρία τέταρτα |

## 用法示例

- Έχω **τρία** αδέλφια.（我有三个兄弟姐妹。）
- Είμαι **είκοσι** χρονών.（我二十岁。）
- Μένω στον **τέταρτο** όροφο.（我住在四楼。）
- Το βιβλίο κοστίζει **δεκαπέντε** ευρώ.（这本书十五欧元。）
