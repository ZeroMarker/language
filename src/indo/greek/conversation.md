# 希腊语日常会话

## 开口与礼貌

| 希腊语 | 中文 |
|--------|------|
| Γεια σου. | 你好。（非正式） |
| Γεια σας. | 您好。（正式/复数） |
| Καλημέρα. | 早上好。 |
| Καλησπέρα. | 下午/晚上好。 |
| Καληνύχτα. | 晚安。 |
| Αντίο. | 再见。 |
| Ευχαριστώ. | 谢谢。 |
| Παρακαλώ. | 请。/不客气。 |
| Συγγνώμη. | 对不起。/打扰一下。 |
| Ναι / Όχι. | 是/不是。 |

## 自我介绍

| 希腊语 | 中文 |
|--------|------|
| Με λένε... | 我叫…… |
| Από πού είσαι; | 你从哪里来？ |
| Είμαι από την Κίνα. | 我来自中国。 |
| Δεν μιλάω καλά ελληνικά. | 我希腊语说得不好。 |
| Μιλάω λίγα ελληνικά. | 我会说一点希腊语。 |
| Μιλάτε αγγλικά; | 您会说英语吗？ |
| Χαίρω πολύ. | 很高兴认识你。 |

## 问路

| 希腊语 | 中文 |
|--------|------|
| Πού είναι ο σταθμός; | 车站在哪里？ |
| Είναι μακριά; | 远吗？ |
| Πώς μπορώ να πάω; | 我怎么去？ |
| Ευθεία. | 直走。 |
| Αριστερά / Δεξιά. | 左/右。 |
| Στρίψτε αριστερά. | 左转。 |
| Εδώ / Εκεί. | 这里/那里。 |
