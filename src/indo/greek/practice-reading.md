# 希腊语阅读练习

## 初级阅读

### 短文 1：自我介绍

> Με λένε Μαρία. Είμαι είκοσι χρονών. Μένω στην Αθήνα. Είμαι φοιτήτρια. Σπουδάζω ιατρική. Μιλάω ελληνικά, αγγλικά και λίγα γαλλικά.

**生词表**

| 希腊语 | 中文 |
|--------|------|
| με λένε | 我叫 |
| είμαι | 我是 |
| χρονών | 岁 |
| μένω | 我住 |
| φοιτήτρια | 女大学生 |
| σπουδάζω | 我学习（专业） |
| ιατρική | 医学 |

**理解问题**
1. Πόσο χρονών είναι η Μαρία;（玛丽亚多大？）
2. Πού μένει;（她住在哪里？）
3. Τι σπουδάζει;（她学什么专业？）

### 短文 2：在咖啡馆

> Ο Γιάννης και η Ελένη είναι στο καφενείο. Ο Γιάννης παραγγέλνει έναν ελληνικό καφέ. Η Ελένη θέλει έναν φρέδο. Είναι καλοί φίλοι. Μιλάνε για τη δουλειά.

**生词表**

| 希腊语 | 中文 |
|--------|------|
| καφενείο | 咖啡馆 |
| παραγγέλνει | 点（餐） |
| ελληνικός καφές | 希腊咖啡 |
| φρέδο | 冰咖啡 |
| καλοί φίλοι | 好朋友 |
| μιλάνε | 他们谈论 |
| δουλειά | 工作 |

## 阅读技巧

1. **先读标题**：了解主题
2. **找关键词**：识别名词和动词
3. **利用上下文**：猜测生词含义
4. **注意词尾**：通过词尾判断词性和时态
5. **多读多练**：从简单文本开始，逐步增加难度
