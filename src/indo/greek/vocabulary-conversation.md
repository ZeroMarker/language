# 希腊语日常会话场景

## 问候与告别

| 场景 | 希腊语 | 中文 |
|------|--------|------|
| 早上好 | Καλημέρα | 早上好 |
| 下午好 | Καλησπέρα | 下午/晚上好 |
| 晚安 | Καληνύχτα | 晚安 |
| 你好 | Γεια σου / Γεια σας | 你好（非正式/正式） |
| 再见 | Αντίο | 再见 |
| 回头见 | Τα λέμε | 回头聊 |

## 自我介绍

| 希腊语 | 中文 |
|--------|------|
| Με λένε... | 我叫…… |
| Είμαι από την Κίνα. | 我来自中国。 |
| Μιλάω κινέζικα. | 我说中文。 |
| Δεν μιλάω καλά ελληνικά. | 我希腊语说得不好。 |
| Μιλάτε αγγλικά; | 您说英语吗？ |

## 在餐厅

| 希腊语 | 中文 |
|--------|------|
| Ένα τραπέζι για δύο, παρακαλώ. | 请给我一张两人桌。 |
| Το μενού, παρακαλώ. | 请给我菜单。 |
| Θα ήθελα έναν καφέ. | 我想要一杯咖啡。 |
| Τον λογαριασμό, παρακαλώ. | 请买单。 |
| Πόσο κάνει; | 多少钱？ |

## 购物

| 希腊语 | 中文 |
|--------|------|
| Πόσο κοστίζει; | 这个多少钱？ |
| Είναι πολύ ακριβό. | 太贵了。 |
| Μπορώ να το δοκιμάσω; | 我可以试一下吗？ |
| Θέλω αυτό. | 我想要这个。 |
| Πού είναι το ταμείο; | 收银台在哪里？ |

## 问路

| 希腊语 | 中文 |
|--------|------|
| Πού είναι...; | ……在哪里？ |
| Πώς πάω στο...; | 去……怎么走？ |
| Είναι μακριά; | 远吗？ |
| Στρίψτε αριστερά/δεξιά. | 向左/右转。 |
| Ευχαριστώ πολύ! | 非常感谢！ |

## 紧急情况

| 希腊语 | 中文 |
|--------|------|
| Βοήθεια! | 救命！ |
| Καλέστε την αστυνομία! | 请叫警察！ |
| Χρειάζομαι γιατρό. | 我需要医生。 |
| Δεν καταλαβαίνω. | 我不明白。 |
| Μιλήστε πιο αργά, παρακαλώ. | 请说慢一点。 |
