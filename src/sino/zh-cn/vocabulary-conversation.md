# 现代汉语 口语高频表达

本页整理日常口语中高频出现的**词汇化表达**（口头禅、应答语、语气词、委婉说法），与场景对话（见 [conversation.md](conversation.md)）互补。

## 应答与接话

| 表达 | 含义/用法 |
|------|-----------|
| 嗯 / 啊 / 哦 | 应声、回应 |
| 行 / 好嘞 / 成 | 同意、答应 |
| 没事儿 | 不要紧、没关系 |
| 那可不 | 赞同对方（"可不是吗"） |
| 说真的 | 强调接下来是认真的 |
| 其实吧 | 引出转折或补充 |

## 语气词与句末

- **啊 / 呀 / 吧 / 呢 / 嘛 / 呗**：调节语气（疑问、催促、让步、提醒等）
- **了**：表示变化或完成（如"下班了"）
- **的**：表示确认、肯定（如"我是这么想的"）

## 口头禅

| 表达 | 含义 |
|------|------|
| 怎么说呢 | 思考时的拖延语 |
| 你懂的 | 心照不宣 |
| 差不多得了 | 适可而止 |
| 厉害了 | 赞叹 |
| 完了 | 糟糕 / 结束 |

## 委婉表达

| 表达 | 委婉含义 |
|------|-----------|
| 还可以 | "一般般"的委婉说法 |
| 凑合 | 勉强过得去 |
| 不太清楚 | "不知道"的委婉说法 |
| 改天 | 未来某天（常用于婉拒邀约） |
