# 现代汉语补语系统详解

## 概述

补语是动词或形容词后面的补充成分，用于说明动作的结果、程度、趋向、可能等。

## 补语的类型

### 1. 结果补语

表示动作的结果。

| 结构 | 示例 | 含义 |
|------|------|------|
| 动词+形容词 | 看清楚 | 看的结果是清楚 |
| 动词+动词 | 听懂 | 听的结果是懂 |
| 动词+形容词 | 洗干净 | 洗的结果是干净 |

**常用结果补语**：

| 补语 | 示例 |
|------|------|
| 完 | 做完、吃完 |
| 好 | 做好、准备好 |
| 到 | 看到、找到 |
| 见 | 听见、看见 |
| 懂 | 听懂、看懂 |
| 清楚 | 看清楚、说清楚 |
| 干净 | 洗干净、打扫干净 |
| 光 | 吃光、用光 |
| 掉 | 扔掉、删掉 |
| 破 | 打破、说破 |

### 2. 程度补语

表示动作或状态的程度。

| 结构 | 示例 | 含义 |
|------|------|------|
| 形容词+得很 | 好得很 | 非常好 |
| 形容词+极了 | 好极了 | 非常好 |
| 形容词+死了 | 累死了 | 非常累 |
| 形容词+透了 | 坏透了 | 非常坏 |

**常用程度补语**：

| 补语 | 示例 |
|------|------|
| 得很 | 好得很、热得很 |
| 极了 | 好极了、冷极了 |
| 死了 | 累死了、热死了 |
| 透了 | 坏透了、恨透了 |
| 坏了 | 累坏了、吓坏了 |
| 了不得 | 好了不得 |

### 3. 趋向补语

表示动作的趋向。

| 趋向动词 | 示例 |
|---------|------|
| 来 | 过来、拿来 |
| 去 | 过去、拿去 |
| 上 | 走上、跑上 |
| 下 | 走下、坐下 |
| 进 | 走进、跑进 |
| 出 | 走出、跑出 |
| 回 | 走回、跑回 |
| 起 | 站起、拿起 |
| 开 | 走开、离开 |
| 到 | 走到、跑到 |

**复合趋向补语**：

| 补语 | 示例 |
|------|------|
| 上来 | 走上来、跑上来 |
| 上去 | 走上去、跑上去 |
| 下来 | 走下来、跑下来 |
| 下去 | 走下去、跑下去 |
| 进来 | 走进来、跑进来 |
| 进去 | 走进去、跑进去 |
| 出来 | 走出来、跑出来 |
| 出去 | 走出去、跑出去 |
| 回来 | 走回来、跑回来 |
| 回去 | 走回去、跑回去 |
| 起来 | 站起来、拿起来 |

### 4. 可能补语

表示动作的可能性。

| 结构 | 示例 | 含义 |
|------|------|------|
| 动词+得+补语 | 看得见 | 能看见 |
| 动词+不+补语 | 看不见 | 不能看见 |

**常用可能补语**：

| 肯定 | 否定 | 示例 |
|------|------|------|
| 看得见 | 看不见 | 能/不能看见 |
| 听得懂 | 听不懂 | 能/不能听懂 |
| 做得到 | 做不到 | 能/不能做到 |
| 说得清 | 说不清 | 能/不能说清 |
| 拿得动 | 拿不动 | 能/不能拿动 |
| 吃得下 | 吃不下 | 能/不能吃下 |
| 进得去 | 进不去 | 能/不能进去 |
| 出得来 | 出不来 | 能/不能出来 |

### 5. 时间补语

表示动作持续的时间。

| 结构 | 示例 |
|------|------|
| 动词+时量 | 等了三天 |
| 动词+时段 | 学了两年 |

### 6. 处所补语

表示动作的处所。

| 结构 | 示例 |
|------|------|
| 动词+在+处所 | 坐在椅子上 |
| 动词+到+处所 | 走到学校 |

## 补语与宾语的区别

| 成分 | 位置 | 示例 |
|------|------|------|
| 补语 | 动词后 | 看清楚（补语） |
| 宾语 | 动词后 | 看书（宾语） |

## 补语的否定

### 结果补语的否定

用"没"否定：

- 没看清楚
- 没做完

### 可能补语的否定

用"不"否定：

- 看不清楚
- 做不完

## 常见补语句型

### 得+补语

表示可能或程度。

- 看得见（能看见）
- 跑得快（能跑快）
- 好得很（非常好）

### 不+补语

表示不可能。

- 看不见（不能看见）
- 跑不快（不能跑快）

## 学习建议

1. **记住类型**：掌握六种补语类型
2. **注意结构**：注意补语的位置和结构
3. **多练习**：用补语造句练习
4. **对比学习**：与宾语对比学习
