## 常用俗语

### 努力类

| 俗语 | 含义 |
|------|------|
| 只要功夫深，铁杵磨成针 | 只要下功夫，就能成功 |
| 一分耕耘，一分收获 | 付出就有回报 |
| 勤能补拙 | 勤奋能弥补笨拙 |
| 坚持就是胜利 | 坚持到底就能成功 |
| 不经历风雨，怎么见彩虹 | 不经历困难就不能成功 |

### 智慧类

| 俗语 | 含义 |
|------|------|
| 三个臭皮匠，赛过诸葛亮 | 人多智慧多 |
| 吃一堑，长一智 | 经历一次挫折，增长一分智慧 |
| 不听老人言，吃亏在眼前 | 不听老人的话会吃亏 |
| 知己知彼，百战百胜 | 了解自己和对手就能胜利 |
| 磨刀不误砍柴工 | 准备工作不会耽误时间 |

### 人际类

| 俗语 | 含义 |
|------|------|
| 远亲不如近邻 | 近处的朋友比远处的亲戚更有用 |
| 滴水之恩，当涌泉相报 | 受人恩惠要加倍报答 |
| 人不可貌相 | 不能只看外表 |
| 路遥知马力，日久见人心 | 时间长了才能看出人心 |
| 得饶人处且饶人 | 能宽容就宽容 |

### 警示类

| 俗语 | 含义 |
|------|------|
| 骄傲使人落后 | 骄傲会让人退步 |
| 酒香不怕巷子深 | 好东西不怕没人知道 |
| 亡羊补牢，为时未晚 | 出了问题及时补救还不晚 |
| 覆水难收 | 事情已成定局，无法挽回 |
| 船到桥头自然直 | 事情到了时候自然会解决 |

## 学习建议

1. **结合场景记忆**：将成语与具体场景联系
2. **造句练习**：用成语造句加深印象
3. **对比学习**：与俗语对比理解
4. **日常使用**：在对话中尝试使用
