# 繁體中文語法實例補充

## 概述

本文補充繁體中文語法的實際應用實例，幫助讀者更好地理解和運用繁體中文語法。

## 基本句型

### 主謂句

| 句型 | 示例 | 說明 |
|------|------|------|
| 主語+謂語 | 我吃飯。 | 基本句型 |
| 主語+謂語+賓語 | 我看書。 | 帶賓語 |
| 主語+謂語+補語 | 我吃飽了。 | 帶補語 |

### 疑問句

| 句型 | 示例 | 說明 |
|------|------|------|
| 嗎？ | 你吃飯嗎？ | 一般疑問 |
| 呢？ | 你呢？ | 追問 |
| 什麼？ | 你吃什麼？ | 特殊疑問 |
| 哪裡？ | 你去哪裡？ | 地點疑問 |
| 誰？ | 你是誰？ | 人物疑問 |
| 怎樣？ | 你好嗎？ | 狀態疑問 |

### 否定句

| 句型 | 示例 | 說明 |
|------|------|------|
| 不+動詞 | 我不吃。 | 一般否定 |
| 沒+動詞 | 我沒吃。 | 過去否定 |
| 別+動詞 | 你別吃。 | 禁止 |

## 時態表達

### 現在時

| 句型 | 示例 |
|------|------|
| 正在+動詞 | 我正在吃飯。 |
| 在+動詞 | 我在吃飯。 |

### 過去時

| 句型 | 示例 |
|------|------|
| 動詞+了 | 我吃了飯。 |
| 已經+動詞 | 我已經吃了。 |
| 動詞+過 | 我去過台灣。 |

### 將來時

| 句型 | 示例 |
|------|------|
| 會+動詞 | 我會去。 |
| 要+動詞 | 我要去。 |
| 將+動詞 | 我將去。 |

## 語氣詞

### 常用語氣詞

| 語氣詞 | 用法 | 示例 |
|--------|------|------|
| 嗎 | 疑問 | 你好嗎？ |
| 呢 | 追問 | 你呢？ |
| 吧 | 建議 | 我們走吧。 |
| 啊 | 感嘆 | 好美啊！ |
| 了 | 完成 | 我吃了。 |
| 的 | 肯定 | 我知道的。 |
| 過 | 經驗 | 我去過。 |

## 比較句

### 基本比較

| 句型 | 示例 |
|------|------|
| A比B+形容詞 | 我比你高。 |
| A沒有B+那麼+形容詞 | 我沒有你那麼高。 |
| A和B一樣+形容詞 | 我和你一樣高。 |

### 最高級

| 句型 | 示例 |
|------|------|
| 最+形容詞 | 我最高。 |
| A是最+形容詞+的 | 我是最高的。 |

## 複合句

### 並列句

| 句型 | 示例 |
|------|------|
| 既…又… | 他既聰明又努力。 |
| 一邊…一邊… | 他一邊吃一邊看。 |
| 不是…而是… | 他不是學生，而是老師。 |

### 轉折句

| 句型 | 示例 |
|------|------|
| 雖然…但是… | 雖然很累，但是我堅持。 |
| 儘管…卻… | 儘管困難，卻不放棄。 |

### 因果句

| 句型 | 示例 |
|------|------|
| 因為…所以… | 因為下雨，所以沒去。 |
| 由於…因此… | 由於努力，因此成功。 |

### 條件句

| 句型 | 示例 |
|------|------|
| 如果…就… | 如果下雨，就不去。 |
| 只要…就… | 只要努力，就成功。 |
| 只有…才… | 只有努力，才成功。 |

## 學習建議

1. **記住句型**：掌握基本句型
2. **多練習**：用不同句型造句
3. **注意語序**：注意詞語的順序
4. **對比學習**：與簡體中文對比
