# 文白異讀詳解

## 概述

文白異讀是漢語方言中常見的現象，同一個字在不同語境下有不同的讀音。文讀（讀書音）用於書面語和正式場合，白讀（口語音）用於日常口語。

## 文白異讀的特點

### 文讀（讀書音）

- 用於書面語和正式場合
- 較接近中古漢語的讀音
- 用於朗讀、演講、新聞播報

### 白讀（口語音）

- 用於日常口語
- 較接近現代口語的讀音
- 用於日常對話、口語表達

## 文白異讀的規律

### 聲母差異

| 類型 | 示例 |
|------|------|
| 文讀送氣，白讀不送氣 | 大（dà/tà） |
| 文讀不送氣，白讀送氣 | 道（dào/tào） |

### 韻母差異

| 類型 | 示例 |
|------|------|
| 文讀開口，白讀合口 | 生（shēng/sēng） |
| 文讀合口，白讀開口 | 學（xué/xiáo） |

### 聲調差異

| 類型 | 示例 |
|------|------|
| 文讀平聲，白讀仄聲 | 白（bái/bó） |
| 文讀仄聲，白讀平聲 | 黑（hēi/hè） |

## 文白異讀的使用場景

### 使用文讀的場合

| 場合 | 說明 |
|------|------|
| 朗讀 | 朗讀課文、詩歌 |
| 演講 | 正式演講、報告 |
| 新聞 | 新聞播報 |
| 教學 | 課堂教學 |

|------|------|
