# 韩语 动词活用与时态

## 动词原形

韩语动词以 -다 结尾：
- 가다 (gada) - 去
- 먹다 (meokda) - 吃
- 하하다 (hada) - 做

## 时态变化

### 现在时
词干 + -아/어요：
- 가 → 가요 (gayo)
- 먹 → 먹어요 (meogeoyo)

### 过去时
词干 + -았/었어요：
- 가 → 갔어요 (gasseoyo)
- 먹 → 먹었어요 (meogeosseoyo)

### 将来时
词干 + -ㄹ/을 거예요：
- 가 → 갈 거예요 (gal geoyeyo)
- 먹 → 먹을 거예요 (meogeul geoyeyo)

## 不规则动词

- ㄷ不规则：듣다 → 들어요
- ㅂ不规则：춥다 → 추워요
- ㅎ不规则：좋다 → 좋아요
