# 韩语 阅读练习

## 基础句子

| 韩语 | 中文 |
|------|------|
| 저는 학생입니다. | 我是学生。 |
| 오늘 날씨가 좋습니다. | 今天天气很好。 |
| 서울에 가고 싶습니다. | 我想去首尔。 |
| 한국어를 공부하고 있습니다. | 我在学韩语。 |
| 이름이 뭐예요？ | 您叫什么名字？ |

## 短文练习

### 자기소개

제 이름은 김민수입니다. 한국 사람입니다. 서울에 살고 있습니다. 대학교에서 한국어를 가르치고 있습니다. 취미는 독서와 여행입니다.

### 翻译

我叫金民秀。我是韩国人。我住在首尔。我在大学教韩语。我的爱好是读书和旅行。

## 练习建议

1. 识别韩文字母的组合
2. 理解助词的用法
3. 识别动词的活用形
