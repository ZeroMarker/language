# 韩国文化简介与敬语使用场景指南

## 韩国文化概述

### 核心价值观

韩国文化的核心价值观包括：

- **孝（효）**：孝道，尊敬长辈
- **礼（예）**：礼仪，注重礼节
- **忠（충）**：忠诚，对国家和社会的忠诚
- **义（의）**：义气，朋友间的义气

### 集体主义

韩国社会强调集体利益：
- 团队精神（팀워크）
- 不突出个人
- 重视人际关系

### 年龄文化

韩国非常重视年龄：
- 初次见面常问年龄
- 根据年龄决定使用何种语体
- 年龄决定社会地位

## 日常礼仪

### 鞠躬

| 场合 | 礼节 |
|------|------|
| 日常问候 | 轻微点头 |
| 对长辈 | 45度鞠躬 |
| 非常正式 | 深鞠躬 |

### 用餐礼仪

- 长辈先动筷
- 不要端起饭碗吃饭
- 倒酒时双手持瓶
- 不要自己给自己倒酒

### 送礼文化

- 乔迁送卫生纸（寓意生活顺利）
- 生病送花（不要送红色花）
- 结婚送现金（白色信封）

## 敬语使用场景指南

### 何时使用敬语

| 对象 | 语体 | 示例 |
|------|------|------|
| 长辈、上司 | 합쇼체 | 갑니다 |
| 不太熟的人 | 해요체 | 가요 |
| 朋友 | 반말 | 가 |
| 晚辈 | 반말 | 가 |

### 年龄与语体

| 关系 | 语体 |
|------|------|
| 年长5岁以上 | 必须使用敬语 |
| 年长1-4岁 | 可使用敬语或半语 |
| 同龄 | 可使用半语 |
| 年幼 | 使用半语 |

### 职场敬语

| 对象 | 语体 |
|------|------|
| 社长 | 最高级敬语 |
| 部长 | 敬语 |
| 代理 | 敬语 |
| 同事（年长） | 敬语 |
| 同事（同龄） | 可半语 |

### 常见敬语表达

| 普通 | 敬语 | 含义 |
|------|------|------|
| 밥 먹었어? | 식사하셨어요? | 吃饭了吗？ |
| 어디 가? | 어디 가세요? | 去哪里？ |
| 이름이 뭐야? | 성함이 어떻게 되세요? | 您贵姓？ |
| 나이가 몇이야? | 연세가 어떻게 되세요? | 您多大年纪？ |
| 집이 어디야? | 댁이 어디세요? | 您家住哪里？ |

## 韩国饮食文化

### 代表性料理

| 料理 | 特点 |
|------|------|
| 김치 | 泡菜（发酵蔬菜） |
| 비빔밥 | 拌饭 |
| 불고기 | 烤肉 |
| 삼겹살 | 五花肉 |
| 떡볶이 | 炒年糕 |
| 냉면 | 冷面 |
| 된장찌개 | 大酱汤 |
| 김치찌개 | 泡菜汤 |
| 삼계탕 | 参鸡汤 |

### 饮食礼仪

- 长辈先开始吃
- 吃饭时不要说话
- 倒酒时右手持瓶，左手扶右手
- 不要将筷子插在饭里

## 韩国职场文化

### 公司聚餐文化

- 회식（会食）：公司聚餐
- 2차：第二轮（通常去酒吧）
- 不要先离开
- 要给前辈倒酒

### 称呼方式

| 称呼 | 用法 |
|------|------|
| ○○씨 | 对同龄或稍年长的人 |
| ○○님 | 对不太熟的人 |
| ○○선배 | 对前辈 |
| ○○老师 | 对老师 |

## 韩国流行文化

### K-POP

- 代表团体：BTS、BLACKPINK、EXO
- 应援文化（응원문화）
- 追星文化（팬덤문화）

### 韩剧

- 代表性作品：《鱿鱼游戏》《太阳的后裔》
- 韩流（한류）现象

### 综艺节目

- Running Man
- 无限挑战
- 我独自生活
