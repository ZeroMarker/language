# 韩语动词活用与时态详解

## 概述

韩语动词的活用是韩语语法的核心，动词词干后接不同的词尾来表示时态、语气等。

## 动词的基本形

### 词干提取

| 基本形 | 词干 | 类型 |
|--------|------|------|
| 가다（去） | 가 | ㅏ类 |
| 먹다（吃） | 먹 | ㅓ类 |
| 배우다（学习） | 배우 | ㅜ类 |
| 마시다（喝） | 마시 | ㅣ类 |
| 하다（做） | 하 | 하类 |

### 词干元音分类

| 元音类型 | 词干末尾元音 | 示例 |
|---------|------------|------|
| ㅏ类 | ㅏ | 가다, 앉다 |
| ㅓ类 | ㅓ | 먹다, 읽다 |
| ㅗ类 | ㅗ | 오다, 보다 |
| ㅜ类 | ㅜ | 주다, 배우다 |
| ㅣ类 | ㅣ | 마시다, 기다리다 |
| 하类 | 하 | 하다, 공부하다 |

## 时态

### 现在时

词干＋아/어요（敬语体）

| 动词 | 现在时 | 规则 |
|------|--------|------|
| 가다 | 가요 | ㅏ+아→ㅏ |
| 먹다 | 먹어요 | ㅓ+어 |
| 오다 | 와요 | ㅗ+아→ㅘ |
| 마시다 | 마셔요 | ㅣ+어→ㅕ |
| 하다 | 해요 | 하+아→해 |
| 배우다 | 배워요 | ㅜ+어→ㅝ |

**元音和谐规则**：
- ㅏ/ㅗ词干 → 加아
- 其他元音 → 加어
- 하다 → 하여→해

### 过去时

词干＋았/었어요

| 动词 | 过去时 |
|------|--------|
| 가다 | 갔어요 |
| 먹다 | 먹었어요 |
| 오다 | 왔어요 |
| 마시다 | 마셨어요 |
| 하다 | 했어요 |
| 배우다 | 배웠어요 |

### 将来时

词干＋ㄹ/을 거예요（表示计划或推测）

| 动词 | 将来时 |
|------|--------|
| 가다 | 갈 거예요 |
| 먹다 | 먹을 거예요 |
| 오다 | 올 거예요 |
| 마시다 | 마실 거예요 |
| 하다 | 할 거예요 |

## 语体

### 敬语体（존댓말）

- 词干＋아/어요：日常敬语
- 词干＋ㅂ/습니다：正式敬语

### 非敬语体（반말）

- 词干＋아/어：朋友之间
- 词干＋다：书面体

| 动词 | 敬语体 | 非敬语体 |
|------|--------|---------|
| 가다 | 가요 | 가 |
| 먹다 | 먹어요 | 먹어 |
| 오다 | 와요 | 와 |
| 하다 | 해요 | 해 |

### 正式敬语体（합쇼체）

| 动词 | 现在时 | 过去时 |
|------|--------|--------|
| 가다 | 갑니다 | 갔습니다 |
| 먹다 | 먹습니다 | 먹었습니다 |
| 오다 | 옵니다 | 왔습니다 |
| 하다 | 합니다 | 했습니다 |

## 尊敬形

对长辈或尊敬的人使用特殊的动词形式。

| 普通动词 | 尊敬形 | 含义 |
|---------|--------|------|
| 먹다 | 드시다/잡수시다 | 吃 |
| 마시다 | 드시다 | 喝 |
| 있다 | 계시다 | 在 |
| 자다 | 주무시다 | 睡觉 |
| 말하다 | 말씀하시다 | 说 |
| 보다 | 뵙다 | 见面 |
| 주시다 | 드리다 | 给（谦语） |
| 죽다 | 돌아가시다 | 去世 |

尊敬形的活用：
- 선생님이 드십니다.（老师在吃。）
- 할아버지가 주무십니다.（爷爷在睡觉。）

## 动词的否定

### 안 + 动词

- 안 먹어요.（不吃。）
- 안 가요.（不去。）

### 动词 + 지 않다

- 먹지 않아요.（不吃。）
- 가지 않아요.（不去。）

### 못 + 动词（不能）

- 못 먹어요.（不能吃。）
- 못 가요.（不能去。）
