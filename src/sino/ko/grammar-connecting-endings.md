# 韩语连接词尾详解

## 概述

连接词尾是韩语语法的重要组成部分，用于连接两个或多个句子，表达各种逻辑关系。

## 表示并列的连接词尾

### -고（和、而且）

连接两个动作或状态。

- 밥을 먹고 학교에 갔어요.（吃了饭去了学校。）
- 날씨가 좋고 바람도 불어요.（天气好，风也吹。）
- 비싸고 맛있어요.（贵而且好吃。）

### -며/며（一边…一边…）

同时进行两个动作。

- 음악을 들으며 공부해요.（一边听音乐一边学习。）
- 노래를 부르며 춤을 추어요.（一边唱歌一边跳舞。）

### -아/어서（…之后）

表示动作的先后顺序。

- 밥을 먹어서 학교에 갔어요.（吃了饭之后去了学校。）
- 일어나서 세수를 해요.（起床后洗脸。）

## 表示原因的连接词尾

### -아/어서（因为）

表示原因或理由。

- 비가 와서 못 갔어요.（因为下雨没去。）
- 배가 고파서 밥을 먹었어요.（因为饿了吃了饭。）

### -니까/으니까（因为）

表示原因，带有强调语气。

- 늦었으니까 빨리 가세요.（因为晚了快走吧。）
- 추우니까 따뜻하게 입으세요.（因为冷穿暖和点。）

### -기 때문에（因为…所以…）

较正式的原因表达。

- 비가 오기 때문에 우산을 가져가세요.（因为下雨请带伞。）

## 表示转折的连接词尾

### -지만（但是）

表示转折。

- 비싸지만 맛있어요.（贵但是好吃。）
- 힘들지만 재미있어요.（辛苦但有趣。）

### -는데/은데（…可是…）

表示背景或转折。

- 한국어를 배우는데 어려워요.（在学韩语可是很难。）
- 맛있는데 비싸요.（好吃可是贵。）

## 表示条件的连接词尾

### -면/으면（如果）

表示假设条件。

- 시간이 있으면 만나요.（如果有时间就见面。）
- 비가 오면 집에 있어요.（如果下雨就在家。）

### -아/어야（只有…才…）

表示必要条件。

- 열심히 해야 성공해요.（只有努力才能成功。）
- 일찍 가야 자리를 잡을 수 있어요.（只有早去才能占到位置。）

## 表示目的的连接词尾

### -러（去/来做…）

表示移动的目的。

- 밥을 먹으러 식당에 가요.（去餐厅吃饭。）
- 책을 빌리러 도서관에 가요.（去图书馆借书。）

### -려고/으려고（为了…）

表示意图或目的。

- 한국어를 배우려고 한국에 왔어요.（为了学韩语来了韩国。）
- 시험을 준비하려고 도서관에 가요.（为了准备考试去图书馆。）

## 表示程度的连接词尾

### -게（…地）

表示方式或程度。

- 빨리 걸어요 → 빨리 걸어가요.（快走。）
- 맛있게 먹어요.（好吃地吃。）

### -도록（直到…为止）

表示时间或程度的界限。

- 밤늦도록 공부해요.（学习到深夜。）
- 쓰러지도록 일해요.（工作到倒下。）

## 表示让步的连接词尾

### -아/어도（即使…也…）

表示让步。

- 비가 와도 갈 거예요.（即使下雨也要去。）
- 비싸도 살 거예요.（即使贵也要买。）

### -더라도（即使…也…）

更强的让步语气。

- 힘들더라도 해야 해요.（即使辛苦也要做。）

## 表示选择的连接词尾

### -거나（或者）

表示选择。

- 커피를 마시거나 차를 마셔요.（喝咖啡或喝茶。）
- 버스를 타거나 지하철을 타요.（坐公交或坐地铁。）

## 连接词尾总结表

| 连接词尾 | 含义 | 示例 |
|---------|------|------|
| -고 | 和、然后 | 먹고 갔어요 |
| -아/어서 | 之后、因为 | 먹어서 갔어요 |
| -지만 | 但是 | 비싸지만 맛있어요 |
| -면/으면 | 如果 | 시간이 있으면 만나요 |
| -러 | 去做… | 먹으러 가요 |
| -려고 | 为了… | 배우려고 왔어요 |
| -게 | …地 | 맛있게 먹어요 |
| -아/어도 | 即使…也… | 와도 돼요 |
| -거나 | 或者 | 먹거나 마셔요 |
| -는데 | 可是 | 하는데 어려워요 |
| -니까 | 因为 | 늦었으니까 가요 |
