# 韩语被动语态详解

## 概述

韩语的被动语态表示主语承受动作，而非执行动作。被动语态在韩语中有多种构成方式。

## 被动语态的构成方式

### 1. 动词词干＋被动后缀

| 主动 | 被动 | 含义 |
|------|------|------|
| 먹다（吃） | 먹히다 | 被吃 |
| 읽다（读） | 읽히다 | 被读 |
| 보다（看） | 보이다 | 被看、看得见 |
| 듣다（听） | 들리다 | 被听、听得见 |
| 잡다（抓） | 잡히다 | 被抓 |
| 읽다（读） | 읽히다 | 被读 |
| 빼앗다（夺） | 빼앗기다 | 被夺 |
| 팔다（卖） | 팔리다 | 被卖 |
| 닫다（关） | 닫히다 | 被关 |
| 열다（开） | 열리다 | 被开 |
| 씻다（洗） | 씻기다 | 被洗 |
| 밀다（推） | 밀리다 | 被推 |
| 놀라다（惊讶） | 놀라게 하다 | 使…惊讶 |

### 被动后缀的规律

| 后缀 | 适用情况 | 示例 |
|------|---------|------|
| -이- | 词干以辅音结尾 | 먹히다, 잡히다 |
| -히- | 词干以ㄱ结尾 | 읽히다 |
| -리- | 词干以ㄹ结尾 | 팔리다, 열리다 |
| -기- | 词干以ㄷ结尾 | 닫히다 |

### 2. -아/어지다（变得…）

表示状态的变化或被动。

- 문이 열려요.（门开了。）→ 문이 열려졌어요.（门被打开了。）
- 날씨가 추워졌어요.（天气变冷了。）
- 그림이 벽에 걸렸어요.（画挂在墙上了。）

### 3. -게 되다（变成…）

表示被动或变化的结果。

- 알게 되었어요.（知道了。）
- 만나게 되었어요.（见到了。）

## 被动语态的使用场景

### 描述动作的承受者

| 主动句 | 被动句 |
|--------|--------|
| 고양이가 쥐를 잡았어요.（猫抓了老鼠。） | 쥐가 고양이에게 잡혔어요.（老鼠被猫抓了。） |
| 누가 문을 열었어요.（谁开了门。） | 문이 열렸어요.（门被打开了。） |
| 경찰이 범인을 체포했어요.（警察逮捕了犯人。） | 범인이 경찰에게 체포되었어요.（犯人被警察逮捕了。） |

### 描述自然现象

- 비가 왔어요.（下雨了。）
- 바람이 불었어요.（刮风了。）

### 描述客观事实

- 한국어는 세계에서 많이 사용돼요.（韩语在世界上被广泛使用。）
- 이 영화는 실화를 바탕으로 만들어졌어요.（这部电影是根据真实故事制作的。）

## 被动语态的助词变化

被动句中，动作的执行者用"-에게"或"-에 의해"表示。

| 主动句助词 | 被动句助词 |
|-----------|-----------|
| -이/가（主语） | -이/가（主语） |
| -을/를（宾语） | — |
| — | -에게/에 의해（执行者） |

### 示例

| 主动句 | 被动句 |
|--------|--------|
| 경찰이 범인을 잡았어요. | 범인이 경찰에게 잡혔어요. |
| 어머니가 아이를 안았어요. | 아이가 어머니에게 안겼어요. |
| 누가 그림을 그렸어요. | 그림이 그려졌어요. |

## 被动形常用动词表

| 主动 | 被动 | 用法 |
|------|------|------|
| 잡다 | 잡히다 | 잡히다（被抓） |
| 읽다 | 읽히다 | 읽히다（被读） |
| 보다 | 보이다 | 보이다（被看见） |
| 듣다 | 들리다 | 들리다（被听见） |
| 팔다 | 팔리다 | 팔리다（被卖） |
| 열다 | 열리다 | 열리다（被打开） |
| 닫다 | 닫히다 | 닫히다（被关闭） |
| 쓰다 | 쓰이다 | 쓰이다（被写） |
| 빼앗다 | 빼앗기다 | 빼앗기다（被夺走） |
| 밀다 | 밀리다 | 밀리다（被推） |
| 놀라다 | 놀라게 하다 | 놀라게 하다（使…惊讶） |
| 안다 | 안기다 | 안기다（被抱） |

## 被动句的否定

| 肯定 | 否定 |
|------|------|
| 문이 열렸어요. | 문이 열리지 않았어요. |
| 잡혔어요. | 잡히지 않았어요. |

## 被动语态与其他语法的结合

### 被动＋时态

| 时态 | 示例 |
|------|------|
| 现在 | 문이 열려요. |
| 过去 | 문이 열렸어요. |
| 将来 | 문이 열릴 거예요. |

### 被动＋敬语

- 문이 열리셨어요.（对尊敬的人）
- 음식이 드셔졌어요.（食物被吃了，敬语）

## 常见被动句型

### -에 의해（由…）

- 이 소설은 유명 작가에 의해 쓰였어요.（这本小说是由著名作家写的。）
- 이 건물은 100년 전에 지어졌어요.（这栋建筑是100年前建的。）

### -에서（在…被…）

- 한국어는 한국에서 사용돼요.（韩语在韩国被使用。）
- 이 제품은 세계에서 팔려요.（这个产品在世界销售。）
