# 授受动词用法（あげる/もらう/くれる）

## 概述

日语中有三组授受动词，分别表示给予、接受和别人为我做某事。它们反映了日语中"内外有别"的文化意识。

## 三组授受动词

### あげる（给…）

表示说话人（或己方）给别人东西或为别人做事。

- 私は友達に本をあげた。（我给了朋友一本书。）
- 弟にケーキを作ってあげた。（我给弟弟做了蛋糕。）

**方向**：说话人 → 他人（由内向外）

### もらう（从…得到）

表示说话人（或己方）从别人那里得到东西或别人为自己做事。

- 友達に本をもらった。（我从朋友那里得到了一本书。）
- 先生に教えてもらった。（我从老师那里学到了。）

**方向**：他人 → 说话人（由外向内）

### くれる（…给我）

表示别人给说话人（或己方）东西或为说话人做事。

- 友達が私に本をくれた。（朋友给了我一本书。）
- 母がケーキを作ってくれた。（妈妈给我做了蛋糕。）

**方向**：他人 → 说话人（由外向内）

## 授受动词的语法结构

### あげる

**基本句型**：AはBに～をあげる

- 私は妹にプレゼントをあげます。（我给妹妹礼物。）

**て形句型**：AはBに～てあげる（为别人做某事）

- 私は友達に手紙を書いてあげました。（我帮朋友写了信。）

**常用搭配**：

| 用法 | 示例 |
|------|------|
| ～てあげる | 手伝ってあげる（帮忙） |
| ～てさしあげる | ご説明してさしあげる（为您说明，更谦虚） |

### もらう

**基本句型**：AはBから/に～をもらう

- 私は友達から本をもらった。（我从朋友那里收到了书。）

**て形句型**：AはBに～てもらう（请别人为自己做某事）

- 友達に写真を撮ってもらいました。（请朋友帮我拍了照片。）

**常用搭配**：

| 用法 | 示例 |
|------|------|
| ～てもらう | 教えてもらう（请人教） |
| ～ていただく | お読みいただく（请您读，更谦虚） |

### くれる

**基本句型**：Aが（私に）～をくれる

- 友達が（私に）本をくれた。（朋友给了我书。）

**て形句型**：Aが（私に）～てくれる（别人为我做某事）

- 先生が（私に）問題を解いてくれた。（老师帮我解了题。）

**常用搭配**：

| 用法 | 示例 |
|------|------|
| ～てくれる | 手伝ってくれる（帮我） |
| ～てくださる | ご説明くださる（您为我说明，更尊敬） |

## 三种形式的对比

| 形式 | 主语 | 方向 | 含义 |
|------|------|------|------|
| ～てあげる | 我/己方 | 己方→他人 | 为别人做 |
| ～てもらう | 我/己方 | 他人→己方 | 请别人做 |
| ～てくれる | 他人 | 他人→己方 | 别人为我做 |

## 实际应用示例

### 日常对话

A: 昨日、誰がこの料理を作ってくれたの？（昨天谁做的这道菜？）
B: 母が作ってくれたんだ。（妈妈做的。）

A: 宿題、手伝ってくれる？（能帮我做作业吗？）
B: うん、手伝ってあげるよ。（嗯，我帮你。）

### 商务场合

- 社長がお忙しい中、来てくださいました。（社长在百忙之中来了。）
- 先輩に資料を見ていただきました。（请前辈看了资料。）

## 注意事项

### 避免直接对长辈使用"あげる"

- ❌ 先生にあげました。（对老师说"给你"）
- ✅ 先生に差し上げました。（用谦让语）

### 内外意识

- 说自己家人为外人做某事时用「あげる」
- 说外人为自己家人做某事时用「くれる」
- 从自己家人角度说时用「もらう」

### 受惠感

日语的授受动词包含"受惠"的含义：

- ～てあげる：我给别人恩惠
- ～てもらう：我受到别人恩惠
- ～てくれる：别人给我恩惠
