# 日语 敬语（尊敬語）

尊敬语（尊敬語，そんけいご）

いる → いらっしゃる（在、来、去）

行く・来る → いらっしゃる

言う → おっしゃる

する → なさる

食べる・飲む → 召し上がる

見る → ご覧になる

くれる → くださる

## 謙譲語（けんじょうご，自谦语）

する → いたす

行く・来る → 伺う（うかがう）

言う → 申す（もうす）

食べる・飲む → いただく

見る → 拝見する（はいけんする）

くれる → くださる

いる → おる

## 丁寧語（ていねいご，礼貌语）

动词普通形 + ます / です，例如：

食べる → 食べます

行く → 行きます
