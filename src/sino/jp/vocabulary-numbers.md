## 助数词（量词）

日语中数东西时需要使用助数词，不同类别的物品使用不同的助数词。

### 常用助数词

| 助数词 | 用法 | 1-10 |
|--------|------|------|
| ～つ | 通用（小物品、抽象事物） | ひとつ、ふたつ、みっつ、よっつ、いつつ、むっつ、ななつ、やっつ、ここのつ、とお |
| ～人（にん） | 人数 | ひとり、ふたり、さんにん、よにん、ごにん… |
| ～個（こ） | 小物品、圆形物 | いっこ、にこ、さんこ、よんこ、ごこ、ろっこ、ななこ、はっこ、きゅうこ、じゅっこ |
| ～本（ほん） | 细长物 | いっぽん、にほん、さんぼん、よんほん、ごほん、ろっぽん、ななほん、はっぽん、きゅうほん、じゅっぽん |
| ～枚（まい） | 扁平物 | いちまい、にまい、さんまい… |
| ～台（だい） | 机器、车辆 | いちだい、にだい、さんだい… |
| ～匹（ひき） | 小动物 | いっぴき、にひき、さんびき、よんひき、ごひき、ろっぴき、ななひき、はっぴき、きゅうひき、じゅっぴき |
| ～冊（さつ） | 书本 | いっさつ、にさつ、さんさつ… |
| ～杯（はい） | 杯装物 | いっぱい、にはい、さんばい、よんはい、ごはい、ろっぱい、ななはい、はっぱい、きゅうはい、じゅっぱい |
| ～階（かい） | 楼层 | いっかい、にかい、さんがい、よんかい、ごかい、ろっかい、ななかい、はちかい/はっかい、きゅうかい、じゅっかい |

### 助数词的发音变化

助数词常发生促音便、浊音便等音变：

- 一＋個 → いっこ（促音便）
- 三＋本 → さんぼん（浊音便）
- 六＋匹 → ろっぴき（促音便＋浊音便）
- 八＋杯 → はっぱい（促音便）
