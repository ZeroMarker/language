# 日语 文化背景

## 日本文化简介

- 和文化：茶道、花道、武道
- 动漫文化全球流行
- 传统节日：正月、�的祭、七夕

## 敬语使用场景

| 场景 | 使用敬语类型 |
|------|-------------|
| 对上司/长辈 | 尊敬语 + 谦让语 |
| 对客户 | 谦让语 + 丁宁语 |
| 对朋友 | 普通体 |
| 书面语 | 丁宁语 |

## 常见敬语转换

| 普通语 | 尊敬语 | 谦让语 |
|--------|--------|--------|
| する | なさる | いたす |
| 言う | おっしゃる | 申す |
| 行く | いらっしゃる | 参る |
| 来る | いらっしゃる | 参る |
| 見る | ご覧になる | 拝見する |
| 食べる | 召し上がる | いただく |
