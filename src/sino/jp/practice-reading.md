# 日语 阅读练习

## 基础句子

| 日语 | 中文 |
|------|------|
| 私は学生です。 | 我是学生。 |
| 今日は天気がいいです。 | 今天天气很好。 |
| 東京に行きたいです。 | 我想去东京。 |
| 日本語を勉強しています。 | 我在学日语。 |
| お名前は何ですか？ | 您叫什么名字？ |

## 短文练习

### 自己紹介

私の名前は田中です。日本人です。東京に住んでいます。大学で日本語を教えています。趣味は読書と旅行です。

### 翻译

我叫田中。我是日本人。我住在东京。我在大学教日语。我的爱好是读书和旅行。

## 练习建议

1. 识别平假名、片假名、汉字
2. 理解助词的用法
3. 识别动词的活用形
