# 谦让语详解（谦譲語）

## 概述

谦让语是日语敬语系统的一部分，通过贬低自己的行为来间接抬高对方，体现日本文化中"内外有别"的意识。

## 谦让语的两种类型

### 谦让语Ⅰ（行为谦让语）

降低说话人（或己方）的动作来抬高对方。

| 普通动词 | 谦让语Ⅰ | 含义 |
|---------|---------|------|
| する | いたす | 做 |
| 行く | 参る（まいる） | 去 |
| 来る | 参る | 来 |
| 言う | 申す（もうす）/申し上げる | 说 |
| 見る | 拝見する（はいけんする） | 看 |
| 食べる/飲む | いただく | 吃/喝 |
| 会う | お目にかかる | 见面 |
| 知る | 存じる（ぞんじる） | 知道 |
| 思う | 存じる | 想 |
| 聞く | 伺う（うかがう） | 问/听 |
| 訪ねる | 伺う | 拜访 |
| 与える | 差し上げる | 给 |
| もらう | いただく | 收到 |
| 見せる | お目にかける | 给…看 |
| 待つ | お待ちいただく | 等 |

### 谦让语Ⅱ（丁重语）

不涉及对方，仅表示说话人对听话人的礼貌态度。

| 普通动词 | 谦让语Ⅱ | 含义 |
|---------|---------|------|
| する | いたす | 做 |
| 行く | 参る | 去 |
| 来る | 参る | 来 |
| いる | おる | 在 |
| 知る | 存じ上げる | 知道 |

## 谦让语的句型

### お/ご + 动词连用形 + する

这是最常用的谦让语句型。

- お荷物をお持ちします。（我来帮您拿行李。）
- ご連絡いたします。（我来联系您。）
- お会いできて光栄です。（能见到您很荣幸。）

### お/ご + 动词连用形 + いたす

更谦虚的表达。

- お待ちいたしました。（我一直在等您。）
- ご説明いたします。（我来说明。）

### お/ご + 动词连用形 + する + ことができる

谦让语的可能形式。

- お手伝いすることができます。（我可以帮忙。）

## 谦让语的使用场景

### 商务场合

- 社長にご報告いたします。（我向社长报告。）
- 明日お伺いいたします。（明天我去拜访您。）
- 資料をお送りいたします。（我把资料发给您。）

### 电话用语

- 田中でございます。（我是田中。）
- 少々お待ちくださいませ。（请稍等。）
- 承知いたしました。（我知道了。）

### 邮件/书信

- ご連絡いただき、ありがとうございます。（感谢您的联系。）
- ご確認のほどよろしくお願いいたします。（请您确认。）

## 常见错误

### 避免过度使用谦让语

- ❌ 私は先生に教えていただきました。（不需要对自己的行为用谦让语来描述自己教老师）
- ✅ 先生に教わりました。

### 谦让语与尊敬语的区别

| 类型 | 对象 | 示例 |
|------|------|------|
| 尊敬语 | 抬高对方的动作 | 先生がおっしゃいました |
| 谦让语 | 贬低己方的动作 | 先生に申し上げました |

### 注意"おる"的使用

- おる是谦让语，不能用于描述对方。
- ❌ 先生は教室におられます。
- ✅ 先生は教室にいらっしゃいます。
