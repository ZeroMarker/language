# 英语同义词与反义词专题

## 常见同义词组

### 表示"好"的同义词

| 词 | 语体 | 含义侧重 |
|----|------|----------|
| good | 通用 | 好的 |
| excellent | 正式 | 极好的 |
| outstanding | 正式 | 杰出的 |
| wonderful | 通用 | 精彩的 |
| fantastic | 口语 | 太棒了 |
| terrific | 口语 | 非常好的 |
| superb | 正式 | 极佳的 |
| marvelous | 正式 | 非凡的 |

### 表示"说"的同义词

| 词 | 含义侧重 | 示例 |
|----|----------|------|
| say | 说（通用） | He said hello. |
| tell | 告诉（接人） | Tell me the truth. |
| speak | 讲话（正式） | She speaks English. |
| talk | 谈话（交流） | We need to talk. |
| mention | 提及 | He mentioned the idea. |
| state | 陈述（正式） | The report states that... |
| claim | 声称 | She claims to be innocent. |
| declare | 宣布 | The judge declared him guilty. |
| announce | 宣告 | They announced the winner. |
| whisper | 低语 | She whispered his name. |
| shout | 喊叫 | Don't shout at me! |
| mutter | 咕哝 | He muttered under his breath. |

### 表示"大"的同义词

| 词 | 含义侧重 |
|----|----------|
| big | 大（通用口语） |
| large | 大（通用正式） |
| huge | 巨大的 |
| enormous | 庞大的 |
| vast | 广阔的 |
| massive | 大而重的 |

| gigantic | 巨人般的 |

### 表示"小"的同义词

| 词 | 含义侧重 |
|----|----------|
| small | 小（通用） |
| little | 小的（带感情色彩） |
| tiny | 极小的 |
| miniature | 微型的 |
| compact | 紧凑的 |

### 表示"看"的同义词

| 词 | 含义侧重 | 示例 |
|----|----------|------|
| look | 看（不及物） | Look at this! |
| see | 看见（结果） | I can see the mountain. |
| watch | 观看（持续） | Watch the game. |
| observe | 观察（仔细） | Observe the experiment. |
| stare | 盯着看 | Stop staring at me. |
| glance | 扫一眼 | He glanced at his phone. |
| glimpse | 瞥见 | I glimpsed her in the crowd. |
| examine | 检查 | The doctor examined the patient. |

## 近义词辨析

| 词组 | 区别 |
|------|------|
| job / work | job 可数（a job）；work 不可数（some work） |
| see / watch / look | see 强调结果；watch 强调持续关注；look 强调动作 |
| big / large | big 偏口语；large 偏正式 |
| learn / study | learn 侧重结果（学会了）；study 侧重过程（在学习） |
| borrow / lend | borrow 借入；lend 借出 |
| speak / talk | speak 偏正式/单向；talk 偏口语/双向 |
| beautiful / pretty / handsome | beautiful 最强；pretty 多用于女性；handsome 多用于男性 |
| salary / wage | salary 月薪（白领）；wage 时薪/周薪（蓝领） |
