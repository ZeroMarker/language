# 英语文化背景

## 英式英语与美式英语差异

### 拼写差异

| 英式 | 美式 | 说明 |
|------|------|------|
| colour | color | -our → -or |
| favour | favor | -our → -or |
| honour | honor | -our → -or |
| centre | center | -re → -er |
| theatre | theater | -re → -er |
| metre | meter | -re → -er |
| organise | organize | -ise → -ize |
| realise | realize | -ise → -ize |
| analyse | analyze | -yse → -yze |
| travelling | traveling | 双写 l → 单写 l |
| cancelled | canceled | 双写 l → 单写 l |
| defence | defense | -ce → -se |
| licence | license | 名词 -ce / 动词 -se（美式统一 -se） |

### 发音差异

| 特征 | 英式 | 美式 |
|------|------|------|
| r 音 | 大多数不发音 | 所有 r 都发音 |
| 例词 | car /kɑː/ | car /kɑːr/ |
| 例词 | water /ˈwɔːtə/ | water /ˈwɔːtər/ |
| -ile | fertile /ˈfɜːtaɪl/ | fertile /ˈfɜːrtl/ |
| schedule | /ˈʃedjuːl/ | /ˈskedʒuːl/ |
| herb | /hɜːb/ | /ɜːrb/（h 不发音） |

### 语法差异

| 方面 | 英式 | 美式 |
|------|------|------|
| 集合名词 | The team **are** winning. | The team **is** winning. |
| have got | I**'ve got** a car. | I **have** a car. |
| 现在完成时 | I**'ve just** eaten. | I **just** ate. |
| 介词 | at the weekend | on the weekend |
| 介词 | different **to/from** | different **from/than** |

## 英语国家文化简介

### 主要英语国家

| 国家 | 官方语言 | 人口（约） | 特色 |
|------|----------|-----------|------|
| 美国 | 英语（无联邦官方语言） | 3.3 亿 | 多元文化、好莱坞 |
| 英国 | 英语 | 6700 万 | 英语发源地、君主制 |
| 加拿大 | 英语、法语 | 3800 万 | 双语国家、多元文化 |
| 澳大利亚 | 英语 | 2600 万 | 独特俚语、多元生态 |
| 新西兰 | 英语、毛利语 | 500 万 | 毛利文化 |
| 爱尔兰 | 英语、爱尔兰语 | 500 万 | 文学传统 |

### 文化礼仪

| 方面 | 说明 |
|------|------|
| 称呼 | 初次见面用 Mr./Ms. + 姓；熟后直呼其名 |
| 小费 | 美国餐厅通常给 15-20%；英国不强制 |
| 排队 | 英国人极其看重排队礼仪 |
| 闲聊 | "How are you?" 是寒暄，通常回答 "Fine, thanks" |
| 邮件 | 正式邮件以 Dear 开头，Best regards 结尾 |
