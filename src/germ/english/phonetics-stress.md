# 英语重音规则说明

## 基本概念

英语是**重音等时语言**（stress-timed language），重音在英语中起着至关重要的作用，可以改变词义或词性。

## 词重音（Word Stress）

### 重音标记

重音符号标在重读音节前：`ˈ` 表示主重音，`ˌ` 表示次重音。

- **ˈ**present（名词，礼物）→ 第一音节重读
- pre**ˈ**sent（动词，呈现）→ 第二音节重读

### 双音节词重音规则

| 规则 | 示例 |
|------|------|
| 大多数名词重音在第一音节 | **ˈ**table, **ˈ**student, **ˈ**window |
| 大多数动词重音在第二音节 | pre**ˈ**sent, re**ˈ**cord, a**ˈ**llow |
| 同形异重音词（名词前/动词后） | **ˈ**record / re**ˈ**cord, **ˈ**import / im**ˈ**port |

### 三音节词重音规则

| 词尾 | 重音位置 | 示例 |
|------|----------|------|
| -tion / -sion | 重音在其前一音节 | edu**ˈ**cation, de**ˈ**cision |
| -ic | 重音在其前一音节 | rea**ˈ**listic, fan**ˈ**tastic |
| -ity | 重音在其前一音节 | uni**ˈ**versity, elec**ˈ**tricity |
| -ous | 重音在其前一音节 | dan**ˈ**gerous, fa**ˈ**mous |
| -fy | 重音在其前一音节 | satis**ˈ**fy, beau**ˈ**tify |
| -al | 重音在其前一音节 | mu**ˈ**sical, na**ˈ**tional |

### 常见后缀对重音的影响

**重音在后缀前：**
- -ee: employ**ˈ**ee, refu**ˈ**gee
- -eer: engi**ˈ**neer, volun**ˈ**teer
- -ese: Japa**ˈ**nese, Portu**ˈ**guese
- -esque: pictu**ˈ**resque

**重音在后缀上（较少）：**
- -ade: lemo**ˈ**nade, masque**ˈ**rade

## 句重音（Sentence Stress）

### 基本原则

英语句子中，**实词**重读，**虚词**弱读。

| 类型 | 是否重读 | 示例 |
|------|----------|------|
| 名词 | 重读 | **book**, **table** |
| 动词（主要动词） | 重读 | **eat**, **run** |
| 形容词 | 重读 | **big**, **beautiful** |
| 副词 | 重读 | **quickly**, **very** |
| 疑问词 | 重读 | **what**, **where** |
| 冠词 | 弱读 | a, the |
| 介词 | 弱读 | in, on, at |
| 连词 | 弱读 | and, but, or |
| 代词 | 弱读 | he, she, it |
| 助动词 | 弱读 | is, are, have |

### 示例

- **ˈ**John **ˈ**went to the **ˈ**store.
- I **ˈ**want to **ˈ**buy a **ˈ**new **ˈ**book.
- She has **ˈ**been **ˈ**working **ˈ**hard.

## 重音改变词义

| 单词 | 名词（前重） | 动词（后重） |
|------|-------------|-------------|
| present | **ˈ**present（礼物） | pre**ˈ**sent（呈现） |
| record | **ˈ**record（记录） | re**ˈ**cord（录制） |
| object | **ˈ**object（物体） | ob**ˈ**ject（反对） |
| subject | **ˈ**subject（科目） | sub**ˈ**ject（使服从） |
| permit | **ˈ**permit（许可证） | per**ˈ**mit（允许） |
| conduct | **ˈ**conduct（行为） | con**ˈ**duct（指挥） |
| desert | **ˈ**desert（沙漠） | de**ˈ**sert（抛弃） |
| produce | **ˈ**produce（产品） | pro**ˈ**duce（生产） |

## 弱读形式（Weak Forms）

虚词在句子中通常弱读：

| 单词 | 强读 | 弱读 |
|------|------|------|
| a | /eɪ/ | /ə/ |
| the | /ðiː/ | /ðə/ |
| and | /ænd/ | /ənd/ 或 /ən/ |
| but | /bʌt/ | /bət/ |
| can | /kæn/ | /kən/ |
| have | /hæv/ | /həv/ 或 /əv/ |
| to | /tuː/ | /tə/ |
| for | /fɔː/ | /fə/ |
| was | /wɒz/ | /wəz/ |
| of | /ɒv/ | /əv/ |
