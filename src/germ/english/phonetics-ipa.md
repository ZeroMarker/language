# 英语音标规则详解

## 基本概念

英语使用国际音标（IPA, International Phonetic Alphabet）来标注发音。英语共有约 44 个音素：20 个元音 + 24 个辅音。

## 元音（Vowels）

### 短元音（Short Vowels）

| 音标 | 发音要点 | 示例单词 |
|------|----------|----------|
| /ɪ/ | 短促的"衣" | sit, bit, hit |
| /e/ | 短促的"诶" | bed, red, head |
| /æ/ | 开口"啊" | cat, hat, bad |
| /ɒ/ | 英式短"奥" | hot, dog, box |
| /ʌ/ | 短促的"啊" | cup, bus, love |
| /ʊ/ | 短促的"乌" | put, book, good |
| /ə/ | 中央元音（schwa） | about, sofa, the |

### 长元音（Long Vowels）

| 音标 | 发音要点 | 示例单词 |
|------|----------|----------|
| /iː/ | 长"衣" | see, eat, tree |
| /ɑː/ | 长"啊" | car, father, park |
| /ɔː/ | 长"奥" | door, four, call |
| /ɜː/ | 长"额" | bird, her, turn |
| /uː/ | 长"乌" | food, moon, blue |

### 双元音（Diphthongs）

| 音标 | 发音要点 | 示例单词 |
|------|----------|----------|
| /eɪ/ | 诶→衣 | day, make, rain |
| /aɪ/ | 啊→衣 | my, time, light |
| /ɔɪ/ | 奥→衣 | boy, coin, join |
| /aʊ/ | 啊→乌 | how, house, out |
| /əʊ/ | 额→乌 | go, home, boat |
| /ɪə/ | 衣→额 | near, here, beer |
| /eə/ | 诶→额 | air, hair, there |
| /ʊə/ | 乌→额 | tour, sure, pure |

## 辅音（Consonants）

### 爆破音（Plosives）

| 清辅音 | 浊辅音 | 示例 |
|--------|--------|------|
| /p/ | /b/ | **p**en / **b**en |
| /t/ | /d/ | **t**en / **d**en |
| /k/ | /g/ | **c**at / **g**et |

### 摩擦音（Fricatives）

| 清辅音 | 浊辅音 | 示例 |
|--------|--------|------|
| /f/ | /v/ | **f**an / **v**an |
| /θ/ | /ð/ | **th**ink / **th**is |
| /s/ | /z/ | **s**eal / **z**eal |
| /ʃ/ | /ʒ/ | **sh**e / vi**si**on |
| /h/ | — | **h**at |

### 破擦音（Affricates）

| 清辅音 | 浊辅音 | 示例 |
|--------|--------|------|
| /tʃ/ | /dʒ/ | **ch**ur**ch** / **j**udge |

### 鼻音（Nasals）

| 音标 | 示例 |
|------|------|
| /m/ | **m**an |
| /n/ | **n**o |
| /ŋ/ | si**ng**, thi**nk** |

### 侧音与近音

| 音标 | 示例 |
|------|------|
| /l/ | **l**ike |
| /r/ | **r**ed（英语 r 不卷舌或微卷） |
| /w/ | **w**et |
| /j/ | **y**es |

## 字母与发音对应规则

### 常见字母组合发音

| 字母组合 | 发音 | 示例 |
|----------|------|------|
| ch | /tʃ/ | chair, church |
| sh | /ʃ/ | she, shop |
| th | /θ/ 或 /ð/ | think (清), this (浊) |
| ph | /f/ | phone, photo |
| wh | /w/（大多数） | what, when |
| ck | /k/ | back, clock |
| ng | /ŋ/ | sing, ring |
| gh | 不发音 / /f/ | night (不发音), laugh (/f/) |

### 元音字母在开音节与闭音节中的发音

| 类型 | 规则 | 示例 |
|------|------|------|
| 开音节 | 元音字母发字母本身的音 | a→/eɪ/ (name), i→/aɪ/ (like) |
| 闭音节 | 元音字母发短音 | a→/æ/ (cat), i→/ɪ/ (sit) |
