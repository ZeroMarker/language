# 德语动词变位表

## 基本概念

德语动词根据人称、数、时态和语气进行变位。动词词干 + 人称词尾构成变位形式。

## 人称词尾（现在时 Präsens）

| 人称 | 词尾 | 示例 (machen) |
|------|------|---------------|
| ich | -e | mach**e** |
| du | -st | mach**st** |
| er/sie/es | -t | mach**t** |
| wir | -en | mach**en** |
| ihr | -t | mach**t** |
| sie/Sie | -en | mach**en** |

## 完成时（Perfekt）

构成：**haben / sein**（现在时）+ **过去分词**

### 过去分词构成

| 类型 | 构成 | 示例 |
|------|------|------|
| 规则动词 | ge- + 词干 + -t | machen → ge**mach**t |
| 以 -ieren 结尾 | 词干 + -t（无 ge-） | studieren → studier**t** |
| 可分动词 | ge- 插入可分前缀后 | aufstehen → auf**ge**standen |
| 不规则动词 | ge- + 词干（元音变化）+ -en | schreiben → ge**schrieb**en |

### 用 haben 还是 sein？

| 用 sein | 用 haben |
|---------|----------|
| 表示位置移动的不及物动词 | 及物动词（有第四格宾语） |
| gehen, kommen, fahren, fliegen | machen, kaufen, lesen, schreiben |
| 表示状态变化的不及物动词 | 情态动词 |
| werden, sterben, einschlafen | können, müssen, wollen |
| sein, bleiben | haben |
