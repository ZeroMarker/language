# 德语可分动词用法

## 基本概念

可分动词（trennbare Verben）由**前缀 + 动词词干**组成。在简单句中，前缀与词干分离，前缀移至句末。

## 常见可分前缀

| 前缀 | 含义 | 示例动词 |
|------|------|----------|
| ab- | 离开、下降 | abfahren（出发）, abnehmen（减少） |
| an- | 朝向、开始 | ankommen（到达）, anfangen（开始） |
| auf- | 向上、打开 | aufstehen（起床）, aufmachen（打开） |
| aus- | 出去、结束 | ausgehen（外出）, ausmachen（关掉） |
| bei- | 附带 | beibringen（教会）, beitragen（贡献） |
| ein- | 进入 | einkaufen（购物）, einsteigen（上车） |
| fest- | 固定 | feststellen（确定）, festhalten（抓住） |
| her- | 向说话者来 | herkommen（过来）, herstellen（生产） |
| hin- | 向远处去 | hingehen（去那边）, hinsetzen（坐下） |
| los- | 开始、离开 | losgehen（出发）, loslassen（放手） |
| mit- | 一起 | mitkommen（一起来）, mitnehmen（带走） |
| nach- | 跟随、之后 | nachdenken（思考）, nachschlagen（查阅） |
| statt- | 发生 | stattfinden（举行） |
| vor- | 向前、提前 | vorstellen（介绍）, vorbereiten（准备） |
| weg- | 离开 | weggehen（走开）, wegwerfen（扔掉） |
| zu- | 关闭、朝向 | zumachen（关闭）, zunehmen（增加） |
| zurück- | 返回 | zurückkommen（回来）, zurückgeben（归还） |
| zusammen- | 一起 | zusammenarbeiten（合作）, zusammenkommen（聚集） |

## 变位规则

### 现在时（Präsens）

前缀分离，移至句末：

- Ich **stehe** um 7 Uhr **auf**.（我7点起床。）
- Er **kommt** um 8 Uhr **an**.（他8点到达。）
- Wir **fangen** jetzt **an**.（我们现在开始。）

### 过去时（Präteritum）

前缀分离，词干加过去时词尾：

- Ich **stand** um 7 Uhr **auf**.
- Er **kam** um 8 Uhr **an**.

### 完成时（Perfekt）

ge- 插入前缀与词干之间：

| 动词 | 过去分词 | 示例 |
|------|----------|------|
| aufstehen | auf**ge**standen | Ich **bin** auf**ge**standen. |
| ankommen | an**ge**kommen | Er **ist** an**ge**kommen. |
| einkaufen | ein**ge**kauft | Wir **haben** ein**ge**kauft. |
| zumachen | zu**ge**macht | Er **hat** die Tür zu**ge**macht. |
| mitnehmen | mit**ge**nommen | Ich **habe** das Buch mit**ge**nommen. |

### 命令式

前缀移至句末：

- **Steh** auf!（起床！）
- **Mach** die Tür zu!（关门！）
- **Komm** mit!（一起来！）
- **Fang** an!（开始！）

## 不可分前缀

以下前缀**永远不分离**，且完成时不加 ge-：

| 前缀 | 示例动词 | 过去分词 |
|------|----------|----------|
| be- | besuchen（拜访） | besucht |
| emp- | empfehlen（推荐） | empfohlen |
| ent- | entscheiden（决定） | entschieden |
| er- | erzählen（讲述） | erzählt |
| ge- | gehören（属于） | gehört |
| miss- | missverstehen（误解） | missverstanden |
| ver- | verstehen（理解） | verstanden |
| zer- | zerbrechen（打碎） | zerbrochen |

## 可分/不可分双重前缀

有些前缀既可分又不可分，含义不同：

| 前缀 | 可分（字面义） | 不可分（引申义） |
|------|---------------|-----------------|
| um- | um**ziehen**（搬家） | um**ziehen**（换衣服） |
| über- | über**setzen**（摆渡） | über**setzen**（翻译） |
| unter- | unter**gehen**（下沉） | unter**gehen**（落山） |
| wider- | — | wider**sprechen**（反对） |
| wieder- | wieder**kommen**（再来） | — |

### 判断方法

- 重音在前缀上 → 可分
- 重音在词干上 → 不可分

## 带 zu 的不定式

可分动词中，zu 插入前缀与词干之间：

- Ich vergesse, die Tür **zuzumachen**.（我忘了关门。）
- Er versprach, pünktlich **anzukommen**.（他承诺准时到达。）
- Es ist schwer, früh **aufzustehen**.（早起很难。）

对比不可分动词：zu 在前缀前：
- Ich hoffe, dich **zu besuchen**.（我希望拜访你。）
