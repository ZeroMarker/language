# 德语常用谚语与习语

## 常见谚语（Sprichwörter）

| 德语 | 中文含义 |
|------|----------|
| Übung macht den Meister. | 熟能生巧。 |
| Wer rastet, der rostet. | 刀不磨要锈，人不学要落后。 |
| Aller Anfang ist schwer. | 万事开头难。 |
| Morgenstund hat Gold im Mund. | 一日之计在于晨。 |
| Ende gut, alles gut. | 结局好，一切都好。 |
| Was du heute kannst besorgen, das verschiebe nicht auf morgen. | 今日事今日毕。 |
| Wie man in den Wald hineinruft, so schallt es heraus. | 种瓜得瓜，种豆得豆。 |
| Es ist nicht alles Gold, was glänzt. | 闪光的不一定是金子。 |
| Keine Rose ohne Dornen. | 没有不带刺的玫瑰。（有得必有失） |
| Besser spät als nie. | 迟到总比不到好。 |
| Der Apfel fällt nicht weit vom Stamm. | 有其父必有其子。 |
| Man soll den Tag nicht vor dem Abend loben. | 不要高兴得太早。 |

## 常见习语（Redewendungen）

### 与身体相关的习语

| 德语 | 字面意思 | 实际含义 |
|------|----------|----------|
| die Daumen drücken | 按拇指 | 祝好运 |
| sich etwas aus den Fingern saugen | 从手指里吸出来 | 凭空捏造 |
| jm. auf den Füßen stehen | 站在某人脚上 | 碍事、打扰 |
| den Kopf verlieren | 丢掉脑袋 | 惊慌失措 |
| die Nase voll haben | 鼻子满了 | 受够了 |
| sich in die Haare geraten | 进入头发里 | 争吵起来 |
| ein Auge zudrücken | 闭一只眼 | 睁一只眼闭一只眼 |
| um den heißen Brei herumreden | 围着热粥说话 | 拐弯抹角 |
| jm. auf die Sprünge helfen | 帮某人跳 | 帮助某人想起某事 |
| Hals- und Beinbruch | 脖子和腿骨折 | 祝好运（类似 break a leg） |

### 与动物相关的习语

| 德语 | 字面意思 | 实际含义 |
|------|----------|----------|
| die Katze im Sack kaufen | 袋子里买猫 | 盲目购买 |
| jm. einen Bären aufbinden | 给某人绑一头熊 | 骗某人 |
| Da liegt der Hund begraben. | 狗埋在那里。 | 问题的关键在这里。 |
| Schwein haben | 有猪 | 走运 |
| eine Eier legende Wollmilchsau | 下蛋的产毛奶猪 | 万能的东西 |
| sich wie ein Elefant im Porzellanladen benehmen | 像瓷器店里的大象 | 举止粗鲁 |
| Eselsbrücke | 驴桥 | 助记法 |

### 与食物相关的习语

| 德语 | 字面意思 | 实际含义 |
|------|----------|----------|
| Butter bei die Fische! | 黄油放到鱼上！ | 别废话了，说重点！ |
| jm. Honig um den Mund schmieren | 在嘴边涂蜂蜜 | 拍马屁 |
| Das ist nicht mein Brot. | 这不是我的面包。 | 这不是我的专长。 |
| Tomaten auf den Augen haben | 眼睛上有番茄 | 视而不见 |
| Alles hat ein Ende, nur die Wurst hat zwei. | 万物有终，只有香肠有两头。 | 天下没有不散的宴席。 |
| jdn. durch den Kakao ziehen | 把某人拉过可可 | 戏弄某人 |

### 表达情感与状态

| 德语 | 含义 | 示例 |
|------|------|------|
| auf Wolke sieben schweben | 飘在第七朵云上 | 非常幸福 |
| Die Daumen drücken | 按拇指 | 祝好运 |
| auf dem Zahnfleisch kriechen | 用牙龈爬行 | 精疲力竭 |
| den inneren Schweinehund überwinden | 克服内心的猪狗 | 克服惰性 |
| einen Kater haben | 有一只公猫 | 宿醉 |
| Gift und Galle spucken | 吐毒和胆汁 | 非常愤怒 |
| einen dicken Hals kriegen | 脖子变粗 | 非常生气 |
| jm. geht eine Licht auf | 某人的灯亮了 | 某人恍然大悟 |

### 表达行为与态度

| 德语 | 含义 |
|------|------|
| jm. freie Hand lassen | 给某人自由的手 → 让某人自行决定 |
| alle Fäden in der Hand halten | 手握所有线 → 掌控全局 |
| den Nagel auf den Kopf treffen | 钉子钉在头上 → 一针见血 |
| Öl ins Feuer gießen | 往火里浇油 → 火上浇油 |
| jm. eine Extrawurst braten | 给某人烤一根特别的香肠 → 给某人特殊待遇 |
| den Wald vor lauter Bäumen nicht sehen | 树太多看不见森林 → 一叶障目 |
| auf dem Holzweg sein | 在木头路上 → 走错路了 |

## 使用建议

- 德语习语在口语中使用频率很高
- 理解习语需要了解德国文化背景
- 习语不可逐字翻译
- 在正式写作中适度使用
