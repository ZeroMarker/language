# 印尼语阅读练习材料

## 初级阅读

### 短文 1：自我介绍

> Nama saya Budi. Saya tinggal di Jakarta. Saya berumur dua puluh lima tahun. Saya bekerja di sebuah kantor. Saya suka membaca buku dan mendengarkan musik.

**词汇表**

| 印尼语 | 中文 |
|--------|------|
| nama | 名字 |
| tinggal | 居住 |
| berumur | 年龄 |
| bekerja | 工作 |
| kantor | 办公室 |
| suka | 喜欢 |
| membaca | 阅读 |
| mendengarkan | 听 |

**理解问题**
1. Siapa nama orang itu?（那人叫什么名字？）
2. Di mana dia tinggal?（他住在哪里？）
3. Apa yang dia suka?（他喜欢什么？）

### 短文 4：巴厘岛旅游

> Bali adalah salah satu pulau terindah di Indonesia. Banyak wisatawan dari seluruh dunia mengunjungi Bali setiap tahun. Pantai Kuta terkenal untuk surfing. Ubud terkenal untuk seni dan budaya. Pengunjung juga dapat melihat sawah terasering yang indah. Makanan Bali sangat pedas dan lezat.

## 阅读技巧

1. **先读标题**：了解主题
2. **找关键词**：人名、地名、数字
3. **根据上下文猜测**：不确定的词先跳过
4. **多次阅读**：第一遍通读，第二遍精读
5. **做笔记**：记录生词和重要信息
