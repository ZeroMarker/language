# 印尼语被动语态结构

印尼语有两种被动语态，分别使用 **di-** 和 **oleh** 结构，使用频率都很高。

## 两种被动语态

### 1. di- 被动（对象焦点被动）

结构：**di- + 动词词根**（+ oleh 施事者）

| 主动 | 被动 | 含义 |
|------|------|------|
| Saya makan nasi. | Nasi dimakan (oleh saya). | 我吃饭。→ 饭被（我）吃了。 |
| Ibu memasak ikan. | Ikan dimasak (oleh ibu). | 妈妈做鱼。→ 鱼被（妈妈）做了。 |
| Dia menulis surat. | Surat ditulis (oleh dia). | 他写信。→ 信被（他）写了。 |
| Guru mengajar murid. | Murid diajar (oleh guru). | 老师教学生。→ 学生被（老师）教。 |

特点：
- 施事者（oleh + 人）可以省略
- 动词保持 di- 前缀形式
- 宾语提前作主语

### 2. ter- 被动（意外/状态被动）

结构：**ter- + 动词词根**

| 示例 | 含义 |
|------|------|
| Pintu terbuka. | 门开了（意外地/自然地）。 |
| Kaca pecah → Kaca terpecah. | 玻璃碎了（意外地）。 |
| Dia terjatuh. | 他摔倒了（不小心）。 |
| Surat itu tertulis dalam bahasa Inggris. | 那封信是用英语写的（状态）。 |

### 3. 主语 + 动词 + oleh + 宾语（施事焦点被动）

结构：**主语 + 动词 + oleh + 施事者**

| 示例 | 含义 |
|------|------|
| Buku itu saya baca. | 那本书我读了。 |
| Nasi ibu masak. | 妈妈做的饭。 |

这种结构中，动词不加 di-，但主语是受事者。

## 被动语态的时态表达

| 时态 | 结构 | 示例 |
|------|------|------|
| 现在 | sedang + di- + 动词 | Surat sedang ditulis.（信正在被写。） |
| 完成 | sudah + di- + 动词 | Surat sudah ditulis.（信已经被写了。） |
| 将要 | akan + di- + 动词 | Surat akan ditulis.（信将要被写。） |
| 否定 | tidak + di- + 动词 | Surat tidak ditulis.（信没有被写。） |

## 使用场景

- **正式/书面语**：di- 被动更常见
- **强调结果**：ter- 被动用于意外或状态
- **口语**：有时省略被动标记，用语序表达
