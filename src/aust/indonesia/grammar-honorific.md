# 印尼语敬语层级说明

印尼语虽然没有像日语那样严格的敬语系统，但在社会交往中仍有一定的礼貌层级和称谓规范。

## 代词的敬语层级

| 普通/亲密 | 礼貌/正式 | 含义 |
|-----------|-----------|------|
| kamu | Anda | 你（您） |
| aku | saya | 我 |
| kau | - | 你（文学/诗歌） |
| dia | beliau | 他/她（beliau 更尊敬） |

## 称谓系统

### 家庭称谓

| 称谓 | 含义 | 用法 |
|------|------|------|
| Bapak / Pak | 父亲/先生 | 称呼年长男性、上级 |
| Ibu / Bu | 母亲/女士 | 称呼年长女性、上级 |
| Kak / Kakak | 哥哥/姐姐 | 称呼稍年长者 |
| Adik | 弟弟/妹妹 | 称呼年幼者 |
| Om / Tante | 叔叔/阿姨 | 称呼父母的朋友 |

### 职业/社会称谓

| 称谓 | 含义 |
|------|------|
| Pak Guru | 老师先生 |
| Bu Dokter | 医生女士 |
| Pak Direktur | 董事先生 |

## 句末礼貌用语

| 表达 | 功能 | 示例 |
|------|------|------|
| -lah | 软化语气 | Makanlah.（请吃吧。） |
| ya | 表示确认/礼貌 | Benar ya?（对吗？） |
| mohon | 正式请求 | Mohon bantuannya.（恳请帮助。） |
| tolong | 请求帮助 | Tolong buka pintu.（请开门。） |
| silakan | 邀请 | Silakan duduk.（请坐。） |

## 礼貌层级的实际应用

### 正式场合
- 使用 **Anda** 代替 **kamu**
- 使用 **saya** 代替 **aku**
- 使用 **Bapak/Ibu** 称呼对方
- 使用 **mohon** 代替 **tolong**

### 非正式场合
- 使用 **kamu/aku**
- 直接用名字称呼
- 使用 **tolong** 或直接命令

## 区域差异

- **爪哇语影响**：在爪哇岛，敬语层级更复杂，受爪哇语影响
- **巽他语影响**：在西爪哇，有更细致的称谓系统
- **巴厘语影响**：在巴厘岛，有高低语体之分
- **现代趋势**：年轻人中 Anda 使用减少，更常用 kamu
