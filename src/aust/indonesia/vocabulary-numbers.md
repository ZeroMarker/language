# 印尼语数字与计数系统

## 基本数词

| 数字 | 印尼语 | 发音提示 |
|------|--------|---------|
| 0 | nol / kosong | 诺尔 / 可松 |
| 1 | satu | 萨图 |
| 2 | dua | 杜阿 |
| 3 | tiga | 蒂加 |
| 4 | empat | 恩帕特 |
| 5 | lima | 利马 |
| 6 | enam | 厄南 |
| 7 | tujuh | 图朱 |
| 8 | delapan | 德拉潘 |
| 9 | sembilan | 森比兰 |
| 10 | sepuluh | 瑟普鲁 |

## 十位数

| 数字 | 印尼语 |
|------|--------|
| 10 | sepuluh |
| 20 | dua puluh |
| 30 | tiga puluh |
| 40 | empat puluh |
| 50 | lima puluh |
| 60 | enam puluh |
| 70 | tujuh puluh |
| 80 | delapan puluh |
| 90 | sembilan puluh |

## 组合示例

- 11 = sebelas（特殊形式）
- 12 = dua belas
- 21 = dua puluh satu
- 35 = tiga puluh lima
- 99 = sembilan puluh sembilan

## 百、千、万、十万、百万

| 单位 | 印尼语 | 示例 |
|------|--------|------|
| 百 | ratus | seratus（一百） |
| 千 | ribu | seribu（一千） |
| 万 | puluh ribu | sepuluh ribu（一万） |
| 十万 | ratus ribu | seratus ribu（十万） |
| 百万 | juta | sejuta（一百万） |

## 大数示例

- 256 = dua ratus lima puluh enam
- 1,000 = seribu
- 3,500 = tiga ribu lima ratus
- 10,000 = sepuluh ribu
- 100,000 = seratus ribu
- 1,000,000 = sejuta

## 序数词

在数词前加 **ke-** 构成序数词：

| 序数 | 印尼语 |
|------|--------|
| 第一 | pertama（特殊） |
| 第二 | kedua |
| 第三 | ketiga |
| 第四 | keempat |
| 第五 | kelima |
| 第十 | kesepuluh |

## 小数和分数

- 小数用 **koma**：3,14 = tiga koma empat belas
- 分数：½ = setengah，⅓ = sepertiga，¼ = seperempat

## 货币计数

印尼盾（Rupiah）常用缩写 Rp：
- Rp 10.000 = sepuluh ribu rupiah
- Rp 100.000 = seratus ribu rupiah
- Rp 1.000.000 = sejuta rupiah

注意：印尼用句点（.）作千位分隔符，用逗号（,）作小数点。
