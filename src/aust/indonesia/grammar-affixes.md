# 印尼语词缀系统详解

印尼语属于黏着语，通过在词根上添加前缀、后缀、中缀和环绕缀来改变词义和词性。这是印尼语语法的核心。

## 前缀 (Awalan)

| 前缀 | 功能 | 词根 → 派生词 | 含义 |
|------|------|---------------|------|
| meN- | 构成主动动词 | tulis → menulis | 写 → 正在写 |
| peN- | 构成施事名词 | tulis → penulis | 写 → 作家 |
| ber- | 构成不及物动词/状态 | jalan → berjalan | 路 → 行走 |
| ter- | 表示意外/最高级 | baik → terbaik | 好 → 最好的 |
| ke- | 构成序数词/抽象名词 | tiga → ketiga | 三 → 第三 |
| se- | 表示"同一/一" | hari → sehari | 天 → 一天 |
| di- | 构成被动语态 | tulis → ditulis | 写 → 被写 |

## 后缀 (Akhiran)

| 后缀 | 功能 | 词根 → 派生词 | 含义 |
|------|------|---------------|------|
| -kan | 使动/及物化 | besar → besarkan | 大 → 放大 |
| -i | 反复/地点动作 | air → airi | 水 → 浇水 |
| -an | 名词化 | makan → makanan | 吃 → 食物 |

## 中缀 (Sisipan)

| 中缀 | 功能 | 词根 → 派生词 | 含义 |
|------|------|---------------|------|
| -el- | 名词化 | tunjuk → telunjuk | 指 → 食指 |
| -em- | 名词化 | guruh → gemuruh | 雷 → 轰鸣声 |
| -er- | 名词化 | gigih → geregih | 坚韧 → 颤抖 |

## 环绕缀 (Apitan)

| 环绕缀 | 功能 | 词根 → 派生词 | 含义 |
|--------|------|---------------|------|
| ke-...-an | 抽象名词/过度 | besar → kebesaran | 大 → 伟大/太大 |
| peN-...-an | 施事/工具名词 | tanam → penanaman | 种 → 种植（行为） |
| ber-...-an | 互相/反复 | tumbuk → bertumbukan | 撞 → 互相碰撞 |
| per-...-an | 使动名词化 | tanya → pertanyaan | 问 → 问题 |

## meN- 前缀的音变规则

meN- 在不同首字母前会发生音变：

| 词根首字母 | meN- 形式 | 示例 |
|-----------|-----------|------|
| p | mem- (p消失) | pukul → memukul |
| t | men- (t消失) | tulis → menulis |
| k | meng- (k消失) | kirim → mengirim |
| s | meny- (s消失) | sapu → menyapu |
| b, d, g, j, v, w, y, z, 元音 | meng- | baca → membaca |
| m, n, ny, ng, l, r, h, c | me- | masak → memasak |

## 常见组合模式

- **meN- + -kan**：使动主动动词，如 *menuliskan*（为…写）
- **meN- + -i**：反复主动动词，如 *menulisi*（在…上写）
- **di- + -kan**：使动被动，如 *dituliskan*（被写出来）
- **peN- + -an**：行为名词，如 *penulisan*（写作过程）
