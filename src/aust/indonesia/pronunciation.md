# 印尼语系统发音规则

印尼语使用拉丁字母书写，发音规则相对规律，比英语简单得多。

## 字母表与发音

| 字母 | 发音 | 说明 |
|------|------|------|
| a | /a/ | 如"啊" |
| b | /b/ | 如"波" |
| c | /tʃ/ | 如"七"的声母 |
| d | /d/ | 如"德" |
| e | /ə/ 或 /e/ | 弱读为 /ə/（如"额"），重读为 /e/（如"诶"） |
| f | /f/ | 如"佛" |
| g | /g/ | 如"哥" |
| h | /h/ | 如"喝" |
| i | /i/ | 如"衣" |
| j | /dʒ/ | 如"知" |
| k | /k/ | 词尾不送气，如"哥" |
| l | /l/ | 如"勒" |
| m | /m/ | 如"摸" |
| n | /n/ | 如"呢" |
| ny | /ɲ/ | 如"尼"（腭鼻音） |
| ng | /ŋ/ | 如"嗯"的韵尾 |
| o | /o/ | 如"哦" |
| p | /p/ | 不送气，如"玻" |
| q | /q/ | 阿拉伯语借词中出现 |
| r | /r/ | 弹舌音，舌尖颤动 |
| s | /s/ | 如"丝" |
| t | /t/ | 不送气，如"德" |
| u | /u/ | 如"乌" |
| v | /v/ | 外来词 |
| w | /w/ | 如"乌" |
| x | /ks/ | 外来词 |
| y | /j/ | 如"呀"的声母 |
| z | /z/ | 外来词 |

## 特殊组合

| 组合 | 发音 | 示例 |
|------|------|------|
| ai | /ai/ | seperti /səˈpaɾti/ |
| au | /au/ | pulau /pulau/ |
| oi | /oi/ | amboi（感叹词） |

## 重音规则

- 重音通常落在**倒数第二个音节**
- 双音节词：**ma**kan, **mi**num
- 三音节词：me**nu**lis, pe**la**jar
- 前缀和后缀不影响重音位置

## 音节结构

印尼语音节结构为 (C)V(C)：
- V：元音（a, i, u, e, o）
- CV：辅音+元音（ma, di, ka）
- VC：元音+辅音（an, in, on）
- CVC：辅音+元音+辅音（man, din, kat）

## 词尾辅音

词尾辅音发音较轻：
- **-k**：不送气，如"哥"
- **-p**：不送气，如"玻"
- **-t**：不送气，如"德"
- **-ng**：鼻音，如"嗯"
- **-n**：鼻音，如"呢"
- **-m**：鼻音，如"摸"
- **-r**：弹舌音

## 常见发音错误

1. **c 发 /tʃ/ 不是 /k/**：cinta（爱）读"亲达"，不是"kin达"
2. **e 有两种发音**：
   - 弱读 /ə/：me-前缀、-kan后缀中的 e
   - 重读 /e/：独立音节中的 e
3. **词尾辅音不送气**：t、p、k 在词尾不送气
4. **r 要弹舌**：不能读成英语的 r

## 练习建议

1. 先掌握元音 a, i, u, e, o 的发音
2. 练习 c, j, ny, ng 的特殊发音
3. 注意词尾辅音的轻读
4. 多听 native speaker 的发音
