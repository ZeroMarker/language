# 印尼语常用谚语与习语

## 常用谚语 (Peribahasa)

| 印尼语 | 直译 | 含义 |
|--------|------|------|
| Ada udang di balik batu. | 石头后面有虾。 | 别有用心 |
| Bagai air di daun talas. | 像芋头叶上的水。 | 不稳定/不坚定 |
| Berat sama dipikul, ringan sama dijinjing. | 重的一起扛，轻的一起提。 | 同甘共苦 |
| Di mana bumi dipijak, di situ langit dijunjung. | 脚踏何方，天顶何方。 | 入乡随俗 |
| Genggam bara api, biar sampai jadi arang. | 握住火炭，直到变成炭。 | 坚持到底 |
| Harapkan pagar, pagar makan paga. | 指望篱笆，篱笆却吃篱笆。 | 事与愿违 |
| Ibarat katak dalam tempurung. | 像椰壳里的青蛙。 | 井底之蛙 |
| Jangan menepuk air di dulang, terpercik muka sendiri. | 别拍托盘里的水，会溅到自己脸上。 | 自找麻烦 |
| Kalau takut dilambung ombak, jangan berumah di tepi pantai. | 怕被浪打，就别住海边。 | 要有担当 |
| Lain ladang lain belalang, lain lubuk lain ikannya. | 不同田不同蝗虫，不同潭不同鱼。 | 各有特色 |

## 常用习语 (Idiom)

| 印尼语 | 直译 | 实际含义 |
|--------|------|---------|
| air muka | 水面 | 面子/表情 |
| angkat tangan | 举手 | 认输/放弃 |
| buang air | 扔水 | 上厕所 |
| buang muka | 扔脸 | 不理睬 |
| cuci mata | 洗眼睛 | 观光/看热闹 |
| hujan emas | 金雨 | 好运气 |
| kena batunya | 碰到石头 | 遇到困难 |
| lepas tangan | 松手 | 撒手不管 |
| mulut manis | 甜嘴 | 说话好听 |
| panjang tangan | 长手 | 手不干净/偷窃 |
| pegang kata | 握住话 | 信守承诺 |
| pusing tujuh keliling | 转七圈 | 晕头转向 |
| simpan mulut | 收起嘴 | 保守秘密 |
| tangan besi | 铁手 | 铁腕/强硬手段 |

## 语气词与感叹词

| 印尼语 | 用法 | 示例 |
|--------|------|------|
| wah | 惊叹 | Wah, bagus sekali!（哇，太棒了！） |
| aduh | 疼痛/惊讶 | Aduh, sakit!（哎呀，疼！） |
| astaga | 惊讶 | Astaga!（天哪！） |
| ya ampun | 无奈 | Ya ampun, macet lagi!（天啊，又堵车了！） |
| celaka | 坏事 | Celaka!（糟糕！） |
| syukurlah | 庆幸 | Syukurlah kamu selamat.（幸好你平安。） |
