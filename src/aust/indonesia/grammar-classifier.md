# 印尼语量词专题

印尼语在数词和名词之间需要使用量词（kata bilangan），类似中文的"个、只、条"。

## 常用量词

| 量词 | 适用对象 | 示例 |
|------|---------|------|
| buah | 大件物品、车辆、建筑、岛屿、书 | dua buah buku（两本书） |
| orang | 人 | tiga orang murid（三个学生） |
| ekor | 动物 | seekor kucing（一只猫） |
| batang | 长条物（笔、棍、烟） | sebatang pensil（一支铅笔） |
| lembar | 薄片物（纸、布） | selembar kertas（一张纸） |
| biji | 小圆物（水果、鸡蛋、种子） | sebutir telur（一个鸡蛋） |
| butir | 小颗粒物（米、珠子） | segenggam beras（一把米） |
| gelas | 用杯量 | segelas air（一杯水） |
| botol | 用瓶量 | sebotol susu（一瓶牛奶） |
| piring | 用盘量 | sepiring nasi（一盘饭） |
| mangkuk | 用碗量 | semangkuk sup（一碗汤） |
| potong | 切割物（面包、蛋糕） | sepotong kue（一块蛋糕） |
| helai | 极薄物（头发、叶子） | sehelai rambut（一根头发） |
| pasang | 成对物（鞋、袜子） | sepasang sepatu（一双鞋） |
| rangkai | 串/束（花、珠子） | serangkai bunga（一束花） |
| tusuk | 串状（烤串） | sate tusuk（一串沙爹） |

## 数词 + 量词结构

结构：**数词 + 量词 + 名词**

| 示例 | 含义 |
|------|------|
| sebuah mobil | 一辆车 |
| dua orang guru | 两位老师 |
| tiga ekor ikan | 三条鱼 |
| empat batang rokok | 四根烟 |
| lima lembar surat | 五封信 |

## 注意事项

1. **se-（一）和 satu 的区别**：se- 是前缀形式，直接加在量词前；satu 是独立数词，通常用于强调或精确计数。
2. **量词可省略**：在口语中，量词有时可以省略，但正式用法中建议保留。
3. **重复表复数**：量词本身可重复表示"每"，如 *seorang-seorang*（每个人）。
4. **非标准量词**：口语中常用 *bijir* 代替 *butir*，用 *biji* 泛指小物件。
