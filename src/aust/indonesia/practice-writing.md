# 印尼语写作练习指导

## 写作基础

### 句子结构

印尼语基本语序：**主语 + 谓语 + 宾语 (SVO)**

| 类型 | 结构 | 示例 |
|------|------|------|
| 肯定句 | S + V + O | Saya makan nasi.（我吃饭。） |
| 否定句 | S + tidak + V + O | Saya tidak makan nasi.（我不吃饭。） |
| 疑问句 | Apakah + S + V + O? | Apakah kamu makan nasi?（你吃饭吗？） |
| 特殊疑问句 | 疑问词 + S + V + O? | Apa yang kamu makan?（你吃什么？） |

### 常用连接词

| 连接词 | 含义 | 示例 |
|--------|------|------|
| dan | 和 | Saya makan dan minum. |
| atau | 或 | Mau kopi atau teh? |
| tetapi / tapi | 但是 | Saya mau, tapi tidak bisa. |
| karena | 因为 | Saya lapar karena belum makan. |
| jadi | 所以 | Hujan, jadi saya di rumah. |
| jika / kalau | 如果 | Kalau hujan, saya di rumah. |
| ketika / saat | 当...时 | Ketika kecil, saya di Jakarta. |
| setelah | 在...之后 | Setelah makan, saya tidur. |
| sebelum | 在...之前 | Sebelum tidur, saya baca buku. |

## 练习任务

### 任务 1：自我介绍（初级）

**要求**：写一段 5-8 句话的自我介绍，包括：
- 名字
- 年龄
- 居住地
- 职业/学生
- 爱好

**参考句型**：
- Nama saya...
- Saya berumur... tahun.
- Saya tinggal di...
- Saya bekerja di... / Saya belajar di...
- Saya suka...

### 任务 2：描述日常生活（初级）

**要求**：写一段 8-10 句话描述你的一天

**参考词汇**：
- bangun (起床), mandi (洗澡), sarapan (早餐)
- bekerja (工作), makan siang (午餐), pulang (回家)
- makan malam (晚餐), tidur (睡觉)

### 任务 3：写信/邮件（中级）

**要求**：给朋友写一封简短的信（10-15 句话），包括：
- 问候
- 近况
- 邀请或请求
- 结束语

**参考格式**：
> Jakarta, 1 Januari 2024
>
> Hallo Budi,
>
> Apa kabar? Saya harap kamu baik-baik saja...
>
> Salam,
> [Nama]

### 任务 4：描述图片（中级）

**要求**：看一张图片，写 10 句话描述图片中的内容

**参考句型**：
- Di gambar ini, ada...
- Orang itu sedang...
- Di sebelah kiri/kanan, ada...
- Gambar ini diambil di...

### 任务 5：议论文（高级）

**要求**：选择一个话题，写一篇 15-20 句话的短文

**话题建议**：
- Keuntungan dan kerugian media sosial（社交媒体的利弊）
- Pentingnya belajar bahasa asing（学习外语的重要性）
- Cara menjaga lingkungan（保护环境的方法）

## 写作检查清单

- [ ] 句子结构是否正确（SVO）
- [ ] 时态标记是否准确（sedang, sudah, akan）
- [ ] 否定词是否正确（tidak/bukan）
- [ ] 连接词使用是否恰当
- [ ] 标点符号是否正确
- [ ] 拼写是否正确

## 常见写作错误

1. **主语遗漏**：印尼语有时可省略主语，但正式写作中应保留
2. **时态混淆**：注意 sedang（进行）、sudah（完成）、akan（将来）
3. **否定词误用**：tidak 用于动词/形容词，bukan 用于名词
4. **介词错误**：di（在）、ke（去）、dari（从）的用法
