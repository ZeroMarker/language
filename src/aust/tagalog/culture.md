# 菲律宾文化简介

## 国家概况

- **全称**：菲律宾共和国（Republika ng Pilipinas）
- **首都**：马尼拉（Manila）
- **人口**：约 1.1 亿
- **面积**：约 30 万平方公里
- **独立日**：1898 年 6 月 12 日
- **国语**：菲律宾语（Filipino，基于他加禄语）

## 多元文化

菲律宾是东南亚文化最多元的国家之一：
- **民族**：超过 180 个民族群体
- **语言**：约 180 种语言
- **宗教**：天主教（约 86%）、新教、伊斯兰教等
- **岛屿**：超过 7,600 个岛屿

## 主要文化区域

| 区域 | 特点 |
|------|------|
| 吕宋岛（Luzon） | 首都马尼拉所在地，他加禄文化为主 |
| 米沙鄢群岛（Visayas） | 宿务语文化，天主教节日丰富 |
| 棉兰老岛（Mindanao） | 穆斯林文化，摩洛人传统 |
| 巴拉望（Palawan） | 原住民文化，自然保护区 |

## 西班牙殖民影响

333 年西班牙殖民（1565-1898）深刻影响了菲律宾文化：
- **宗教**：天主教成为主要宗教
- **姓名**：西班牙姓氏普遍
- **节日**：宗教节日众多
- **建筑**：西班牙式教堂和建筑
- **食物**：西班牙菜肴影响

## 宗教与习俗

- **天主教**：影响深远，教堂是社区中心
- **圣周（Semana Santa）**：最重要的宗教节日
- **圣诞节**：世界最长圣诞季（9月至12月）
- **家庭至上**：家庭关系紧密
- **尊重长辈**：用"po"和"opo"表示尊敬

## 社交礼仪

| 场景 | 礼仪 |
|------|------|
| 见面 | 微笑，握手，用"po/opo" |
| 称呼 | 用 Kuya（哥）/Ate（姐）称呼年长者 |
| 递物 | 用右手或双手 |
| 用餐 | 用勺子和叉子（右手勺，左手叉） |
| 做客 | 带小礼物，不要准时到（稍晚） |

## 现代菲律宾

- **经济**：BPO（业务流程外包）产业发达
- **海外劳工（OFW）**：约 1000 万菲律宾人在海外工作
- **旅游**：长滩岛、巴拉望、宿务
- **流行文化**：菲律宾流行音乐、电影
- **社交媒体**：菲律宾是社交媒体使用大国
- **篮球**：最受欢迎的运动
