# 他加禄语日常会话

## 开口与礼貌

| 他加禄语 | 中文 |
|----------|------|
| Kumusta? | 你好吗？ |
| Mabuti naman. | 我很好。 |
| Salamat. | 谢谢。 |
| Salamat po. | 谢谢您。（尊称） |
| Walang anuman. | 不客气。 |
| Oo. | 是。 |
| Hindi. | 不是。 |
| Patawad. | 对不起。 |
| Paumanhin. | 打扰一下/抱歉。 |
| Pakiusap. | 请。 |

## 自我介绍

| 他加禄语 | 中文 |
|----------|------|
| Ako si... | 我叫…… |
| Taga-saan ka? | 你来自哪里？ |
| Taga-China ako. | 我来自中国。 |
| Ako ay estudyante. | 我是学生。 |
| Kaunti lang ang Tagalog ko. | 我只会一点他加禄语。 |
| Hindi ako marunong mag-Tagalog. | 我不会说他加禄语。 |
| Marunong ka ba ng Ingles? | 你会说英语吗？ |

## 问路

| 他加禄语 | 中文 |
|----------|------|
| Nasaan ang istasyon? | 车站在哪里？ |
| Nasaan ang banyo? | 厕所在哪里？ |
| Malayo ba? | 远吗？ |
| Malapit ba? | 近吗？ |
| Dumiretso. | 直走。 |
| Kumaliwa. | 左转。 |
| Kumanan. | 右转。 |
| Dito / Doon. | 这里/那里。 |

## 购物与点餐

| 他加禄语 | 中文 |
|----------|------|
| Magkano ito? | 这个多少钱？ |
| Mahal masyado. | 太贵了。 |
| Gusto ko nito. | 我想要这个。 |
| Mayroon ba kayong...? | 你们有……吗？ |
| Yung bill, please. | 请结账。 |
| Masarap! | 好吃！ |
| Tubig, please. | 请给我水。 |
