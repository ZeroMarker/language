# 他加禄语阅读练习材料

## 初级阅读

### 短文 1：自我介绍

> Ang pangalan ko ay Maria. Nakatira ako sa Maynila. Dalawampu't limang taon na ako. Nagtatrabaho ako sa isang opisina. Gusto ko magbasa ng libro at makinig ng musika.

**词汇表**

| 他加禄语 | 中文 |
|----------|------|
| pangalan | 名字 |
| nakatira | 居住 |
| taon | 年/岁 |
| nagtatrabaho | 工作 |
| opisina | 办公室 |
| gusto | 喜欢/想要 |
| magbasa | 阅读 |
| makinig | 听 |

**理解问题**
1. Ano ang pangalan ng babae?（那个女人叫什么名字？）
2. Saan siya nakatira?（她住在哪里？）
3. Ano ang gusto niya?（她喜欢什么？）

## 阅读技巧

1. **先读标题**：了解主题
2. **找关键词**：人名、地名、数字
3. **根据上下文猜测**：不确定的词先跳过
4. **多次阅读**：第一遍通读，第二遍精读
5. **做笔记**：记录生词和重要信息

## 推荐阅读材料

- **儿童书籍**：简单易懂
- **菲律宾新闻**：如 Inquirer、PhilStar
- **社交媒体**：Facebook、Twitter 上的菲律宾语内容
- **歌词**：菲律宾流行歌曲歌词
