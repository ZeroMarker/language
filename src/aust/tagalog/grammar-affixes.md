# 他加禄语词缀系统

他加禄语的词缀系统丰富，通过前缀、后缀、中缀和环绕缀来改变词义和词性。

## 前缀 (Prefix)

| 前缀 | 功能 | 词根 → 派生词 | 含义 |
|------|------|---------------|------|
| mag- | 施事焦点/使动 | luto → magluto | 做 → 做饭 |
| nag- | 完成时施事 | luto → nagluto | 做 → 做了饭 |
| magsi- | 复数施事 | kain → magsikain | 吃 → （多人）吃 |
| magpa- | 使役 | tulog → magpatulog | 睡 → 使...睡觉 |
| ma- | 能力/意外 | kain → makain | 吃 → 能吃 |
| ma-...-an | 能力/地点 | kain → makainan | 吃 → 能在...吃 |
| mapa- | 意外使役 | takot → mapatakot | 怕 → 被吓到 |
| mang- | 施事焦点 | kain → mangain | 吃 → 吃（强调） |
| mang-...-an | 施事地点 | kain → mangainan | 吃 → 在...吃 |
| mangi- | 施事受益 | bigay → mangibigay | 给 → 给（受益） |
| ipa- | 受益焦点 | luto → ipagluto | 做 → 为...做 |
| ipang- | 工具焦点 | sulat → ipangsulat | 写 → 用...写 |
| i- | 受益/受事 | bigay → ibigay | 给 → 给（受事） |
| ipag- | 工具 | luto → ipagluto | 做 → 用...做 |
| ipang-...-an | 工具地点 | sulat → ipangsulatan | 写 → 用...在...写 |
| pag-...-an | 动作名词 | kain → pagkain | 吃 → 食物 |
| pag- | 动作名词 | luto → pagluto | 做 → 做饭（行为） |
| pam- | 工具名词 | kain → pamkinain | 吃 → 餐具 |
| pa- | 使役 | aral → paaral | 学 → 教 |
| pa-...-an | 使役地点 | tulog → patulugan | 睡 → 使...在...睡 |

## 中缀 (Infix)

| 中缀 | 功能 | 词根 → 派生词 | 含义 |
|------|------|---------------|------|
| -um- | 施事焦点 | kain → kumain | 吃 → 吃（施事） |
| -in- | 受事/完成 | kain → kinain | 吃 → 被吃/吃了 |
| -um- (变体) | 施事 | bili → bumili | 买 → 买（施事） |
| -in- (变体) | 受事/完成 | bili → binili | 买 → 被买/买了 |

**注意**：-um- 和 -in- 是最常用的中缀，插入到词根的第一个辅音和元音之间。

## 后缀 (Suffix)

| 后缀 | 功能 | 词根 → 派生词 | 含义 |
|------|------|---------------|------|
| -an | 地点/方向焦点 | kain → kainan | 吃 → 餐厅 |
| -in | 受事焦点 | luto → lutuin | 做 → 做（受事） |
| -hin | 受事焦点（变体） | bigay → ibigay | 给 → 给（受事） |

## 环绕缀 (Circumfix)

| 环绕缀 | 功能 | 词根 → 派生词 | 含义 |
|--------|------|---------------|------|
| mag-...-an | 施事地点 | kain → magkainan | 吃 → （多人）在...吃 |
| mag-...-in | 施事受事 | luto → maglutuin | 做 → 做（受事） |
| i-...-an | 受益地点 | kain → ikainan | 吃 → 为...在...吃 |
| pag-...-in | 动作受事名词 | luto → paglutuin | 做 → 被做的食物 |
| pa-...-an | 使役地点 | tulog → patulugan | 睡 → 使...在...睡 |
| -in-...-an | 完成地点 | kain → kinainan | 吃 → 在...吃了 |

## 词缀音变规则

### 词根首字母的影响

| 词根首字母 | mag- 变体 | nag- 变体 | 示例 |
|-----------|----------|----------|------|
| 元音 | mag- | nag- | aral → mag-aral |
| b, p, m | mag- (p→magp-) | nag- (p→nagp-) | basa → magbasa |
| t, d, s, n | mag- (t→magt-) | nag- (t→nagt-) | tawag → magtawag |
| k, g | mag- (k→magk-) | nag- (k→nagk-) | kain → magkain |
| l, r, w, y | mag- | nag- | luto → magluto |

### 中缀 -um- 的音变

| 词根首字母 | -um- 形式 | 示例 |
|-----------|----------|------|
| 元音 | -um- | aral → umaral |
| 辅音 | -um- (插入) | kain → kumain |
| b, p, m | -um- | basa → bumasa |
| t, d, s, n | -um- | tawag → tumawag |

## 常见词缀组合

### 动词 → 名词

| 词缀 | 功能 | 示例 |
|------|------|------|
| pag- + 词根 | 动作名词 | luto → pagluto（做饭） |
| pag- + 词根 + -an | 地点名词 | kain → pagkainan（餐厅） |
| pam- + 词根 | 工具名词 | kain → pamkinain（餐具） |
| pang- + 词根 | 工具名词（变体） | sulat → pangsulat（笔） |

### 形容词 → 动词

| 词缀 | 功能 | 示例 |
|------|------|------|
| mag- + 词根 | 使动 | ganda → magpaganda（变美） |
| ma- + 词根 | 能力 | kain → makain（能吃） |
| -um- + 词根 | 状态变化 | ganda → gumanda（变美） |

## 学习建议

1. **从核心词缀开始**：mag-、nag-、-um-、-in-、i-、-an
2. **掌握音变规则**：词根首字母影响词缀形式
3. **多记词根**：词缀系统依赖于对词根的掌握
4. **通过例句学习**：理解词缀在实际句子中的运用
