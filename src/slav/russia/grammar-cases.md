# 俄语六格变化详解

俄语有 **6 个格（падеж）**，是名词、形容词、代词变格的基础。

## 六格总览

| 格 | 俄语名称 | 主要功能 | 疑问词 |
|---|---|---|---|
| 第一格 | Именительный | 主语 | кто? что? |
| 第二格 | Родительный | 所属、否定、部分 | кого? чего? |
| 第三格 | Дательный | 间接宾语 | кому? чему? |
| 第四格 | Винительный | 直接宾语 | кого? что? |
| 第五格 | Творительный | 工具、伴随 | кем? чем? |
| 第六格 | Предложный | 介词位置 | о ком? о чём? |

## 各格用法详解

### 第一格（Именительный）
- 用作主语：**Студент читает.**（学生在读书。）
- 用作表语：**Он студент.**（他是学生。）
- 回答 кто?/что? 的问题

### 第二格（Родительный）
- 表示所属：**Книга студента**（学生的书）
- 否定句中的直接宾语：**Я не читаю книги.**（我不读书。）
- 表示部分：**Чашка чаю**（一杯茶）
- 与某些介词连用：из（从）、до（到）、от（从…起）、без（没有）、для（为了）
- 表示没有：**Нет времени.**（没有时间。）

### 第三格（Дательный）
- 间接宾语：**Я даю книгу студенту.**（我把书给学生。）
- 表示年龄：**Мне двадцать лет.**（我二十岁。）
- 表示感受：**Мне нравится.**（我喜欢。）
- 与某些介词连用：к（朝）、по（沿着）

### 第四格（Винительный）
- 直接宾语（肯定句）：**Я читаю книгу.**（我在读书。）
- 表示方向：**Я иду домой.**（我回家。）
- 时间状语：**Весь день**（一整天）
- 与某些介词连用：в（到…里）、на（到…上）、за（到…后）

### 第五格（Творительный）
- 表示工具：**Я пишу ручкой.**（我用笔写字。）
- 表示伴随（与 с 连用）：**С другом**（和朋友一起）
- 用在表示职业的句中：**Я студентом.**（我是学生。—强调身份）
- 与某些介词连用：с（和…一起）、над（在…上方）、под（在…下方）、перед（在…前方）、за（在…后方）、между（在…之间）

### 第六格（Предложный）
- 与介词 о（关于）、в（在…里）、на（在…上）连用
- **Я говорю о России.**（我在谈论俄罗斯。）
- **Я живу в Москве.**（我住在莫斯科。）
- **Книга на столе.**（书在桌子上。）

## 常见介词与格搭配

| 介词 | 搭配格 | 示例 |
|---|---|---|
| в | 第四格（方向）/ 第六格（位置） | иду в школу / живу в Москве |
| на | 第四格（方向）/ 第六格（位置） | иду на работу / на столе |
| с | 第五格 / 第二格 | с братом / с Москвы |
| из | 第二格 | из дома |
| к | 第三格 | к другу |
| от | 第二格 | от дома |
| до | 第二格 | до Москвы |
| для | 第二格 | для тебя |
| без | 第二格 | без денег |
| о | 第六格 | о тебе |
| по | 第三格 | по улице |
| при | 第六格 | при школе |
| над | 第五格 | над столом |
| под | 第五格 | под столом |
| между | 第五格 | между домами |
| перед | 第五格 | перед домом |
| за | 第五格 / 第四格 | за домом / за стол |
| через | 第四格 | через улицу |
