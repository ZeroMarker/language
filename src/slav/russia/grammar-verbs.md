# 俄语动词变位详解

俄语动词根据人称、数、时态进行变位，分为第一变位法和第二变位法。

## 动词分类

| 变位法 | 结尾特征 | 示例 |
|---|---|---|
| 第一变位法 | -ать, -ять, -оть, -уть, -ть | читать（读）、знать（知道） |
| 第二变位法 | -ить, -еть, -ать（少数） | говорить（说）、смотреть（看） |

## 现在时变位

### 第一变位法：читать（读）

| 人称 | 单数 | 复数 |
|---|---|---|
| 第一人称 | читаю | читаем |
| 第二人称 | читаешь | читаете |
| 第三人称 | читает | читают |

### 第二变位法：говорить（说）

| 人称 | 单数 | 复数 |
|---|---|---|
| 第一人称 | говорю | говорим |
| 第二人称 | говоришь | говорите |
| 第三人称 | говорит | говорят |

### 第二变位法：смотреть（看）

| 人称 | 单数 | 复数 |
|---|---|---|
| 第一人称 | смотрю | смотрим |
| 第二人称 | смотришь | смотрите |
| 第三人称 | смотрит | смотрят |

## 过去时变位

过去时由不定式词干 + 性别后缀构成，不随人称变化。

### читать 的过去时

| 性别/数 | 形式 |
|---|---|
| 阳性单数 | читал |
| 阴性单数 | читала |
| 中性单数 | читало |
| 复数 | читали |

### говорить 的过去时

| 性别/数 | 形式 |
|---|---|
| 阳性单数 | говорил |
| 阴性单数 | говорила |
| 中性单数 | говорило |
| 复数 | говорили |

**注意：** 过去时的性别取决于主语的性别。

## 将来时变位

### 未完成体将来时：буду + 不定式

| 人称 | 形式 |
|---|---|
| я | буду читать |
| ты | будешь читать |
| он/она | будет читать |
| мы | будем читать |
| вы | будете читать |
| они | будут читать |

### 完成体将来时：直接变位

| 人称 | 形式 |
|---|---|
| я | прочитаю |
| ты | прочитаешь |
| он/она | прочитает |
| мы | прочитаем |
| вы | прочитаете |
| они | прочитают |

## 命令式

### 构成规则

| 类型 | 构成 | 示例 |
|---|---|---|
| 第一变位法 | 去掉 -ть, 加 -й | читай! |
| 第二变位法 | 去掉 -ить, 加 -и | говори! |
| 复数 | 加 -те | читайте! говорите! |
| 包括式 | 加 -те | пойдёмте!（我们走吧！） |

### 示例

| 动词 | 单数命令式 | 复数命令式 |
|---|---|---|
| читать | читай | читайте |
| говорить | говори | говорите |
| писать | пиши | пишите |
| делать | делай | делайте |
| смотреть | смотри | смотрите |
| знать | знай | знайте |
| идти | иди | идите |

## 运动动词基础

### 定向与不定向

| 定向（一次） | 不定向（习惯） | 含义 |
|---|---|---|
| идти | ходить | 步行 |
| ехать | ездить | 乘车 |
| бежать | бегать | 跑 |
| лететь | летать | 飞 |
| нести | носить | 带（去） |
| вести | водить | 引导 |
| везти | возить | 运送 |

### 用法区别

- **定向**：朝一个方向移动
  - **Я иду в школу.**（我正在去学校。）

- **不定向**：习惯性或往返移动
  - **Я хожу в школу каждый день.**（我每天去学校。）

详细内容请参见[运动动词详解](grammar-motion-verbs.md)。
