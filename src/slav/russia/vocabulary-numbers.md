# 俄语 数字与计数

## 基数词

| 数字 | 俄语 |
|------|------|
| 1 | один |
| 2 | два |
| 3 | три |
| 4 | четыре |
| 5 | пять |
| 6 | шесть |
| 7 | семь |
| 8 | восемь |
| 9 | девять |
| 10 | десять |

## 特殊规则

- 11-19: одиннадцать, двенадцать...
- 20: двадцать, 30: тридцать...
- 100: сто, 200: двести...

## 序数词

加后缀 -ый/-ой/-ий：первый (第一), второй (第二), третий (第三)
