# 俄语阅读练习材料

## 初级阅读

### 1. 自我介绍（Самопредставление）

> Меня зовут Анна. Мне двадцать пять лет. Я из России. Я живу в Москве. Я студентка. Я изучаю медицину в Московском университете. Я говорю по-русски, по-английски и немного по-китайски. Моё хобби — чтение книг и игра на гитаре.

**词汇表：**
| 俄语 | 中文 |
|---|---|
| меня зовут | 我叫 |
| мне... лет | 我…岁 |
| живу | 我住 |
| изучаю | 我学习 |
| медицина | 医学 |
| хобби | 爱好 |
| чтение | 阅读 |
| игра | 弹奏 |

**练习问题：**
1. Сколько лет Анне?（安娜多大？）
2. Где она живёт?（她住在哪里？）
3. Что она изучает?（她学什么？）

---

### 2. 关于家庭（О семье）

> У меня большая семья. Моего отца зовут Марк. Он инженер. Мою мать зовут Екатерина. Она учительница. У меня есть один брат и одна сестра. Моего брата зовут Том. Ему двадцать лет. Мою сестру зовут Зоя. Ей пятнадцать лет. У нас ещё есть собака. Её зовут Бобик.

**词汇表：**
| 俄语 | 中文 |
|---|---|
| большая семья | 大家庭 |
| отец | 父亲 |
| инженер | 工程师 |
| мать | 母亲 |
| учительница | 女教师 |
| брат | 兄弟 |
| сестра | 姐妹 |
| собака | 狗 |

**练习问题：**
1. Сколько человек в семье?（家里有几口人？）
2. Кем работает отец?（父亲是做什么的？）
3. Как зовут брата?（兄弟叫什么名字？）

## 中级阅读

### 3. 在餐厅（В ресторане）

> Добрый вечер! Столик на двоих, пожалуйста. Конечно, проходите, пожалуйста. Вот меню. Спасибо. Что вы порекомендуете? Сегодня у нас очень хороший лосось с овощами. Звучит отлично. Мне лосось и салат. А мне пельмени. Что будете пить? Бутылку минеральной воды и бокал красного вина. Понял. Сейчас принесу.

**词汇表：**
| 俄语 | 中文 |
|---|---|
| столик | 桌子 |
| проходите | 请进 |
| меню | 菜单 |
| порекомендуете | 推荐 |
| лосось | 三文鱼 |
| овощи | 蔬菜 |
| звучит | 听起来 |
| пельмени | 饺子 |
| минеральная вода | 矿泉水 |
| бокал | 一杯 |
| сейчас | 马上 |

**练习：** 翻译这段对话为中文。

### 4. 日记（Дневник）

> Понедельник, 15 октября
>
> Сегодня я встал в семь часов утра. Я позавтракал и пошёл на работу. На работе у меня было много совещаний. В двенадцать часов я обедал с коллегами в ресторане. После работы я пошёл за покупками. Я купил хлеб, масло, сыр и фрукты. Вечером я читал книгу и смотрел телевизор. Ялёг спать в одиннадцать.

**词汇表：**
| 俄语 | 中文 |
|---|---|
| встал | 我起床了 |
| позавтракал | 我吃了早饭 |
| пошёл | 我去了 |
| совещание | 会议 |
| обедал | 我吃了午饭 |
| покупки | 购物 |
| смотрел | 我看了 |
| телевизор | 电视 |

**练习：** 用俄语写一段类似的日记。

## 高级阅读

### 5. 俄罗斯历史片段（Фрагмент истории России）

> Россия имеет богатую историю. В IX веке возникла Киевская Русь — первое восточнославянское государство. В 988 году князь Владимир принял христианство. В XIII веке Русь попала под монгольское иго. В XVI веке Иван Грозный стал первым царём. Пётр Великий в XVIII веке провёл масштабные реформы и основал Санкт-Петербург. В 1917 году произошла Октябрьская революция. В 1991 году распался Советский Союз, и Россия стала Российской Федерацией.

**词汇表：**
| 俄语 | 中文 |
|---|---|
| богатая история | 丰富的历史 |
| возникла | 产生了 |
| государство | 国家 |
| принял христианство | 接受了基督教 |
| монгольское иго | 蒙古统治 |
| царь | 沙皇 |
| реформы | 改革 |
| основал | 建立了 |
| революция | 革命 |
| распался | 解体了 |

**练习：**
1. Когда возникла Киевская Русь?（基辅罗斯何时产生？）
2. Что сделал Пётр Великий?（彼得大帝做了什么？）
3. Когда распался СССР?（苏联何时解体？）

## 阅读技巧

### 如何提高俄语阅读能力

1. **从简单开始**：先读儿童读物、简单对话
2. **利用上下文**：通过上下文猜测生词含义
3. **查词典**：遇到关键生词及时查阅
4. **大声朗读**：提高语感和发音
5. **做笔记**：记录新词汇和表达
6. **定期复习**：反复阅读同一篇文章
