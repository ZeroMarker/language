# 波兰语常用谚语与习语

## 常用谚语（Przysłowia）

| 波兰语 | 直译 | 含义 |
|---|---|---|
| Co kraj, to obyczaj. | 一国一风俗。 | 入乡随俗 |
| Nie wszystko złoto, co się świeci. | 发光的不都是金子。 | 不要以貌取人 |
| Kto sieje wiatr, ten zbiera burzę. | 种风者收暴风。 | 自作自受 |
| Darowanemu koniowi w zęby się nie zagląda. | 别看赠马的牙齿。 | 收到礼物别挑剔 |
| Gdzie kucharek sześć, tam nie ma co jeść. | 六个厨师反而没饭吃。 | 人多反而坏事 |
| Lepszy wróbel w garści niż gołąb na dachu. | 手中麻雀胜过房上鸽子。 | 一鸟在手胜过二鸟在林 |
| Apetyt rośnie w miarę jedzenia. | 食欲越吃越大。 | 得寸进尺 |
| Co dwie głowy, to nie jedna. | 两个脑袋总比一个好。 | 三个臭皮匠赛过诸葛亮 |
| Cicha woda brzegi rwie. | 静水冲岸。 | 深水静流 |
| Kto pod kim dołki kopie, ten sam w nie wpada. | 给别人挖坑的人自己会掉进去。 | 害人终害己 |
| Niedaleko pada jabłko od jabłoni. | 苹果落得离树不远。 | 有其父必有其子 |
| Potrzeba jest matką wynalazków. | 需要是发明之母。 | |
| Ucz się, póki czas. | 趁时间来得及学习。 | 少壮不努力，老大徒伤悲 |
| Bez pracy nie ma kołaczy. | 不劳动就没有面包。 | 不劳无获 |
| Nie ucz ryby pływać. | 别教鱼游泳。 | 班门弄斧 |

| jak pies z kotem | 像狗和猫一样 | 像猫狗一样不合 |

| uparty jak osioł | 像驴一样固执 | 非常固执 |
