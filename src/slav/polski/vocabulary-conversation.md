# 波兰语日常会话场景

## 打招呼与问候

| 波兰语 | 中文 | 使用场景 |
|---|---|---|
| Cześć! | 你好！（非正式） | 朋友之间 |
| Dzień dobry! | 早上好/下午好！ | 正式场合 |
| Dobry wieczór! | 晚上好！ | 正式场合 |
| Dobranoc! | 晚安！ | 睡前 |
| Jak się masz? | 你好吗？（非正式） | 朋友之间 |
| Jak się Pan/Pani miewa? | 您好吗？（正式） | 正式场合 |
| Dziękuję, dobrze. | 谢谢，很好。 | 回应问候 |
| Co słychać? | 最近怎么样？ | 非正式 |
| Do widzenia! | 再见！ | 正式 |
| Na razie! / Cześć! | 再见！（非正式） | 朋友之间 |
