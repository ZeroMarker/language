# 波兰语 数字与计数

## 基数词

| 数字 | 波兰语 |
|------|--------|
| 1 | jeden |
| 2 | dwa |
| 3 | trzy |
| 4 | cztery |
| 5 | pięć |
| 6 | sześć |
| 7 | siedem |
| 8 | osiem |
| 9 | dziewięć |
| 10 | dziesięć |

## 特殊规则

- 11-19: jedenaście, dwanaście...
- 20: dwadzieścia, 30: trzydzieści...
- 100: sto, 200: dwieście...

## 序数词

加后缀 -ty/-szy：pierwszy (第一), drugi (第二), trzeci (第三)
