# 希伯来语常用谚语与习语

## 经典谚语（פתגמים）

| 希伯来语 | 转写 | 含义 |
|---------|------|------|
| אִם אֵין קֶמַח אֵין תּוֹרָה | im ein qemaḥ ein tora | 没有面包就没有 Torah（物质基础决定精神追求） |
| הַזּוֹרֵעַ בְּדִמְעָה בְּרִנָּה יִקְצֹר | ha-zoreʿa bedimʿah berinah yiqtso | 流泪播种者必欢呼收割（苦尽甘来） |
| אַל תָּשֶׂם עַל לִבְּךָ | al tasem ʿal libkha | 别放在心上 |
| טוֹב שְׁכֵנָה קְרוֹבָה מֵאָח רָחוֹק | tov shekhena qrova me-aḥ raḥoq | 远亲不如近邻 |
| כָּל הַמַּצִּיל נֶפֶשׁ אַחַת כְּאִלּוּ הִצִּיל עוֹלָם מָלֵא | kol ha-matsil nefesh aḥat ke-ilu hitsil ʿolam male | 救一人如救全世界 |
| מִי שֶׁטּוֹרֵחַ בְּעֶרֶב שַׁבָּת אוֹכֵל בְּשַׁבָּת | mi she-toreaḥ be-ʿerev shabbat oḥel be-shabbat | 安息日前准备者安息日有得吃（有备无患） |
| סוֹף מַעֲשֶׂה בְּמַחְשָׁבָה תְּחִלָּה | sof maʿaseh be-maḥshava teḥila | 行动之前先思考（三思而后行） |
| יֵשׁ תִּקְוָה לְאַחֲרִיתֵךְ | yesh tiqva le-aḥaritekh | 你的未来有希望 |

## 常用习语与表达（ביטויים）

| 希伯来语 | 转写 | 字面义 | 实际含义 |
|---------|------|--------|---------|
| בְּהַצְלָחָה | be-hatslaḥa | 以成功 | 祝好运 |
| מַזָּל טוֹב | mazal tov | 好星座 | 恭喜 |
| בְּסֵדֶר | beseder | 好的 | 没问题/好的 |
| לְבַד | levad | 独自 | 一个人 |
| כְּלּוּם | klum | 什么都不是 | 没什么/零 |
| דַּי | dai | 足够 | 够了 |
| יָלָא | yalla | 走吧（借自阿拉伯语） | 快点/走吧 |
| סְתָם | setam | 随便 | 无缘无故/随便 |
| עַל הַקַּו | ʿal ha-qav | 在线上 | 准时 |
| בִּכְלָל | bikhlal | 总体上 | 根本/总的来说 |

## 日常问候

| 场景 | 希伯来语 | 含义 |
|------|---------|------|
| 问候 | שָׁלוֹם | 你好 |
| 早上好 | בֹּקֶר טוֹב | 早上好 |
| 晚上好 | עֶרֶב טוֹב | 晚上好 |
| 安息日快乐 | שַׁבָּת שָׁלוֹם | 安息日平安 |
| 节日快乐 | חַג שָׂמֵחַ | 节日快乐 |
| 新年快乐 | שָׁנָה טוֹבָה | 新年好 |
| 告别 | לְהִתְרָאוֹת | 再见 |
| 感谢 | תּוֹדָה | 谢谢 |
| 不客气 | בְּבַקָּשָׁה | 请/不客气 |
