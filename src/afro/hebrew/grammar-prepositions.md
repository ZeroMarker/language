# 希伯来语介词体系与前置词用法

希伯来语介词（מילות יחס）通常作为前缀附加在名词前。

## 常用介词一览

| 介词 | 转写 | 含义 | 示例 |
|------|------|------|------|
| בְּ- | be- | 在…里/用 | בַּבַּיִת（在家里） |
| לְ- | le- | 给/到 | לַבַּיִת（到家） |
| מִ- / מִן | mi- / min | 从 | מִן הַבַּיִת（从家里） |
| עִם | ʿim | 和…一起 | עִם חָבֵר（和朋友一起） |
| עַל | ʿal | 在…上/关于 | עַל הַשֻּׁלְחָן（在桌子上） |
| אֶל | ʾel | 到/向 | אֶל הַמִּסְעָדָה（到餐厅） |
| כְּ- | ke- | 像… | כְּמוֹ（像） |
| בֵּין | bein | 在…之间 | בֵּין הַבָּתִּים（在房子之间） |
| תַּחַת | taḥat | 在…下面 | תַּחַת הַשֻּׁלְחָן（在桌子下面） |
| עַל יַד | ʿal yad | 在…旁边 | עַל יַד הַבַּיִת（在房子旁边） |
| אַחֲרֵי | aḥarei | 在…之后 | אַחֲרֵי הָאֲרוּחָה（饭后） |
| לִפְנֵי | lifnei | 在…之前 | לִפְנֵי הַשִּׁעוּר（课前） |

## 介词前缀与定冠词的合并

当介词 בְּ、לְ、מִ 遇到定冠词 ה 时，会合并：

| 介词 + 定冠词 | 合并形式 | 示例 | 含义 |
|-------------|---------|------|------|
| בְּ + הַ | בַּ | בַּבַּיִת | 在这房子里 |
| לְ + הַ | לַ | לַבַּיִת | 到这房子 |
| מִן + הַ | מִן הַ | מִן הַבַּיִת | 从这房子 |

## 介词与代词后缀

介词可以附加代词后缀：

### בְּ（在…里）+ 代词后缀

| 形式 | 转写 | 含义 |
|------|------|------|
| בִּי | bi | 在我这里 |
| בְּךָ | bekha | 在你（阳）这里 |
| בָּךְ | bakh | 在你（阴）这里 |
| בּוֹ | bo | 在他这里 |
| בָּהּ | bah | 在她这里 |
| בָּנוּ | banu | 在我们这里 |
| בָּכֶם | bakhem | 在你们这里 |
| בָּהֶם | bahem | 在他们这里 |

### לְ（给）+ 代词后缀

| 形式 | 转写 | 含义 |
|------|------|------|
| לִי | li | 给我 |
| לְךָ | lekha | 给你（阳） |
| לָךְ | lakh | 给你（阴） |
| לוֹ | lo | 给他 |
| לָהּ | lah | 给她 |
| לָנוּ | lanu | 给我们 |
| לָכֶם | lakhem | 给你们 |
| לָהֶם | lahem | 给他们 |

## 常见介词搭配

### בְּ（在…里/用）

- בַּבֹּקֶר — 在早上
- בָּעֶרֶב — 在晚上
- בַּקַּיִץ — 在夏天
- בְּעִבְרִית — 用希伯来语

### מִן（从）

- מֵאַיִן אַתָּה? — 你从哪里来？
- מִתּוֹךְ — 从里面
- מֵעַל — 从上面

### אֶל（到/向）

- הָלַכְתִּי אֶל הַמִּסְעָדָה — 我去了餐厅
- אֶל מִי אַתָּה מְדַבֵּר? — 你在和谁说话？

## 特殊介词短语

| 短语 | 含义 |
|------|------|
| בִּגְלַל | 因为 |
| בְּעַד | 为了/支持 |
| נֶגֶד | 反对 |
| אוּלָם | 然而 |
| כְּפִי שֶׁ- | 按照 |
