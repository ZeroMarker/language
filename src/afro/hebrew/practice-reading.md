# 希伯来语阅读练习

## 初级阅读

### 短文 1：自我介绍

**希伯来语：**

שְׁמִי דָּוִד. אֲנִי תַּלְמִיד בְּבֵית סֵפֶר. אֲנִי גָּר בִּירוּשָׁלַיִם עִם מִשְׁפַּחְתִּי. אֲנִי אוֹהֵב לִקְרֹא וּלְשַׂחֵק כַּדּוּרֶגֶל. אֲנִי לָמֵד עִבְרִית וְאַנְגְּלִית.

**转写：**

Shmi David. Ani talmid be-vehet sefer. Ani gar bi-Yerushalayim ʿim mishpaḥti. Ani ohev liqro ulsaḥeq kaduregel. Ani lomed ʿivrit ve-anglit.

**译文：**

我叫大卫。我是学校里的学生。我和家人住在耶路撒冷。我喜欢阅读和踢足球。我学习希伯来语和英语。

**生词：**

| 希伯来语 | 含义 |
|---------|------|
| שֵׁם | 名字 |
| תַּלְמִיד | 学生 |
| בֵּית סֵפֶר | 学校 |
| גָּר | 居住 |
| מִשְׁפָּחָה | 家庭 |
| אוֹהֵב | 喜欢 |
| לִקְרֹא | 阅读 |
| לְשַׂחֵק | 玩/运动 |
| כַּדּוּרֶגֶל | 足球 |

### 短文 2：我的一天

**希伯来语：**

אֲנִי מִתְעוֹרֵר בְּשֵׁשׁ בַּבֹּקֶר. אֲנִי לָבֵשׁ וְשׁוֹתֶה קָפֶה. אֲנִי הוֹלֵךְ לְבֵית הַסֵּפֶר בָּאוֹטוֹבּוּס. אֲנִי לָמֵד מִשְּׁמוֹנֶה עַד שְׁתֵּים עֶשְׂרֵה. אֲנִי חוֹזֵר הַבַּיְתָה בִּצְהׇרַיִם. אֲנִי אוֹכֵל אֶת הָאֲרוּחָה עִם מִשְׁפַּחְתִּי.

**转写：**

Ani mitʿorer be-shesh baboker. Ani lavesh ve-shote qafe. Ani holekh le-vehet ha-sefer ba-ʾotobus. Ani lomed mi-shmoneʿ ʿad shteiʿ esre. Ani ḥozer ha-bayta bi-tsohorayim. Ani oḥel et ha-arukha ʿim mishpaḥti.

**译文：**

我早上六点起床。我穿好衣服并喝咖啡。我坐公共汽车去学校。我从八点学到十二点。我中午回家。我和家人一起吃饭。

## 中级阅读

### 短文 3：以色列简介

**希伯来语：**

יִשְׂרָאֵל הִיא מְדִינָה קְטַנָּה בְּאֶרֶץ יִשְׂרָאֵל. הִיא נִמְצֵאת בַּמִּזְרָח הַתִּיכוֹן. יֵשׁ בָּהּ כִּתְשַׁע מִלְיוֹן תּוֹשָׁבִים. הַשָּׁפָה הָרְשׁוּמִית הִיא עִבְרִית. יְרוּשָׁלַיִם הִיא הָעִיר הַבִּירָה. תֵּל אָבִיב הִיא הָעִיר הַגְּדוֹלָה בְּיוֹתֵר.

**译文：**

以色列是圣地上的一个小国。它位于中东。有大约九百万居民。官方语言是希伯来语。耶路撒冷是首都。特拉维夫是最大的城市。

## 阅读练习技巧

1. **从右到左阅读**，适应希伯来语书写方向
2. **注意元音标记**，初学者依赖 nikkud（元音符号）
3. **识别词根**，大多数希伯来词基于三辅音词根
4. **标记生词**，查阅后记录
5. **大声朗读**，培养语感
6. **注意 Binyan 模式**，识别动词的词干类型
