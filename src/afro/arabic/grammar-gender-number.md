# 阿拉伯语阴阳性与单双复数变化规则

## 阴阳性（الجنس）

### 阳性名词（المذكر）

- 一般无特殊词尾标记
- 示例：كِتَاب（书）、قَلَم（笔）、رَجُل（男人）、وَلَد（男孩）

### 阴性名词（المؤنث）

- 大多数以 ة（تاء مربوطة）结尾
- 示例：مَدْرَسَة（学校）、حَقِيبَة（包）、سَيَّارَة（车）、حَمَامَة（鸽子）

### 阴阳性对照表

| 阳性 | 阴性 | 含义 |
|------|------|------|
| مُعَلِّم | مُعَلِّمَة | 教师 |
| طَالِب | طَالِبَة | 学生 |
| طَبِيب | طَبِيبَة | 医生 |
| كَاتِب | كَاتِبَة | 作家 |
| وَزِير | وَزِيرَة | 部长 |
| أَسَد | أَسَدَة | 狮子/母狮 |
| ذَكَر | أُنْثَى | 雄性/雌性 |

### 特殊阴性名词（不带 ة）

| 阳性 | 阴性 | 含义 |
|------|------|------|
| أَب | أُم | 父亲/母亲 |
| أَخ | أُخْت | 兄弟/姐妹 |
| ابْن | بِنْت | 儿子/女儿 |
| رَجُل | اِمْرَأَة | 男人/女人 |
| عَمّ | عَمَّة | 伯父/伯母 |
| خَال | خَالَة | 舅父/舅母 |

## 数（العدد）

### 单数（المفرد）

无特殊词尾：كِتَاب（书）、بَيْت（房子）

### 双数（المثنى）

| 格 | 词尾 | 示例 |
|----|------|------|
| 主格 | ـَانِ | كِتَابَانِ（两本书） |
| 宾格/属格 | ـَيْنِ | كِتَابَيْنِ（两本书） |

### 复数（الجمع）

#### 完整复数（الجمع السالم）

| 类型 | 主格词尾 | 宾属格词尾 | 示例 |
|------|---------|-----------|------|
| 阳性 | ـُونَ | ـِينَ | مُسْلِمُونَ / مُسْلِمِينَ |
| 阴性 | ـَاتٌ | ـَاتٍ | مُسْلِمَاتٌ / مُسْلِمَاتٍ |

#### 破碎复数（الجمع المكسر）

破碎复数通过改变词内元音构成，形式多样：

| 单数 | 破碎复数 | 含义 | 词形模式 |
|------|---------|------|---------|
| كِتَاب | كُتُب | 书 | فِعَال → فُعُل |
| رَجُل | رِجَال | 男人 | فَعُل → فِعَال |
| بَيْت | بُيُوت | 房子 | فَعْل → فُعُول |
| وَلَد | أَوْلَاد | 男孩 | فَعْل → أَفْعَال |
| قَلَم | أَقْلَام | 笔 | فَعَل → أَفْعَال |
| شَجَرَة | أَشْجَار | 树 | فَعَلَة → أَفْعَال |
| جَبَل | جِبَال | 山 | فَعَل → فِعَال |
| مَدِينَة | مُدُن | 城市 | فَعِيلَة → فُعُل |
| طَرِيق | طُرُق | 路 | فَعِيل → فُعُل |
| مَكْتَب | مَكَاتِب | 办公室 | مَفْعَل → مَفَاعِل |

## 形容词的性数变化

形容词必须与所修饰的名词在性、数上保持一致：

| 名词 | 形容词（大的） | 含义 |
|------|--------------|------|
| كِتَابٌ (阳单) | كِتَابٌ كَبِيرٌ | 大书 |
| كِتَابَانِ (阳双) | كِتَابَانِ كَبِيرَانِ | 两本大书 |
| كُتُبٌ (阳复) | كُتُبٌ كَبِيرَةٌ | 大书（复数） |
| مَدْرَسَةٌ (阴单) | مَدْرَسَةٌ كَبِيرَةٌ | 大学校 |
| مَدْرَسَتَانِ (阴双) | مَدْرَسَتَانِ كَبِيرَتَانِ | 两所大学校 |
| مَدَارِسُ (阴复) | مَدَارِسُ كَبِيرَةٌ | 大学校（复数） |
