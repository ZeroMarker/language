# 阿拉伯语介词体系与前置词用法

阿拉伯语介词（حرف الجر）置于名词前，使其后的名词变为属格。介词是不可变化的虚词。

## 常用介词一览

| 介词 | 转写 | 含义 | 示例 |
|------|------|------|------|
| فِي | fī | 在…里 | فِي الْبَيْتِ（在房子里） |
| عَلَى | ʿalā | 在…上 | عَلَى الْمَكْتَبِ（在桌子上） |
| مَعَ | maʿa | 和…一起 | مَعَ صَدِيقِي（和我的朋友一起） |
| إِلَى | ilā | 到…去 | إِلَى الْمَدْرَسَةِ（去学校） |
| مِن | min | 从… | مِنَ الْبَيْتِ（从家里） |
| عَن | ʿan | 关于 | عَنْ تَارِيخٍ（关于历史） |
| بِ | bi | 用/在 | بِالْقَلَمِ（用笔） |
| لِ | li | 为了/给 | لِلطَّالِبِ（给学生） |
| كَ | ka | 像… | كَالْأَسَدِ（像狮子一样） |
| بَعْدَ | baʿda | 在…之后 | بَعْدَ الْعَصْرِ（下午之后） |
| قَبْلَ | qabla | 在…之前 | قَبْلَ الظُّهْرِ（中午之前） |
| تَحْتَ | taḥta | 在…下面 | تَحْتَ الْمَكْتَبِ（在桌子下面） |
| أَمَامَ | amāma | 在…前面 | أَمَامَ الْبَيْتِ（在房子前面） |
| خَلْفَ | khalfa | 在…后面 | خَلْفَ الْبَابِ（在门后面） |
| بَيْنَ | bayna | 在…之间 | بَيْنَ الْبَيْتَيْنِ（在两栋房子之间） |

## 介词与代词后缀

介词可以附加代词后缀：

| 介词 + 后缀 | 转写 | 含义 |
|------------|------|------|
| فِيَّ | fiyya | 在我这里 |
| فِيكَ | fīka | 在你这里 |
| فِيكِ | fīki | 在你（女）这里 |
| فِيهِ | fīhi | 在他这里 |
| فِيهَا | fīhā | 在她这里 |
| فِينَا | fīnā | 在我们这里 |
| فِيكُمْ | fīkum | 在你们这里 |
| فِيهِمْ | fīhim | 在他们这里 |
| مَعِي | maʿī | 和我一起 |
| مَعَكَ | maʿaka | 和你一起 |
| مَعَهُ | maʿahu | 和他一起 |
| لِي | lī | 给我/我的 |
| لَكَ | laka | 给你/你的 |
| لَهُ | lahu | 给他/他的 |

## 介词的常见搭配

### فِي（在…里）

- فِي الْمَدْرَسَةِ — 在学校
- فِي الْبَيْتِ — 在家
- فِي الصَّيْفِ — 在夏天
- فِي هَذَا الْوَقْتِ — 在这个时候

### مِن（从…）

- مِنْ أَيْنَ أَنْتَ؟ — 你从哪里来？
- مِنَ الصَّبَاحِ — 从早上
- مِنْ بَعْدِ — 从那以后

### إِلَى（到…）

- ذَهَبْتُ إِلَى الْمَدْرَسَةِ — 我去了学校
- إِلَى أَيْنَ؟ — 到哪里去？

### بِ（用/在）

- كَتَبْتُ بِالْقَلَمِ — 我用笔写了
- بِاللُّغَةِ الْعَرَبِيَّةِ — 用阿拉伯语

## 特殊介词短语

| 短语 | 含义 |
|------|------|
| مِنْ أَجْلِ | 为了 |
| بِسَبَبِ | 因为 |
| عَلَى الرُّغْمِ مِنْ | 尽管 |
| فِي نِهَايَةِ | 在…结束时 |
| عِنْدَمَا | 当…时 |
