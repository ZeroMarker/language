# 阿拉伯语阅读练习

## 初级阅读

### 短文 1：自我介绍

**阿拉伯语：**

اِسْمِي أَحْمَدُ. أَنَا طَالِبٌ فِي الْجَامِعَةِ. أَسْكُنُ فِي الْقَاهِرَةِ مَعَ عَائِلَتِي. أُحِبُّ الْقِرَاءَةَ وَالرِّيَاضَةَ. أَدْرُسُ اللُّغَةَ الْعَرَبِيَّةَ وَاللُّغَةَ الْإِنْجِلِيزِيَّةَ.

**转写：**

Ismī Aḥmadu. Anā ṭālibun fī al-jāmiʿati. Askunu fī al-Qāhirati maʿa ʿāʾilatī. Uḥibbu al-qirāʾata wa-al-riyāḍata. Adrusu al-lughata al-ʿarabiyyata wa-al-lughata al-injlīziyyata.

**译文：**

我叫艾哈迈德。我是大学里的学生。我和家人住在开罗。我喜欢阅读和运动。我学习阿拉伯语和英语。

**生词：**

| 阿拉伯语 | 含义 |
|---------|------|
| اسْم | 名字 |
| طَالِب | 学生 |
| جَامِعَة | 大学 |
| أَسْكُنُ | 我居住 |
| عَائِلَة | 家庭 |
| أُحِبُّ | 我喜欢 |
| قِرَاءَة | 阅读 |
| رِيَاضَة | 运动 |
| أَدْرُسُ | 我学习 |

### 短文 2：我的一天

**阿拉伯语：**

أَسْتَيْقِظُ فِي السَّاعَةِ السَّادِسَةِ صَبَاحًا. أَتَنَعَّلُ وَأَشْرَبُ الشَّايَ. أَذْهَبُ إِلَى الْمَدْرَسَةِ بِالْحَافِلَةِ. أَدْرُسُ مِنَ الثَّامِنَةِ إِلَى الثَّانِيَةِ عَشْرَةَ. أَعُودُ إِلَى الْبَيْتِ فِي الظُّهْرِ. أَأْكُلُ الْغَدَاءَ مَعَ أُسْرَتِي.

**转写：**

Astayqiẓu fī al-sāʿati al-sādisati ṣabāḥan. Atanaʿʿalu wa-ashrabu al-shāya. Adhhabu ilā al-madrasati bi-al-ḥāfila. Adrusu mina al-thāminati ilā al-thāniyati ʿashrata. Aʿūdu ilā al-bayti fī al-ẓuhr. Ākulu al-ghadāʾa maʿa usrati.

**译文：**

我早上六点起床。我穿上鞋并喝茶。我坐公共汽车去学校。我从八点学到十二点。我中午回家。我和家人一起吃午饭。

## 中级阅读

### 短文 3：阿拉伯语的重要性

**阿拉伯语：**

اللُّغَةُ الْعَرَبِيَّةُ هِيَ لُغَةُ الْقُرْآنِ الْكَرِيمِ. يَتَحَدَّثُ بِهَا أَكْثَرُ مِنْ أَرْبَعِمِائَةِ مِلْيُونِ إِنْسَانٍ فِي الْعَالَمِ. تُعَدُّ اللُّغَةَ الرَّابِعَةَ فِي الْعَالَمِ مِنْ حَيْثُ عَدَدُ النُّطَّاقِينَ بِهَا. لِلُّغَةِ الْعَرَبِيَّةِ ثَلَاثَةُ أَنْوَاعٍ: الْفُصْحَى وَالْعَامِيَّةُ وَالْعَرَبِيَّةُ الْوَسَطَى.

**译文：**

阿拉伯语是《古兰经》的语言。世界上有超过四亿人使用阿拉伯语。按使用人数计算，它是世界第四大语言。阿拉伯语有三种类型：标准阿拉伯语、方言和中间阿拉伯语。

## 阅读练习技巧

1. **先通读全文**，不要逐字翻译
2. **标记生词**，查阅后记录
3. **注意动词变位**，识别时态和人称
4. **理解上下文**，通过已知词推断未知词义
5. **大声朗读**，培养语感和发音
6. **从右到左阅读**，适应阿拉伯语书写方向
