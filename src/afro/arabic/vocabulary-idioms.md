# 阿拉伯语常用谚语与习语

## 经典谚语（الأمثال العربية)

| 阿拉伯语 | 转写 | 含义 |
|---------|------|------|
| اُكْتُبْ يَا مُصْطَفَى | uktub yā muṣṭafā | 好记性不如烂笔头（直：写吧，穆斯塔法） |
| الْعَقْلُ السَّلِيمُ فِي الْجِسْمِ السَّلِيمِ | al-ʿaql al-salīm fī al-jism al-salīm | 健全的精神寓于健全的身体 |
| إِذَا أَرَدْتَ أَنْ تُطَاعَ فَأْمُرْ بِمَعْرُوفٍ | idhā aradta an tuṭāʿ faʾmur bi-maʿrūf | 若要人服从，须以善相令 |
| مَنْ جَدَّ وَجَدَ | man jadda wajada | 有志者事竟成（直：谁努力谁就找到） |
| الصَّبْرُ مِفْتَاحُ الْفَرَجِ | al-ṣabru miftāḥu al-faraj | 忍耐是解脱的钥匙 |
| مَنْ طَلَبَ الْعُلَا سَهِرَ اللَّيَالِي | man ṭalaba al-ʿulā sahira al-layālī | 求高位者必夜不能寐（欲戴王冠必承其重） |
| الدَّرْبُ الَّذِي تَعْرِفُ خَيْرٌ مِنَ الَّذِي لَا تَعْرِفُ | al-darb alladhī taʿrifu khayrun min alladhī lā taʿrifu | 熟路胜于陌生路 |
| خَيْرُ الْكَلَامِ مَا قَلَّ وَدَلَّ | khayru al-kalām mā qalla wa-dalla | 言贵精不贵多 |
| لَا تُؤَخِّرْ عَمَلَ الْيَوْمِ إِلَى الْغَدِ | lā tuʾakhkhir ʿamal al-yawm ilā al-ghad | 今日事今日毕 |
| الْجَارُ قَبْلَ الدَّارِ | al-jāru qabla al-dār | 先选邻居再选房 |

## 常用习语与表达（التعبيرات الاصطلاحية)

| 阿拉伯语 | 转写 | 字面义 | 实际含义 |
|---------|------|--------|---------|
| عَلَى الرَّأْسِ | ʿalā al-raʾs | 在头上 | 欢迎（表示尊重） |
| يَدًا بِيَدٍ | yadan bi-yadin | 手牵手 | 合作 |
| بِأَلْفِ صِحَّة | bi-alf ṣiḥḥa | 祝你千次健康 | 祝你好运/保重 |
| مَا شَاءَ اللَّهُ | mā shāʾa Allāhu | 真主意欲 | 太棒了/了不起 |
| إِنْ شَاءَ اللَّهُ | in shāʾa Allāhu | 如果真主意欲 | 希望如此/但愿 |
| الْحَمْدُ لِلَّهِ | al-ḥamdu li-llāhi | 赞美归于真主 | 感谢真主/太好了 |
| تُقَبَّلْ | tuqabbal | 被接受 | 愿你的祈祷/善行被接受 |
| أَهْلًا وَسَهْلًا | ahlan wa-sahlan | 家人和平地 | 欢迎光临 |
| مَرْحَبًا | marḥaban | 宽敞的地方 | 你好/欢迎 |
| بِسْمِ اللَّهِ | bismi-llāhi | 奉真主之名 | 开始吧（饭前/做事前） |
| يُسَلِّمُ عَلَيْكَ | yusallimu ʿalayka | 他向你问好 | 代我向…问好 |

## 日常问候（التحيات)

| 场景 | 阿拉伯语 | 含义 |
|------|---------|------|
| 问候 | السَّلَامُ عَلَيْكُمْ | 愿平安降临于你们 |
| 回应 | وَعَلَيْكُمُ السَّلَامُ | 也愿平安降临于你们 |
| 早晨 | صَبَاحُ الْخَيْرِ | 早上好 |
| 回应 | صَبَاحُ النُّورِ | 早上好（光明的早晨） |
| 晚上 | مَسَاءُ الْخَيْرِ | 晚上好 |
| 回应 | مَسَاءُ النُّورِ | 晚上好（光明的晚上） |
| 告别 | مَعَ السَّلَامَةِ | 一路平安 |
| 感谢 | شُكْرًا / جَزَاكَ اللَّهُ خَيْرًا | 谢谢 / 愿真主善报你 |
| 回应 | عَفْوًا / وَإِيَّاكَ | 不客气 / 也祝你 |
