# 意大利语常用谚语与习语

## 经典谚语（Proverbi）

| 意大利语 | 中文含义 |
|----------|---------|
| Chi dorme non piglia pesci. | 睡觉的人抓不到鱼（早起的鸟儿有虫吃。） |
| Tra il dire e il fare c'è di mezzo il mare. | 说和做之间隔着大海（说到容易做到难。） |
| L'abito non fa il monaco. | 衣服不能造就僧侣（人不可貌相。） |
| Non tutte le ciambelle riescono col buco. | 不是所有甜甜圈都有洞（事情不会总是如愿。） |
| Chi trova un amico trova un tesoro. | 找到朋友就找到了宝藏。 |
| Meglio tardi che mai. | 迟到总比不到好。 |
| Il lupo perde il pelo ma non il vizio. | 狼会掉毛但不会改掉恶习（江山易改本性难移。） |
| A caval donato non si guarda in bocca. | 别看赠马的嘴（不要挑剔收到的礼物。） |
| Chi si accontenta gode. | 知足者常乐。 |
| La gatta frettolosa fece i gattini ciechi. | 急躁的母猫生了瞎眼的小猫（欲速则不达。） |
| Ogni lasciata è persa. | 每次放弃都是损失（机会不等人。） |
| Gallina vecchia fa buon brodo. | 老母鸡炖好汤（姜还是老的辣。） |
| Paese che vai, usanza che trovi. | 入乡随俗。 |
| Chi semina vento raccoglie tempesta. | 种风者收暴风（自作自受。） |
| Tutto il mondo è paese. | 全世界都是一个村（天下乌鸦一般黑。） |

## 常用习语（Modi di dire）

### 身体相关

| 习语 | 字面意思 | 实际含义 |
|------|---------|---------|
| Avere le mani in pasta | 手在面团里 | 有影响力、插手某事 |
| Rompere le scatole | 打破箱子 | 烦扰某人 |
| Mettere il carro davanti ai buoi | 把车放在牛前面 | 本末倒置 |
| Non avere peli sulla lingua | 舌头上没有毛 | 说话直率 |
| Avere la testa fra le nuvole | 头在云里 | 白日做梦 |
| Avere un diavolo per capello | 每根头发一个魔鬼 | 非常生气 |
| Fare orecchie da mercante | 做商人的耳朵 | 装聋作哑 |
| Prendere due piccioni con una fava | 用一颗豆子抓两只鸽子 | 一箭双雕 |
| Mettere la pulce nell'orecchio | 在耳朵里放跳蚤 | 让人起疑心 |
| Toccare il cielo con un dito | 用手指碰到天空 | 高兴极了 |

### 动物相关

| 习语 | 字面意思 | 实际含义 |
|------|---------|---------|
| Avere una fame da lupo | 有狼的饥饿 | 饿极了 |
| Essere un pesce lesso | 是一条白水鱼 | 无趣的人 |
| In bocca al lupo | 在狼嘴里 | 祝好运（回应：Crepi il lupo!） |
| Fare il viso della lontra | 做水獭的脸 | 假装无辜 |
| Mettere il bastone fra le ruote | 在轮子间放棍子 | 阻挠某事 |
| Essere una gazza | 是喜鹊 | 话多的人 |
| Dormire come un ghiro | 像睡鼠一样睡 | 睡得很沉 |
| Avere la memoria da elefante | 有大象的记忆 | 记忆力极好 |

### 日常表达

| 习语 | 含义 | 使用场景 |
|------|------|---------|
| In bocca al lupo! | 祝好运！ | 考试、面试前 |
| Che pizza! | 多无聊啊！ | 表达厌烦 |
| Non vedo l'ora! | 我等不及了！ | 期待某事 |
| Dai! | 来吧！/得了吧！ | 鼓励或不相信 |
| Ma figurati! | 算了吧！ | 表示不介意 |
| Boh! | 不知道！ | 表达不确定 |
| Magari! | 要是能就好了！ | 表达愿望 |
| Ci mancherebbe! | 那还用说！ | 表示不客气 |
| Punto e basta. | 句号，就这样。 | 表示结束讨论 |
| Essere al verde | 是绿色的 | 身无分文 |

## 使用场景建议

- **日常对话**：习语使表达更地道，但注意使用场合
- **正式写作**：谚语可用于议论文增强说服力
- **口语练习**：建议先在非正式场合使用，注意语气
