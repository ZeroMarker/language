# 西班牙语代词系统详解

## 主语代词（Pronombres personales sujeto）

| 人称 | 代词 | 说明 |
|------|------|------|
| yo | 我 | |
| tú | 你 | 非正式 |
| él/ella/usted (Ud.) | 他/她/您 | usted 为敬称 |
| nosotros/as | 我们 | |
| vosotros/as | 你们 | 仅西班牙使用 |
| ellos/ellas/ustedes (Uds.) | 他们/她们/您们 | 拉美ustedes代替vosotros |

## 直接宾语代词（Pronombres de objeto directo）

| 人称 | 代词 | 例句 |
|------|------|------|
| me | 我 | Él **me** vio.（他看见了我。） |
| te | 你 | Yo **te** amo.（我爱你。） |
| lo/la | 他/她/它 | Yo **lo** conozco.（我认识他。） |
| nos | 我们 | Ellos **nos** invitaron.（他们邀请了我们。） |
| os | 你们 | Yo **os** ayudo.（我帮助你们。） |
| los/las | 他们/她们 | Yo **los** vi.（我看见了他们。） |

## 间接宾语代词（Pronombres de objeto indirecto）

| 人称 | 代词 | 例句 |
|------|------|------|
| me | 给我 | Él **me** dio un libro.（他给了我一本书。） |
| te | 给你 | Yo **te** envié una carta.（我给你寄了一封信。） |
| le | 给他/她 | Yo **le** di el libro.（我把书给了他。） |
| nos | 给我们 | Ella **nos** contó una historia.（她给我们讲了一个故事。） |
| os | 给你们 | Yo **os** agradezco.（我感谢你们。） |
| les | 给他们/她们 | Yo **les** respondí.（我回复了他们。） |

## 与格代词 le/les 的特殊用法

在某些地区（尤其是阿根廷），le/les 可用作直接宾语（leísmo）：
- **Le** vi ayer.（= Lo vi ayer.）（我昨天看见了他。）

> 标准西班牙语中，直接宾语应该用 lo/la/los/las。

## 重读代词（Pronombres tónicos）

| 人称 | 代词 | 用法 |
|------|------|------|
| mí | 我 | 介词后、强调 |
| ti | 你 | 介词后、强调 |
| él/ella | 他/她 | 介词后、强调 |
| nosotros/as | 我们 | 介词后、强调 |
| vosotros/as | 你们 | 介词后、强调 |
| ellos/ellas | 他们/她们 | 介词后、强调 |

**例句**：
- ¿Es **para mí**?（这是给我的吗？）
- **Contigo**.（和你一起。）
- **Para nosotros**.（给我们。）

## 反身代词（Pronombres reflexivos）

| 人称 | 代词 | 例句（lavarse 洗） |
|------|------|---------------------|
| yo | me | Yo **me** lavo. |
| tú | te | Tú **te** lavas. |
| él/ella/usted | se | Él **se** lava. |
| nosotros/as | nos | Nosotros **nos** lavamos. |
| vosotros/as | os | Vosotros **os** laváis. |
| ellos/ellas/ustedes | se | Ellos **se** lavan. |

## 代词位置规则

1. **陈述句**：代词放在动词前（前置）
   - **Lo** veo.（我看见他。）

2. **命令式肯定**：代词放在动词后，连写
   - ¡Dime!（告诉我！）= Di + me
   - ¡Hazlo!（做吧！）= Haz + lo

3. **不定式/副动词**：代词可连写在动词后或放在变位动词前
   - **Viéndolo** / Lo **viendo**（看见他的时候）

4. **否定句**：代词在动词前
   - No **lo** veo.（我没看见他。）

## 双代词顺序

当直接宾语代词和间接宾语代词同时出现时：

**顺序**：IO + DO + 动词

- **Me lo** dio.（他把它给了我。）
- **Te lo** explico.（我把它解释给你。）

> 注意：当间接宾语为 le/les 时，要变为 se：
- Le dio el libro → **Se lo** dio.（他把书给了他。）

## se 的特殊用法

### 被动句
- Se **habla** español.（说西班牙语。）
- Se **venden** casas.（出售房屋。）

### 无人称句
- Se **necesita** ayuda.（需要帮助。）
- Se **dice** que…（据说…）

### 自反被动
- La puerta se **abrió**.（门开了。）

## 拉美西班牙语代词差异

| 用法 | 西班牙 | 拉美 |
|------|--------|------|
| 你们 | vosotros | ustedes |
| 反身代词 | os | se |
| 直接宾语 | lo/la | lo/la（阿根廷有时用le） |
