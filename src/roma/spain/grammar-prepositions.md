# 西班牙语介词用法详解

## 常用介词一览

| 介词 | 基本含义 | 核心用法 |
|------|---------|---------|
| de | 的、从 | 所有格、来源、材料 |
| a | 在、到、给 | 地点、方向、时间、间接宾语 |
| en | 在…里 | 地点、时间 |
| con | 和…一起 | 伴随 |
| por | 通过、为了 | 方式、原因、持续时间 |
| para | 为了、给 | 目的、方向、截止时间 |
| sin | 没有 | 缺失 |
| entre | 在…之间 | 两者之间 |
| sobre | 在…上面 | 位置、关于 |

## de 的用法

### 所有格
- El libro **de** María.（玛丽的书。）

### 来源
- Soy **de** México.（我来自墨西哥。）

### 材料
- Una mesa **de** madera.（一张木桌。）

### 内容
- Una taza **de** café.（一杯咖啡。）

### 固定搭配
- gustar **de**（喜欢…）
- acordarse **de**（记得…）
- tratar **de**（试图…）

## a 的用法

### 地点（到某地）
- Voy **a** Madrid.（我去马德里。）

### 时间
- **A** las ocho.（在八点。）

### 间接宾语
- Doy el libro **a** María.（我把书给玛丽。）

### 直接宾语人（个人a）
- Veo **a** María.（我看见玛丽。）

> **个人a**：直接宾语是人时，需要加 a。

### 固定搭配
- empezar **a**（开始做…）
- ir **a**（将要做…）

## en 的用法

### 地点
- Estoy **en** Madrid.（我在马德里。）
- **En** la mesa.（在桌子上。）

### 时间
- **En** marzo.（在三月。）

### 交通方式
- Viajar **en** avión/autobús/tren.（坐飞机/公共汽车/火车旅行。）

## por vs para

| por | para |
|-----|------|
| 原因、方式 | 目的、方向 |
| Viajó **por** trabajo.（他因工作旅行。） | Viajó **para** Japón.（他去了日本。） |
| Hecho **por** mí.（由我做的。） | Es **para** ti.（这是给你的。） |
| Durante **por** dos horas.（持续两小时。） | Para el lunes.（到周一为止。） |
| Gracias **por** tu ayuda.（谢谢你的帮助。） | Estudio **para** aprender.（我学习是为了学。） |

## 介词与冠词的缩合

### de + el = del
- El libro **del** profesor.（老师的书。）

### a + el = al
- Voy **al** cine.（我去电影院。）

> **注意**：只有与阳性单数定冠词 el 缩合，阴性、复数不缩合。

## 常见错误

| 错误 | 正确 | 说明 |
|------|------|------|
| Vivo **en** Madrid. | Vivo **en** Madrid. | ✓ 正确 |
| Voy **a** España. | Voy **a** España. | ✓ 正确 |
| Hecho **para** mí. | Hecho **por** mí. | 表示施动者用 por |
| Viajó **para** dos horas. | Viajó **por** dos horas. | 表示持续时间用 por |
| Estoy **a** casa. | Estoy **en** casa. | 表示所在位置用 en |
| Lo vi **∅** María. | Vi **a** María. | 直接宾语是人需要个人a |
