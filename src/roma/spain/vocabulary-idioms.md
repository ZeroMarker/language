# 西班牙语常用谚语与习语

## 经典谚语（Refranes）

| 西班牙语 | 中文含义 |
|----------|---------|
| Más vale tarde que nunca. | 迟到总比不到好。 |
| No hay mal que por bien no venga. | 塞翁失马，焉知非福。 |
| En boca cerrada no entran moscas. | 闭着的嘴进不了苍蝇（祸从口出。） |
| Quien mucho abarca, poco aprieta. | 贪多嚼不烂。 |
| Dime con quién andas y te diré quién eres. | 告诉我和谁在一起，我就能告诉你你是谁（近朱者赤。） |
| A caballo regalado no se le mira el diente. | 别看赠马的嘴（不要挑剔收到的礼物。） |
| Quien espera, desespera. | 等待的人会绝望（等待是痛苦的。） |
| Del dicho al hecho hay mucho trecho. | 说到和做到之间有很大的距离。 |
| No por mucho madrugar amanece más temprano. | 不会因为早起天就亮得更早（欲速则不达。） |
| Más vale prevenir que curar. | 预防胜于治疗。 |
| A mal tiempo, buena cara. | 面对坏天气，保持好脸色（苦中作乐。） |
| Quien ríe el último, ríe mejor. | 笑到最后的人笑得最好。 |
| Casa de herrero, cuchillo de palo. | 铁匠家用木刀（木匠家里没凳子。） |
| Perro que ladra no muerde. | 叫的狗不咬人。 |
| En todas partes cuecen habas. | 到处都在煮豆子（天下乌鸦一般黑。） |

## 常用习语（Modismos）

### 身体相关

| 习语 | 字面意思 | 实际含义 |
|------|---------|---------|
| Estar en las nubes | 在云里 | 心不在焉 |
| No tener pelos en la lengua | 舌头上没有毛 | 说话直率 |
| Meter la pata | 把爪子放进去 | 犯错误 |
| Dar en el clavo | 打在钉子上 | 一语中的 |
| Costar un ojo de la cara | 花掉脸上的一只眼 | 非常昂贵 |
| Quedarse en blanco | 变成白色 | 脑子一片空白 |
| Tomar el pelo | 抓住头发 | 捉弄某人 |
| Tener mala pata | 有坏爪子 | 运气不好 |
| Ser todo oídos | 全是耳朵 | 洗耳恭听 |
| Abrir el ojo | 睁开眼睛 | 小心/注意 |

### 动物相关

| 习语 | 字面意思 | 实际含义 |
|------|---------|---------|
| Tener un hambre de lobo | 有狼的饥饿 | 饿极了 |
| Ser un búho | 是猫头鹰 | 夜猫子 |
| Llover a cántaros | 下罐子雨 | 倾盆大雨 |
| Meter gato por liebre | 用猫代替兔 | 以次充好 |
| Ser un ratón de biblioteca | 是图书馆的老鼠 | 书虫 |
| Ponerse como un pulpo | 像章鱼一样 | 拿太多东西 |
| Dar gato por liebre | 给猫当兔 | 欺骗某人 |

### 日常表达

| 习语 | 含义 | 使用场景 |
|------|------|---------|
| ¡Qué rollo! | 多无聊啊！ | 表达厌烦 |
| No tengo ni idea. | 我一点都不知道。 | 表达不知道 |
| Me da igual. | 我无所谓。 | 表达不在乎 |
| ¡Qué va! | 怎么会！ | 表达不相信 |
| ¡Hombre! | 哎呀！ | 表达惊讶或高兴 |
| Tener mucha tela. | 有很多布料 | 很复杂/很多要说 |
| Ponerse las pilas | 装上电池 | 加把劲 |
| Dar la lata | 给罐头 | 烦扰某人 |
| Echar una mano | 伸出手 | 帮忙 |
| Ir al grano | 去看谷粒 | 直奔主题 |

## 拉美西班牙语 vs 西班牙本土差异

| 含义 | 西班牙 | 墨西哥 | 阿根廷 |
|------|--------|--------|--------|
| 很酷 | guay | chido | copado |
| 帅 | guapo | guapo | lindo |
| 傻瓜 | tonto | tonto | boludo |
| 钱 | pasta | lana | plata |
| 公共汽车 | autobús | camión | colectivo |
| 手机 | móvil | celular | celular |

## 使用场景建议

- **日常对话**：习语使表达更地道
- **正式写作**：谚语可用于议论文
- **跨文化理解**：不同国家的习语反映文化差异
