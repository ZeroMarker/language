# 西语国家文化简介与拉美/西班牙本土差异

## 西语全球分布

西班牙语是全球约 5.9 亿人使用的语言，分布在 20 个国家。

### 主要西语国家

| 中美洲 | 危地马拉、洪都拉斯、萨尔瓦多、尼加拉瓜、哥斯达黎加、巴拿马 | |

## 拉美西班牙语 vs 西班牙本土差异

### 人称代词差异

| 用法 | 西班牙 | 拉美 |
|------|--------|------|
| 你们 | vosotros | ustedes |
| 反身代词 | os | se |
| 动词变位 | -áis, -éis, -ís | -an, -en |

### vosotros vs ustedes

| 西班牙 | 拉美 |
|--------|------|
| Vosotros **habláis**. | Ustedes **hablan**. |
| Vosotros **coméis**. | Ustedes **comen**. |
| Vosotros **vivís**. | Ustedes **viven**. |

### 发音差异

| 特征 | 西班牙（卡斯蒂利亚） | 拉美 |
|------|-------------------|------|
| c/z | /θ/（th音） | /s/（s音） |
| s | /s/ | /s/ |
| ll | /ʎ/ | /ʝ/ 或 /ʃ/ |
| y | /ʝ/ | /ʝ/ 或 /ʃ/ |

**例子**：
- **casa**：西班牙 /ˈkasa/，拉美 /ˈkasa/（相同）
- **zapato**：西班牙 /θaˈpato/，拉美 /saˈpato/
- **cerveza**：西班牙 /θerˈβeθa/，拉美 /serˈβesa/

### 语法差异

| 用法 | 西班牙 | 拉美 |
|------|--------|------|
| 过去时 | he hablado（现在完成时） | hablé（简单过去时） |
| 命令式 | ¡Habla! | ¡Habla!（相同） |
| 虚拟式 | 更常用 | 使用较少 |

**例子**：
- 西班牙：**Hoy he comido** paella.（我今天吃了海鲜饭。）
- 拉美：**Hoy comí** paella.（我今天吃了海鲜饭。）

## 文化特色

### 西班牙

| 方面 | 特点 |
|------|------|
| 节日 | 奔牛节、番茄节、弗拉门戈 |
| 饮食 | 海鲜饭、塔帕斯、火腿 |
| 特点 | 午睡文化、晚餐时间晚（21:00-22:00） |

| 方面 | 特点 |

## 学习建议

1. **选择变体**：根据学习目的选择西班牙或拉美西班牙语
2. **了解差异**：两种变体互通，但需注意词汇差异
3. **多听多说**：通过电影、音乐、播客练习
4. **阅读材料**：选择目标变体的新闻和小说
5. **实际交流**：与母语者练习，注意发音差异
