# 西班牙语词根与构词法

## 常见拉丁词根

| 词根 | 含义 | 例词 |
|------|------|------|
| -duct-/-duz- | 引导 | conducir（驾驶）, producir（生产）, traducir（翻译） |
| -port- | 搬运 | portar（搬运）, importación（进口）, transporte（运输） |
| -scrib-/-script- | 写 | escribir（写）, descripción（描述）, inscripción（铭文） |
| -vis-/-vid- | 看 | visitar（参观）, visible（可见的）, vídeo（视频） |
| -spect- | 看 | espectáculo（演出）, inspeccionar（检查）, respetar（尊重） |
| -aud- | 听 | auditor（审计员）, audio（音频）, audiencia（听众） |
| -loqu-/-locut- | 说 | elocuencia（口才）, alocución（讲话）, interlocutor（对话者） |
| -mort- | 死 | muerte（死亡）, mortal（致命的）, inmortal（不朽的） |
| -man- | 手 | mano（手）, manual（手册）, manipular（操纵） |
| -cap-/-cep- | 抓/拿 | capturar（捕获）, aceptar（接受）, concepción（概念） |

## 常见前缀（Prefijos）

| 前缀 | 含义 | 例词 |
|------|------|------|
| re- | 再次、重新 | rehacer（重做）, reescribir（重写）, regresar（返回） |
| pre- | 在…之前 | prever（预见）, preferir（更喜欢）, nombre（名字） |
| des- | 相反、去除 | deshacer（拆开）, desorden（混乱）, desvestir（脱衣） |
| in-/im-/ir- | 不、非 | imposible（不可能）, incorrecto（不正确）, irregular（不规则） |
| sobre- | 在上、过度 | superficie（表面）, sorprender（惊讶）, sobrecalentamiento（过热） |
| sub- | 在下、不足 | submarino（潜水艇）, subestimar（低估） |
| entre- | 在…之间 | internacional（国际的）, entretener（娱乐） |
| trans- | 穿越、转变 | transformar（转变）, transportar（运输） |
| anti- | 反对 | antídoto（解毒剂）, antirracista（反种族主义的） |
| co- | 共同 | cooperar（合作）, coautor（合著者） |
| auto- | 自己 | automóvil（汽车）, autobiografía（自传） |
| multi- | 多 | multicultural（多元文化的）, multiplicar（乘/增加） |

## 常见后缀（Sufijos）

### 名词后缀

| 后缀 | 含义/功能 | 例词 |
|------|----------|------|
| -ción/-sión | 动作/状态 | nación（国家）, decisión（决定）, visión（视觉） |
| -miento | 动作/结果 | movimiento（运动）, gobierno（政府） |
| -dor/-dora | 施动者 | profesor（教授）, actor（演员） |
| -ista | 从业者 | periodista（记者）, pianista（钢琴家） |
| -dad/-idad | 性质/状态 | libertad（自由）, universidad（大学） |
| -aje | 动作/集合 | viaje（旅行）, garaje（车库）, queso（奶酪） |
| -ito/-ita | 小/爱称 | chiquito（小男孩）, casita（小房子） |
| -ero/-era | 从事者 | panadero（面包师）, panadera（女面包师） |

### 形容词后缀

| 后缀 | 含义 | 例词 |
|------|------|------|
| -able/-ible | 可…的 | posible（可能的）, agradable（愉快的） |
| -oso/-osa | 充满…的 | peligroso（危险的）, feliz（幸福的） |
| -ivo/-iva | 有…倾向的 | activo（活跃的）, creativo（创造性的） |
| -ico/-ica | 与…有关的 | histórico（历史的）, político（政治的） |
| -al/-el | 属于…的 | nacional（国家的）, natural（自然的） |

### 动词后缀

| 后缀 | 含义 | 例词 |
|------|------|------|
| -ar | 第一组动词 | hablar（说）, comprar（买） |
| -er | 第二组动词 | comer（吃）, beber（喝） |
| -ir | 第三组动词 | vivir（住）, partir（离开） |
| -ificar | 使…化 | simplificar（简化）, verificar（验证） |
| -izar | 使…化 | organizar（组织）, realizar（实现） |

## 构词方法

### 1. 派生（Derivación）
通过加前缀/后缀构成新词：
- grande → agrandar（变大）→ agrandamiento（增大）

### 2. 复合（Composición）
两个词组合成新词：
- saco + dormir = saco de dormir（睡袋）
- paraguas（雨伞）= para + aguas

### 3. 转化（Conversión）
词性转变：
- el amor（爱，动词 → 名词）
- la limpia（清洁，形容词 → 名词）

### 4. 缩略（Abreviación）
- automóvil → auto（汽车）
- publicidad → publi（广告）
- profesor → profe（老师，口语）

### 5. 混合（Mezcla）
- helicóptero + avión = helicóptero（直升机）
- desayuno（早餐）= des + ayuno（打破禁食）
