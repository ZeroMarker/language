# 法语词根与构词法

## 常见拉丁词根

| 词根 | 含义 | 例词 |
|------|------|------|
| -duct-/-duit- | 引导 | conduire（驾驶）, produire（生产）, traduire（翻译） |
| -port- | 搬运 | porter（搬运）, importation（进口）, transport（运输） |
| -scrib-/-script- | 写 | écrire（写）, description（描述）, inscription（铭文） |
| -vis-/-vid- | 看 | visiter（参观）, visible（可见的）, vidéo（视频） |
| -spect- | 看 | spectacle（演出）, inspecter（检查）, respecter（尊重） |
| -aud- | 听 | auditeur（听众）, audio（音频）, auditorat（听众群） |
| -loqu-/-locut- | 说 | éloquence（口才）, allocution（讲话）, interlocuteur（对话者） |
| -mort- | 死 | mort（死亡）, mortalité（死亡率）, immortalité（不朽） |
| -man- | 手 | manuscrit（手稿）, manuel（手册）, manipuler（操纵） |
| -cap-/-cep- | 抓/拿 | capturer（捕获）, accepter（接受）, conception（概念） |

## 常见前缀（Préfixes）

| 前缀 | 含义 | 例词 |
|------|------|------|
| re-/ré- | 再次、重新 | refaire（重做）, réécrire（重写）, revenir（回来） |
| pré- | 在…之前 | prévoir（预见）, préférer（更喜欢）, prénom（名字） |
| dé-/dés- | 相反、去除 | défaire（拆开）, désordre（混乱）, déshabiller（脱衣） |
| in-/im-/ir- | 不、非 | impossible（不可能）, incorrect（不正确）, irrégulier（不规则） |
| sur- | 在上、过度 | surface（表面）, surprendre（惊讶）, surchauffe（过热） |
| sous- | 在下、不足 | sous-marin（潜水艇）, sous-estimer（低估） |
| inter- | 在…之间 | international（国际的）, interdit（禁止） |
| trans- | 穿越、转变 | transformer（转变）, transporter（运输） |
| anti- | 反对 | antidote（解毒剂）, antiraciste（反种族主义的） |
| co- | 共同 | coopérer（合作）, coauteur（合著者） |
| auto- | 自己 | automobile（汽车）, autobiographie（自传） |
| multi- | 多 | multiculturel（多元文化的）, multiplier（乘/增加） |

## 常见后缀（Suffixes）

### 名词后缀

| 后缀 | 含义/功能 | 例词 |
|------|----------|------|
| -tion/-sion | 动作/状态 | nation（国家）, décision（决定）, vision（视觉） |
| -ment | 动作/结果 | mouvement（运动）, gouvernement（政府） |
| -eur | 施动者 | professeur（教授）, acteur（演员） |
| -iste | 从业者 | journaliste（记者）, pianiste（钢琴家） |
| -ité | 性质/状态 | liberté（自由）, université（大学） |
| -age | 动作/集合 | voyage（旅行）, garage（车库）, fromage（奶酪） |
| -ette | 小/阴性 | fourchette（叉子）, cigarette（香烟） |
| -eau/-el | 小 | château（城堡）, modèle（模型） |

### 形容词后缀

| 后缀 | 含义 | 例词 |
|------|------|------|
| -able/-ible | 可…的 | possible（可能的）, agréable（愉快的） |
| -eux/-ieux | 充满…的 | dangereux（危险的）, heureux（幸福的） |
| -if/-ive | 有…倾向的 | actif（活跃的）, créatif（创造性的） |
| -ique | 与…有关的 | historique（历史的）, politique（政治的） |
| -al/-el | 属于…的 | national（国家的）, naturel（自然的） |

### 动词后缀

| 后缀 | 含义 | 例词 |
|------|------|------|
| -ir | 使成为 | finir（完成）, grandir（长大） |
| -ifier | 使…化 | simplifier（简化）, vérifier（验证） |
| -iser | 使…化 | organiser（组织）, réaliser（实现） |

## 构词方法

### 1. 派生（Dérivation）
通过加前缀/后缀构成新词：
- grand → grandir（变大）→ grandissement（增大）

### 2. 复合（Composition）
两个词组合成新词：
- porte + feuille = portefeuille（钱包）
- timbre + poste = timbre-poste（邮票）

### 3. 转化（Conversion）
词性转变：
- un pourboire（小费，动词短语 → 名词）
- le bleu（蓝色，形容词 → 名词）

### 4. 缩略（Abréviation）
- métropolitain → métro（地铁）
- automobile → auto（汽车）
- publicité → pub（广告）
