# 法语常用谚语与习语

## 经典谚语（Proverbes）

| 法语 | 中文含义 |
|------|---------|
| Petit à petit, l'oiseau fait son nid. | 积少成多（鸟儿一点点筑巢。） |
| Qui vivra verra. | 日久自明（谁活着谁就能看到。） |
| L'habit ne fait pas le moine. | 人不可貌相（衣服不能造就僧侣。） |
| Il ne faut pas mettre la charrue avant les bœufs. | 不要本末倒置（不要把犁放在牛前面。） |
| Après la pluie, le beau temps. | 雨过天晴。 |
| Qui sème le vent récolte la tempête. | 自作自受（种风者收暴风。） |
| Mieux vaut tard que jamais. | 迟到总比不到好。 |
| Ce n'est pas la mer à boire. | 这不是什么难事（这不是喝干大海。） |
| Il faut battre le fer quand il est chaud. | 趁热打铁。 |
| Pierre qui roule n'amasse pas mousse. | 滚石不生苔（常换工作难积累。） |
| Les murs ont des oreilles. | 隔墙有耳。 |
| Tel père, tel fils. | 有其父必有其子。 |
| Tous les chemins mènent à Rome. | 条条大路通罗马。 |
| Qui ne risque rien n'a rien. | 不入虎穴，焉得虎子。 |
| La nuit tous les chats sont gris. | 黑夜里猫都是灰色的（昏暗中难辨好坏。） |

## 常用习语表达（Expressions idiomatiques）

### 身体相关

| 习语 | 字面意思 | 实际含义 |
|------|---------|---------|
| Avoir le coup de foudre | 被雷击 | 一见钟情 |
| Coûter les yeux de la tête | 花掉眼珠 | 非常昂贵 |
| Avoir le cafard | 有蟑螂 | 心情低落 |
| Se creuser la tête | 挖自己的头 | 绞尽脑汁 |
| Tourner la tête | 转头 | 令人神魂颠倒 |
| Avoir bon dos | 背好 | 被当作借口（替罪羊） |
| Casser les pieds | 打断脚 | 烦扰某人 |
| En avoir ras le bol | 碗满了 | 受够了 |
| Avoir la pêche | 有桃子 | 精力充沛 |
| Donner sa langue au chat | 把舌头给猫 | 放弃猜测 |

### 动物相关

| 习语 | 字面意思 | 实际含义 |
|------|---------|---------|
| Avoir une faim de loup | 有狼的饥饿 | 饿极了 |
| Quand les poules auront des dents | 母鸡长牙时 | 永远不可能 |
| Être un lion | 是狮子 | 勇敢无畏 |
| Avoir d'autres chats à fouetter | 有其他猫要打 | 有更重要的事要做 |
| Faire le pied de grue | 做鹤的脚 | 站着等很久 |
| Poser un lapin | 放一只兔子 | 放鸽子（爽约） |

### 日常表达

| 习语 | 含义 | 例句 |
|------|------|------|
| C'est la vie | 这就是生活 | 表示接受现实 |
| N'importe quoi | 无论什么 | 胡说八道 |
| Ça me dit quelque chose | 这对我说些什么 | 有点印象 |
| Mettre les pieds dans le plat | 把脚放进盘子 | 说话太直 |
| Faire chou blanc | 做白菜 | 白费力气 |
| Avoir le beurre et l'argent du beurre | 既要有黄油又要有买黄油的钱 | 鱼和熊掌兼得 |
| Tomber dans les pommes | 掉进苹果堆 | 晕倒 |
| Couper la poire en deux | 把梨切成两半 | 各退一步 |
| Passer du coq à l'âne | 从公鸡到驴 | 说话东拉西扯 |
| Mettre de l'eau dans son vin | 往酒里加水 | 降低要求/让步 |

## 使用场景建议

- **写作**：谚语可用于议论文开头或结尾增强说服力
- **口语**：习语使表达更地道，但注意场合（正式场合少用俚语）
- **理解**：遇到不认识的习语不要逐字翻译，要查整体含义
