# 法语国家文化简介与敬语系统

## 法语全球分布

法语是全球约 3 亿人使用的语言，分布在五大洲 29 个国家。

### 主要法语国家/地区

| 地区 | 国家 | 特点 |
|------|------|------|
| 欧洲 | 法国、比利时、瑞士、卢森堡 | 标准法语发源地 |
| 北非 | 摩洛哥、阿尔及利亚、突尼斯 | 阿拉伯语影响，殖民历史 |
| 西非 | 塞内加尔、科特迪瓦、马里、几内亚 | 法语为官方语言，多语并存 |
| 中非 | 刚果（布）、喀麦隆、乍得 | 法语为行政语言 |
| 北美 | 加拿大（魁北克、新不伦瑞克） | 魁北克法语有独特词汇和发音 |
| 大洋洲 | 新喀里多尼亚、法属波利尼西亚 | 法国海外领土 |

## 敬语与称呼系统

### tu vs vous

| 代词 | 使用场景 |
|------|---------|
| **tu** | 朋友、家人、同龄人之间；对孩子说话；部分职场内部 |
| **vous** | 初次见面、陌生人、长辈、上级、正式场合 |

### 使用原则

- **年龄**：对比自己年长的人通常用 vous
- **社会关系**：不熟的人用 vous，熟了之后由年长者或地位较高者提议改用 tu
- **场合**：商务、官方场合几乎一律用 vous
- **地区差异**：魁北克比法国更早使用 tu；比利时在商店也常用 tu

### 从 vous 到 tu 的过渡

当法国人说：
- "On se tutoie ?"（我们用 tu 吧？）
- "Tutoie-moi."（用 tu 称呼我吧。）

表示关系进入更亲近的阶段。**不建议由你主动提出**。

### 称呼用语

| 场景 | 称呼 |
|------|------|
| 男性（正式） | Monsieur（先生） |
| 女性（正式） | Madame（女士） |
| 未婚女性（较正式） | Mademoiselle（小姐，现已少用） |
| 复数 | Messieurs, Mesdames |
| 职业头衔 | Docteur, Professeur（直接用头衔称呼） |

> **注意**：法国近年来倾向于不再区分 Madame/Mademoiselle，统称 Madame。

### 问候方式

| 场景 | 表达 |
|------|------|
| 正式 | Bonjour, Monsieur/Madame. |
| 非正式 | Salut ! / Coucou ! |
| 晚上 | Bonsoir. |
| 告别（正式） | Au revoir, Monsieur/Madame. |
| 告别（非正式） | Salut ! / À bientôt ! / À plus ! |

### 贴面礼（La bise）

- 法国人见面/告别时行贴面礼（脸颊相触，同时发出 mwah 声）
- 贴几次因地区而异：巴黎 2 次，南部 3 次，部分地区 4 次
- 商务场合通常握手；与非常亲近的人才行贴面礼
- 男性之间通常握手，除非是亲属或密友

## 法国文化小贴士

### 餐饮文化
- 正餐顺序：entrée（前菜）→ plat principal（主菜）→ fromage（奶酪）→ dessert（甜点）→ café
- 法国人午餐时间较长（1-2 小时），不习惯边走边吃
- 面包直接放桌上，不放盘子里

### 社交礼仪
- 进入商店要先说 Bonjour
- 被邀请做客通常带一瓶酒或一束花（不要带偶数花，那是葬礼用的）
- 不要在非用餐时间讨论工作

### 魁北克法语的特殊性
- 问候：Bonjour → Salut（更常用）
- 常用 Sacrebleu → Tabernac（感叹词，但后者是粗话）
- 称呼：几乎所有人都用 tu，包括部分商业场合
- 法式法语的 seventy（soixante-dix）在魁北克有时说 septante
