# 拉丁语常用谚语与格言

## 罗马谚语（Proverbia Rōmāna）

| 拉丁语 | 中文含义 |
|--------|---------|
| Amor vincit omnia. | 爱征服一切。 |
| Carpe diem. | 抓住今天（及时行乐）。 |
| Dum spīrō, spērō. | 只要我呼吸，我就有希望。 |
| Errāre hūmānum est. | 犯错是人之常情。 |
| Fortes fortūna iuvat. | 命运眷顾勇者。 |
| Memento morī. | 记住你终有一死。 |
| Nōlī mittere margarītās ante porcōs. | 不要把珍珠丢在猪前（对牛弹琴）。 |
| Quod licet Iovī, nōn licet bovī. | 朱庇特可以做的事，牛不可以做（只许州官放火）。 |
| Rōma nōn ūnō diē aedificāta est. | 罗马不是一天建成的。 |
| Sī vīs pācem, parā bellum. | 你想要和平，就准备战争。 |
| Tempus fugit. | 时间飞逝。 |
| Vēnī, vīdī, vīcī. | 我来，我见，我征服。（凯撒名言） |
| Verba volant, scripta manent. | 话语飞逝，文字长存。 |
| Vīta brevis, ars longa. | 生命短暂，艺术永恒。 |
| Amīcus certus in rē incertā cernitur. | 患难见真情。 |

## 哲学格言（Sententiae philosophicae）

| 拉丁语 | 中文含义 | 出处 |
|--------|---------|------|
| Cōgitō, ergō sum. | 我思故我在。 | 笛卡尔 |
| Scientia potentia est. | 知识就是力量。 | 培根 |
| Homo homini lupus. | 人对人是狼。 | 普劳图斯 |
| Nīl dēspērandum. | 永远不要绝望。 | 贺拉斯 |
| Docēre discendum est. | 教即是学。 | 塞涅卡 |
| In vīnō vēritās. | 酒中有真理。 | 老普林尼 |
| Nōn scholae sed vītae discimus. | 我们不是为学校而是为生活而学习。 | 塞涅卡 |
| Ars longa, vīta brevis. | 艺术长存，人生短暂。 | 希波克拉底 |
| Audācēs fortūna iuvat. | 命运眷顾大胆的人。 | 维吉尔 |
| Praedīcāre dē praesentibus. | 不要对未来过于乐观。 | |

## 法律与政治格言

| 拉丁语 | 中文含义 |
|--------|---------|
| Dūra lēx, sed lēx. | 法律虽严，但仍是法律。 |
| Iūstitia omnibus. | 对所有人公正。 |
| Pars pro toto. | 以部分代整体。 |
| Audi alteram partem. | 听取另一方意见。 |
| Ignōrantia iūris nōn excusat. | 不知法不能免责。 |
| Cui bonō? | 对谁有利？ |
| Prīmum nōlī nocēre. | 首先，不要伤害。 |

## 宗教与道德格言

| 拉丁语 | 中文含义 |
|--------|---------|
| Deus ex machinā. | 机械降神（意外的解救）。 |
| Pax vōbīscum. | 愿平安与你们同在。 |
| Anima munda. | 纯洁的灵魂。 |
| Crux decussāta. | 十字架。 |
| Fiat lūx. | 要有光。 |
| Gloria in excelsis Deō. | 荣耀归于至高的上帝。 |

## 学术与科学格言

| 拉丁语 | 中文含义 |
|--------|---------|
| Nātūra nōn facit saltum. | 自然无飞跃。 |
| Ex nihīlō nihil fit. | 无中不能生有。 |
| Tabula rāsa. | 白板（空白状态）。 |
| Modus operandī. | 操作方法。 |
| Ad hoc. | 特定的/临时的。 |
| Per capita. | 每人。 |
| Vice versā. | 反之亦然。 |
| Status quō. | 现状。 |

## 日常拉丁语表达

| 拉丁语 | 中文含义 |
|--------|---------|
| Salvē! / Salvēte! | 你好！（单数/复数） |
| Valē! / Valēte! | 再见！ |
| Grātiās tibi agō. | 谢谢你。 |
| Quid agis? | 你好吗？（字面：你在做什么？） |
| Bene. | 好。 |
| Ita vērō. | 是的。 |
| Nōn. | 不。 |
| Ignōscite mihi. | 对不起。 |
| Quid est nōmen tibi? | 你叫什么名字？ |
| Nōmen mihi est… | 我的名字是… |

## 学习建议

1. **理解语境**：了解格言的历史背景
2. **记忆发音**：拉丁语发音规则较规律
3. **分析语法**：用格言练习语法分析
4. **文化联系**：许多英语词汇源自拉丁语
