# 拉丁语完整格变化表（五种变格法）

| 变格法 | 属格单数词尾 | 例子 |
|--------|-------------|------|
| 第一变格 | -ae | puella（女孩）, terra（土地） |
| 第二变格 | -ī | dominus（主人）, bellum（战争） |
| 第三变格 | -is | rex（国王）, civis（公民） |
| 第四变格 | -ūs | exercitus（军队）, manus（手） |
| 第五变格 | -ēī | rēs（事物）, diēs（天） |

## 六格功能总结

| 格 | 主要功能 | 例子 |
|----|---------|------|
| 主格（Nominative） | 主语、表语 | **Puella** cantat.（女孩唱歌。） |
| 属格（Genitive） | 所有格、部分 | Liber **puellae**.（女孩的书。） |
| 与格（Dative） | 间接宾语 | **Puellae** librum dat.（他给女孩书。） |
| 宾格（Accusative） | 直接宾语、方向 | **Puellam** video.（我看见女孩。） |
| 夺格（Ablative） | 工具、方式、地点 | **Cum puellā**.（和女孩一起。） |
| 呼格（Vocative） | 称呼 | **Puella**, venī!（女孩，过来！） |

## 第三变格名词性别判断

| 类型 | 特征 | 常见性别 |
|------|------|---------|
| -or, -ōs | | 阳性 |
| -ās, -ēs, -is, -x | | 阴性 |
| -ar, -al, -e, -men | | 中性 |

## 变格法学习建议

1. **先记属格单数**：确定变格法类型
2. **记住词干**：去掉属格单数词尾 -is, -ae, -ī 等
3. **按格记忆**：先掌握主格、属格、宾格三个最常用格
4. **大量阅读**：在语境中熟悉格的用法
