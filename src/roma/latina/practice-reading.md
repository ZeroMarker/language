# 拉丁语 阅读练习

## 基础句子

| 拉丁语 | 中文 |
|--------|------|
| Puella rosam habet. | 女孩有一朵玫瑰。 |
| Puer librum legit. | 男孩在读书。 |
| Via longa est. | 路很长。 |
| Tempus fugit. | 时间飞逝。 |
| Amor vincit omnia. | 爱征服一切。 |

## 经典名言

| 拉丁语 | 中文 |
|--------|------|
| Veni, vidi, vici. | 我来，我见，我征服。 |
| Cogito, ergo sum. | 我思故我在。 |
| Carpe diem. | 把握当下。 |

## 练习建议

1. 识别名词的格变化
2. 识别动词的时态和人称
3. 理解句子结构（SOV）
