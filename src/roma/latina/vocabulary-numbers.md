# 拉丁语 数字与计数

## 基数词

| 数字 | 拉丁语 |
|------|--------|
| 1 | ūnus |
| 2 | duo |
| 3 | trēs |
| 4 | quattuor |
| 5 | quīnque |
| 6 | sex |
| 7 | septem |
| 8 | octō |
| 9 | novem |
| 10 | decem |

## 特殊规则

- 11: undecim, 12: duodecim
- 20: vīgintī, 30: trīgintā
- 100: centum, 1000: mīlle

## 序数词

prīmus (第一), secundus (第二), tertius (第三)
