# 拉丁语 名词变格

## 五种变格法

| 变格法 | 属格词尾 | 例词 |
|--------|----------|------|
| 第一变格 | -ae | puella (女孩) |
| 第二变格 | -ī | dominus (主人) |
| 第三变格 | -is | rex (国王) |
| 第四变格 | -ūs | portus (港口) |
| 第五变格 | -eī | rēs (事情) |

## 第一变格示例（puella）

| 格 | 单数 | 复数 |
|----|------|------|
| 主格 | puella | puellae |
| 属格 | puellae | puellārum |
| 与格 | puellae | puellīs |
| 宾格 | puellam | puellās |
| 夺格 | puellā | puellīs |

## 格的功能

- 主格：主语
- 属格：所有格
- 与格：间接宾语
- 宾格：直接宾语
- 夺格：工具、方式
