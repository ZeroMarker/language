# 拉丁语日常表达

## 问候与告别

| 拉丁语 | 中文 | 说明 |
|--------|------|------|
| Salvē. | 你好。 | 对一人说 |
| Salvēte. | 你们好。 | 对多人说 |
| Valē. | 再见。/保重。 | 对一人说 |
| Valēte. | 再见。/保重。 | 对多人说 |
| Quid agis? | 你好吗？ | 非正式 |
| Bene est. | 我很好。 | 回答 |
| Bonum diem. | 日安。 | 祝福语 |
| Bonam noctem. | 晚安。 | 睡前 |
| Bene valē. | 祝好。 | 告别 |

## 课堂用语

| 拉丁语 | 中文 |
|--------|------|
| Quid significat...? | ……是什么意思？ |
| Quōmodo dīcitur...? | ……怎么说？ |
| Iterum dīc, quaesō. | 请再说一遍。 |
| Tarde dīc, quaesō. | 请说慢一点。 |
| Nōn intellegō. | 我不明白。 |
| Ita. | 是。 |
| Minimē. | 不是。 |
| Librum habeō. | 我有一本书。 |
| Magister/Magistra, quaesō... | 老师，请问…… |

## 常见用语

| 拉丁语 | 中文 |
|--------|------|
| Grātiās tibi agō. | 谢谢。 |
| Grātiās. | 谢谢。 |
| Quaesō. | 请。/劳驾。 |
| Ignōsce mihi. | 对不起。/请原谅。 |
| Sīs. | 请。（缩略式） |
| Salvē! | 欢迎！ |
| Responde, quaesō. | 请回答。 |
| Sede, quaesō. | 请坐。 |
| Vērum est. | 是真的。 |
| Falsum est. | 是假的。 |

## 场景短句

| 拉丁语 | 中文 |
|--------|------|
| Quota hōra est? | 现在几点？ |
| Hodiē est diēs ... | 今天是……（星期几） |
| Quis est? | 那是谁？ |
| Quid est? | 那是什么？ |
| Ubi est lātrīna? | 厕所在哪里？ |
| Portam aperī, quaesō. | 请开门。 |
| Sīc. | 是的。/确实。 |
