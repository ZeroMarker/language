# 拉丁语输入法说明

## 输入法方案

### 方案一：使用英语键盘 + 长音符号

拉丁语需要输入长音符号（macron）：ā, ē, ī, ō, ū

#### Windows 系统

**方法 1：使用 Alt 代码**

| 字母 | Alt 代码 |
|------|---------|
| ā | Alt + 0257 |
| ē | Alt + 0275 |
| ī | Alt + 0299 |
| ō | Alt + 0333 |
| ū | Alt + 0363 |
| Ā | Alt + 0256 |
| Ē | Alt + 0274 |
| Ī | Alt + 0298 |
| Ō | Alt + 0332 |
| Ū | Alt + 0362 |

**方法 2：使用字符映射表**
1. 按 Win + R，输入 charmap
2. 找到所需的长音字母
3. 复制粘贴

**方法 3：安装拉丁语键盘布局**
1. 设置 → 时间和语言 → 语言 → 添加语言
2. 搜索 Latin 或添加拉丁语键盘
3. 使用切换键输入特殊字符

### 方案二：使用 Unicode 输入

| 字符 | Unicode |
|------|---------|
| ā | U+0101 |
| ē | U+0113 |
| ī | U+012B |
| ō | U+014D |
| ū | U+016B |
| Ā | U+0100 |
| Ē | U+0112 |
| Ī | U+012A |
| Ō | U+014C |
| Ū | U+016A |

### 方案三：使用 LaTeX

在 LaTeX 中输入拉丁语长音：
- \=a → ā
- \=e → ē
- \=i → ī
- \=o → ō
- \=u → ū

### 方案四：在线工具

- **Lexilogos**：https://www.lexilogos.com/keyboard/latin.htm
- **TypeIt**：https://typeit.org/

## 编码与字体

### 推荐编码
- **UTF-8**：支持所有拉丁语字符
- **ISO 8859-1**：基本拉丁字符

### 推荐字体
- **Serif**：Times New Roman, Georgia, Garamond
- **Monospace**：Courier New, Consolas
- **专业字体**：Junicode, Gentium

## 转写系统

拉丁语的罗马化就是其本身，但需要注意：

| 古典发音 | 教会发音 | 说明 |
|----------|---------|------|
| c = /k/ | c = /k/ 或 /tʃ/ | 教会发音在 e, i 前读 /tʃ/ |
| v = /w/ | v = /v/ | 古典发音为半元音 |
| ae = /ae/ | ae = /e/ | 教会发音合并 |
| oe = /oe/ | oe = /e/ | 教会发音合并 |

## 音标系统

### 古典拉丁语发音（恢复发音）

| 字母 | 音标 | 例子 |
|------|------|------|
| a | /a/ | amāre |
| ā | /aː/ | rēgīna |
| e | /e/ | bene |
| ē | /eː/ | rēx |
| i | /i/ | sī |
| ī | /iː/ | vīta |
| o | /o/ | bonus |
| ō | /oː/ | nōmen |
| u | /u/ | sum |
| ū | /uː/ | lūna |

### 教会拉丁语发音

| 字母 | 音标 | 例子 |
|------|------|------|
| c (在 e, i 前) | /tʃ/ | caelum → /tʃ/ |
| sc (在 e, i 前) | /ʃ/ | scientia → /ʃ/ |
| gn | /ɲ/ | magnus → /ɲ/ |

## 实用建议

1. **初学者**：可暂不标记长音，先掌握基本拼写
2. **进阶学习**：建议使用长音符号，有助于掌握重音规则
3. **学术写作**：必须使用正确的长音符号
4. **发音练习**：区分古典发音和教会发音
