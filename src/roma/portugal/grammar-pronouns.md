# 葡萄牙语代词系统详解

## 主语代词（Pronomes pessoais sujeito）

| 人称 | 代词 | 说明 |
|------|------|------|
| eu | 我 | |
| tu | 你 | 非正式（葡葡更常用） |
| você | 你/您 | 巴葡更常用，动词用第三人称 |
| ele/ela | 他/她 | |
| nós | 我们 | |
| vós | 你们 | 古语，现极少用 |
| vocês | 你们 | 动词用第三人称复数 |
| eles/elas | 他们/她们 | |

## 直接宾语代词（OD: Objeto direto）

| 人称 | 代词 | 例句 |
|------|------|------|
| me | 我 | Ele **me** viu.（他看见了我。） |
| te | 你 | Eu **te** amo.（我爱你。） |
| o/a (lo/la) | 他/她/它 | Eu **o** conheço.（我认识他。） |
| nos | 我们 | Eles **nos** convidaram.（他们邀请了我们。） |
| vos | 你们 | Eu **vos** ajudo.（我帮助你们。） |
| os/as (los/las) | 他们/她们 | Eu **os** vi.（我看见了他们。） |

> **注意**：在元音或鼻音后，o/a 变为 lo/la/los/las。

## 间接宾语代词（OI: Objeto indireto）

| 人称 | 代词 | 例句 |
|------|------|------|
| me (mim) | 给我 | Ele **me** deu um livro.（他给了我一本书。） |
| te (ti) | 给你 | Eu **te** enviei uma carta.（我给你寄了一封信。） |
| lhe | 给他/她 | Eu **lhe** dei o livro.（我把书给了他。） |
| nos (nós) | 给我们 | Ela **nos** contou uma história.（她给我们讲了一个故事。） |
| vos (vós) | 给你们 | Eu **vos** agradeço.（我感谢你们。） |
| lhes | 给他们/她们 | Eu **lhes** respondi.（我回复了他们。） |

## 重读代词（Pronomes tônicos）

| 人称 | 代词 | 用法 |
|------|------|------|
| mim | 我 | 介词后、强调 |
| ti | 你 | 介词后、强调 |
| ele/ela | 他/她 | 介词后、强调 |
| nós | 我们 | 介词后、强调 |
| vós | 你们 | 介词后、强调 |
| eles/elas | 他们/她们 | 介词后、强调 |

**例句**：
- É **para mim**?（这是给我的吗？）
- **Com ele**.（和他一起。）
- **Para nós**.（给我们。）

## 反身代词（Pronomes reflexivos）

| 人称 | 代词 | 例句（lavar-se 洗） |
|------|------|---------------------|
| eu | me | Eu **me** lavo. |
| tu | te | Tu **te** lavas. |
| ele/ela | se | Ele **se** lava. |
| nós | nos | Nós **nos** lavamos. |
| vocês | se | Vocês **se** lavam. |
| eles/elas | se | Eles **se** lavam. |

## 巴葡 vs 欧葡代词差异

| 用法 | 巴西葡萄牙语 | 欧洲葡萄牙语 |
|------|-------------|-------------|
| 主语代词 | 常用 você | 常用 tu |
| 直接宾语 | 常省略或用 o/a | 保留 lo/la |
| 间接宾语 | 常用 pra mim | 常用 mim |
| 反身代词 | 前置：me lavo | 后置：lavo-me |

## 代词位置规则

### 欧葡（标准）
1. **陈述句**：代词放在动词后（后置）
   - Ele viu-**me**.（他看见了我。）

2. **否定句**：代词仍在动词后
   - Ele não viu-**me**.（他没看见我。）

3. **疑问句**：代词在动词后
   - Viste-**o**?（你看见他了吗？）

### 巴葡（口语）
1. **陈述句**：代词放在动词前（前置）
   - Ele **me** viu.（他看见了我。）

2. **否定句**：代词在动词前
   - Ele não **me** viu.（他没看见我。）

## 常见错误

| 错误 | 正确 | 说明 |
|------|------|------|
| Eu viu ele. | Eu **o** vi. | 用代词形式 |
| Me dá um livro. | Dá-**me** um livro.（欧葡）/ **Me** dá um livro.（巴葡） | 位置差异 |
| Para eu. | Para **mim**. | 介词后用重读形式 |
