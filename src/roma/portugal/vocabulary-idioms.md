# 葡萄牙语常用谚语与习语

## 经典谚语（Provérbios）

| 葡萄牙语 | 中文含义 |
|----------|---------|
| Água mole em pedra dura, tanto bate até que fura. | 水滴石穿。 |
| Quem cedo madruga, Deus ajuda. | 早起的人得到上帝帮助（早起的鸟儿有虫吃。） |
| Quem tem boca vai a Roma. | 有嘴就能去罗马（嘴甜走天下。） |
| Cada macaco no seu galho. | 每只猴子在自己的树枝上（各司其职。） |
| Não coloque o carro na frente dos bois. | 不要把车放在牛前面（不要本末倒置。） |
| Quem não arrisca, não petisca. | 不冒险就没有零食（不入虎穴焉得虎子。） |
| Mais vale tarde do que nunca. | 迟到总比不到好。 |
| Quem semeia ventos, colhe tempestades. | 种风者收暴风（自作自受。） |
| Em terra de cego, quem tem um olho é rege. | 盲人国里独眼为王（矮子里面拔将军。） |
| Devagar se vai ao longe. | 慢慢走才能走得远（欲速则不达。） |
| Casa de ferreiro, espeto de pau. | 铁匠家用木叉（木匠家里没凳子。） |
| Filho de peixe, peixinho é. | 鱼的儿子是小鱼（有其父必有其子。） |

## 常用习语（Expressões idiomáticas）

### 身体相关

| 习语 | 字面意思 | 实际含义 |
|------|---------|---------|
| Estar com a pulga atrás da orelha | 耳朵后面有跳蚤 | 感到怀疑 |
| Dar com a língua nos dentes | 舌头碰到牙齿 | 说漏嘴 |
| Não ter papas na língua | 舌头上没有糊糊 | 说话直率 |
| Meter a pata | 把爪子放进去 | 犯错误 |
| Virar as costas | 转过背 | 背叛/抛弃 |
| Abrir o jogo | 打开游戏 | 摊牌/坦白 |
| Quebrar o gelo | 打破冰 | 打破僵局 |
| Dar um nó na cabeça | 在头上打个结 | 绞尽脑汁 |

### 动物相关

| 习语 | 字面意思 | 实际含义 |
|------|---------|---------|
| Ter uma fome de lobo | 有狼的饥饿 | 饿极了 |
| Ser uma galinha | 是一只母鸡 | 傻乎乎的人 |
| Ser um burro | 是一头驴 | 笨蛋 |
| Correr como uma lebre | 像兔子一样跑 | 跑得很快 |
| Dormir como um log | 像原木一样睡 | 睡得很沉 |
| Ter olhos de lince | 有猞猁的眼睛 | 目光敏锐 |

### 日常表达

| 习语 | 含义 | 使用场景 |
|------|------|---------|
| Quebra-galho | 折断树枝 | 临时解决方案 |
| Mão na roda | 手在轮子上 | 帮大忙 |
| Pagar o pato | 付鸭子的钱 | 背黑锅 |
| Ficar de boca aberta | 嘴巴张开 | 惊呆了 |
| Dar uma de João-sem-brazo | 做无臂若昂 | 装作不知道 |
| Encher linguiça | 填香肠 | 说废话/凑字数 |
| Pôr a mão na massa | 把手放进面团 | 亲自动手 |
| Ser a cereja do bolo | 是蛋糕上的樱桃 | 锦上添花 |
| Ir pelo ralo | 走下水道 | 化为泡影 |
| Botar a boca no trombone | 把嘴放在喇叭上 | 公开说出真相 |

## 巴葡 vs 欧葡习语差异

| 含义 | 巴西葡萄牙语 | 欧洲葡萄牙语 |
|------|-------------|-------------|
| 没钱 | Estar sem grana | Estar sem massa |
| 傻瓜 | Trouxa | Totó |
| 警察 | Polícia / Pó | Polícia / GNR |
| 漂亮 | Bonito/a | Giro/a |
| 酷 | Legal | Fixe |

## 使用场景建议

- **日常对话**：习语使表达更地道
- **正式写作**：谚语可用于议论文
- **跨文化理解**：巴葡和欧葡习语差异反映文化差异
