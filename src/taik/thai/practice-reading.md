## 中级：对话练习

### 在餐厅

```
A: สวัสดีครับ ขอเมนูหน่อย
   sawatdi khrap, kho menu noi
   你好，请给我菜单。

B: ได้ค่ะ นี่เลย
   dai kha, ni loei
   好的，给您。

A: เอาผัดไทยหนึ่งจาน กับน้ำส้มหนึ่งแก้ว
   ao phat thai nueng chan, kap nam som nueng kaew
   要一盘泰式炒面，和一杯橙汁。

B: ค่ะ รอสักครู่
   kha, ro sak khru
   好的，请稍等。

A: อร่อยมากครับ เช็คบิลด้วย
   aroi mak khrap, chek bin duai
   很好吃，请结账。

B: ทั้งหมดร้อยห้าสิบบาทค่ะ
   thang mot roi ha sip ba kha
   一共150铢。
```

### 问路

```
A: โทษครับ สถานีรถไฟอยู่ที่ไหน
   thot khrap, sathani rot fai yu thi nai
   请问，火车站在哪里？

B: ตรงไป แล้วเลี้ยวซ้าย
   trong pai, laew liao sai
   直走，然后左转。

A: ไกลไหมครับ
   klai mai khrap
   远吗？

B: ไม่ไกลมาก เดินสิบนาที
   mai klai mak, doein sip na thi
   不太远，走十分钟。
```

### 购物

```
A: ตัวนี้เท่าไหร่
   tua ni thao rai
   这件多少钱？

B: สามร้อยบาท
   sam roi ba
   300铢。

A: แพงไป ลดหน่อยได้ไหม
   phaeng pai, lot noi dai mai
   太贵了，能便宜点吗？

B: ได้ค่ะ สองร้อยห้าสิบบาท
   dai kha, song roi ha sip ba
   好的，250铢。

A: เอาเลย
   ao loei
   要了。
```

## 阅读技巧

### 1. 识别词界

泰语没有空格分词，需要学会识别词界：
- 常见前缀：การ, ความ, สถาน, ประ
- 常见后词：ๆ, ครับ, ค่ะ, ไหม
- 数字和量词通常成组出现

### 2. 利用语境

- 动词通常在主语后、宾语前
- 时间词通常在句首或动词前
- 形容词通常在名词后

### 3. 忽略不认识的词

- 先抓主干：主语 + 动词 + 宾语
- 再补充细节：形容词、副词
- 最后理解整句意思

### 4. 使用工具

- Google翻译：辅助理解
- Thai2English：泰英词典
- Longdo Dictionary：泰英中词典

## 练习建议

1. **每天读一点**：坚持比强度重要
2. **先读后写**：阅读是写作的基础
3. **大声朗读**：培养语感
4. **做笔记**：记录生词和句型
5. **与母语者交流**：实践是最好的老师
