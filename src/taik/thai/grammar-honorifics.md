# 泰语敬语系统详解

## 概述

泰语敬语系统复杂且重要，反映了泰国社会的等级观念和礼貌文化。敬语主要体现在代词、动词和句末语气词上。

## 人称代词系统

### 第一人称（我）

| 代词 | 转写 | 使用场合 |
|------|------|----------|
| ผม | phom | 男性谦称，正式场合 |
| ดิฉัน | di-chan | 女性谦称，正式场合 |
| ฉัน | chan | 女性，较随意 |
| กู | ku | 极不礼貌，仅限亲密或吵架 |
| เรา | rao | 中性，可表"我"或"我们" |
| หนู | nu | 女性对长辈谦称，或小孩自称 |

### 第二人称（你）

| 代词 | 转写 | 使用场合 |
|------|------|----------|
| คุณ | khun | 通用尊称 |
| ท่าน | than | 非常正式，对上级或神佛 |
| เธอ | thoe | 亲昵称呼，或对女性 |
| แก | kae | 较随意，对同辈或晚辈 |
| มึง | mueng | 极不礼貌 |
| ลุง / ป้า / น้า / อา | lung / pa / na / a | 按年龄称呼长辈 |

### 第三人称（他/她）

| 代词 | 转写 | 使用场合 |
|------|------|----------|
| ท่าน | than | 尊敬 |
| เขา | khao | 通用 |
| แก | kae | 较随意 |
| พ่อ / แม่ | pho / mae | 指代父母 |

## 句末敬语词

| 词汇 | 转写 | 使用者 | 场合 |
|------|------|--------|------|
| ครับ | khrap | 男性 | 正式、礼貌 |
| ค่ะ | kha | 女性 | 正式、礼貌 |
| ครับผม | khrap phom | 男性 | 非常恭敬 |
| ค่ะ/คะ | kha/kha | 女性 | ค่ะ 肯定，คะ 疑问 |
| นะ | na | 通用 | 轻微强调，较随意 |
| เนาะ | no | 通用 | 亲切，寻求同意 |
| จ้ะ / จ้า | ja | 通用 | 亲昵 |

## 王室用语（ราชาศัพท์）

泰语有专门的王室用语，用于提及王室成员：

| 普通用语 | 王室用语 | 中文 |
|----------|----------|------|
| กิน | เสวย | 吃 |
| นอน | บรรทม | 睡 |
| พูด | ตรัส | 说 |
| ตาย | สวรรคต | 去世 |
| บ้าน | พระตำหนัก | 住所 |

## 僧侣用语

| 普通用语 | 僧侣用语 | 中文 |
|----------|----------|------|
| กิน | ฉัน | 吃 |
| นอน | จำวัด | 睡 |
| ไป | ไป | 去（但说 เจริญพร 表尊敬）|
| ตาย | มรณภาพ | 去世 |

## 使用原则

1. **对长辈和上级**：使用 ผม/ดิฉัน + ครับ/ค่ะ + คุณ/ท่าน
2. **对同辈朋友**：可省略敬语词，用 ผม/ฉัน + คุณ
3. **对晚辈**：可用 เธอ/แก，省略敬语词
4. **王室话题**：必须使用 ราชาศัพท์
5. **宗教场合**：对僧侣使用特殊敬语

## 常见错误

- 对长辈使用 กู/มึง（极不礼貌）
- 男性使用 ฉัน（听起来女性化）
- 忘记加 ครับ/ค่ะ（显得不礼貌）
- 对王室不用 ราชาศัพท์（严重违规）
