# 泰语敬语使用指南

## 敬语的重要性

泰语敬语（ภาษาสุภาพ, phasa suphap）是泰国社会交往的基础。使用正确的敬语体现教养和尊重，是融入泰国社会的关键。

## 句末敬语词

### 男性用语

| 词汇 | 转写 | 语气 | 场合 |
|------|------|------|------|
| ครับ | khrap | 礼貌、正式 | 通用礼貌 |
| ครับผม | khrap phom | 非常恭敬 | 对上级、长辈 |
| ครับท่าน | khrap than | 极其恭敬 | 对非常尊贵的人 |
| ฮะ | ha | 随意 | 对亲近的朋友 |

### 女性用语

| 词汇 | 转写 | 语气 | 场合 |
|------|------|------|------|
| ค่ะ | kha | 礼貌、肯定 | 通用礼貌 |
| คะ | kha | 礼貌、疑问 | 问句时使用 |
| ค่ะ/คะ | kha/kha | 柔和 | 可互换使用 |
| นะ | na | 亲昵 | 对亲近的人 |

### 性别中立

| 词汇 | 转写 | 语气 | 场合 |
|------|------|------|------|
| นะ | na | 轻微强调 | 朋友间 |
| เนาะ | no | 亲切 | 寻求同意 |
| จ้ะ / จ้า | ja | 亲昵 | 亲密朋友 |
| ล่ะ | la | 轻微提醒 | 朋友间 |

### 使用场景

1. **新闻报道**：提及王室时必须使用 ราชาศัพท์
2. **正式文件**：王室相关公告
3. **日常对话**：提及王室时使用，体现尊重
4. **历史叙述**：讲述王室历史时

## 敬语使用原则

### 何时使用敬语

1. **对陌生人**：必须使用敬语
2. **对长辈**：必须使用敬语
3. **对上级**：必须使用敬语
4. **正式场合**：必须使用敬语
5. **服务行业**：必须使用敬语

### 何时可省略

1. **亲密朋友**：可省略 ครับ/ค่ะ
2. **家人之间**：可省略，但仍有程度之分
3. **自言自语**：可省略
4. **儿童之间**：可省略

### 敬语程度

| 场合 | 敬语程度 | 示例 |
|------|----------|------|
| 对王室 | 极高 | ราชาศัพท์ + ครับ/ค่ะ |
| 对僧侣 | 高 | 僧侣用语 + ครับ/ค่ะ |
| 对长辈/上级 | 高 | 我/你敬语 + ครับ/ค่ะ |
| 对陌生人 | 中 | คุณ + ครับ/ค่ะ |
| 对朋友 | 低 | 我/你随意 + นะ/เนาะ |
| 对亲密朋友 | 无 | 随意 |

## 常见错误

### 错误示例

| 错误 | 正确 | 说明 |
|------|------|------|
| ผมกินแล้วค่ะ | ผมกินแล้วครับ | 男性用 ค่ะ |
| ฉันกินแล้วครับ | ฉันกินแล้วค่ะ | 女性用 ครับ |
| คุณไปไหนกู | คุณไปไหนครับ | 对陌生人用 กู |
| กินข้าวแล้ว | กินข้าวแล้วครับ/ค่ะ | 忘记敬语词 |

### 文化禁忌

1. **不要对长辈用 กู/มึง**：极其不礼貌
2. **不要对僧侣不敬**：尤其女性要注意距离
3. **不要批评王室**：这是严重的法律问题
4. **不要忘记 ครับ/ค่ะ**：显得没教养

## 练习

### 场景练习

1. **对老师说**：
   - 正确：สวัสดีครับ/ค่ะ อาจารย์
   - 错误：สวัสดี คุณ

2. **对朋友说**：
   - 正确：ไปไหน
   - 错误：ไปไหนครับ（过于正式）

3. **对陌生长辈说**：
   - 正确：สวัสดีครับ/ค่ะ คุณลุง
   - 错误：สวัสดี แก

4. **对僧侣说**：
   - 正确：สวัสดีครับ หลวงพ่อ
   - 错误：สวัสดี พระ
