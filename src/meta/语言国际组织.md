# 语言相关的国际组织

语言相关的国际组织大致可分为几类：联合国体系的官方语言与语言保护机构、语言代码与标准化组织、语言研究与濒危语言保护机构，以及以语言共同体或语言推广为目的的组织。

## 联合国体系

| 组织 | 与语言相关的职能 |
|------|------------------|
| 联合国 (UN) | 六种官方语言：**阿拉伯语、中文、英语、法语、俄语、西班牙语**；各机构出版物均以这六种语言发布 |
| 联合国教科文组织 (UNESCO) | 濒危语言保护与记录；设立 **国际母语日**（2 月 21 日）；发起 **国际原住民语言十年**（2022–2032） |
| 联合国地名专家组 (UNGEGN) | 地名罗马化标准（WGRS，见 [转写资料](ipa.md)） |

- [UNESCO 世界濒危语言图集](https://en.wal.unesco.org/) —— 濒危语言等级划分（脆弱 / 濒危 / 严重濒危 / 极度濒危）和全球分布
- [国际母语日](https://www.unesco.org/en/days/mother-language) —— 每年 2 月 21 日，倡导语言多样性与多语教育

## 语言代码与标准化组织

| 组织 | 标准 | 说明 |
|------|------|------|
| 国际标准化组织 (ISO) | **ISO 639** | 语言代码：639-1（两字母）、639-2（三字母，含集体代码）、639-3（完整三字母代码，覆盖约 7000 种语言） |
| ISO | **ISO 15924** | 文字代码（如 `Latn`、`Hans`、`Hani`、`Kana`、`Hang`） |
| ISO | **ISO 3166** | 国家/地区代码，常用于语言标签后缀 |
| Unicode 联盟 (Unicode Consortium) | **Unicode / UAX** | 字符编码与文字属性，见 [CJK 字体命名后缀](CJK字体命名后缀.md) |
| IETF | **BCP 47** | 语言标签规范（如 `zh-Hans-CN`），用于 HTML、系统 locale 等 |
| ICANN | IDN | 国际化域名与多语种顶级域（IDN ccTLD） |

其中 ISO 639-3 是语言学研究最常用的完整代码表，由 **SIL International** 维护；单个语言若有争议（语言 vs. 方言），往往体现在 639-3 是否单独编码。

## 语言研究与濒危语言保护机构

| 机构 | 说明 |
|------|------|
| [SIL International](https://www.sil.org/)（前身：暑期语言学院） | 传教背景的语言研究机构，维护 [Ethnologue](https://www.ethnologue.com/)（全球语言数据库）与 ISO 639-3 代码 |
| 国际语音学协会 (International Phonetic Association) | 国际音标 (IPA) 的制定与维护机构，官网见 [ipa.md](ipa.md) |
| [濒危语言项目 (ELP)](https://endangeredlanguages.com/) | 由 Google 与 Living Tongues Institute 等合作建立的濒危语言在线平台 |
| [Living Tongues Institute for Endangered Languages](https://livingtongues.org/) | 濒危语言记录、复兴与档案建设 |

## 语言共同体与区域性组织

以某语言（或语言集团）为纽带的国际组织，是观察"语言作为身份认同"的典型样本：

| 组织 | 语言 | 说明 |
|------|------|------|
| 法语国家组织 (OIF) | 法语 | 覆盖 88 个成员/观察员国和地区，是最大的以语言为纽带的国际组织 |
| 葡萄牙语国家共同体 (CPLP) | 葡萄牙语 | 9 个成员国，横跨欧洲、美洲、非洲、亚洲（东帝汶） |
| 英联邦 (Commonwealth) | 英语 | 56 个成员国，英语为工作语言 |
| 突厥国家组织 (Organization of Turkic States) | 突厥语族语言 | 土耳其、阿塞拜疆、哈萨克、吉尔吉斯、乌兹别克等国 |
| 阿拉伯国家联盟 | 阿拉伯语 | 22 个成员国 |
| 北欧理事会 | 斯堪的纳维亚语言 | 北欧五国，强调北欧语言互通 |
| 欧洲联盟 (EU) | 24 种官方语言 | 多语制是欧盟立法与机构运行的基本原则 |
| 国际世界语协会 (UEA) | 世界语 | 全球世界语使用者组织，推广中立国际辅助语 |

此外还有欧洲委员会设立的 **欧洲语言日**（9 月 26 日），以及欧洲语言共同参考框架（CEFR）这一语言能力分级标准。

## 语言文化推广机构

各国通过半官方或政府机构向海外推广本国语言：

| 机构 | 语言 | 国家/地区 |
|------|------|-----------|
| 英国文化协会 (British Council) | 英语 | 英国 |
| 法语联盟 (Alliance française) | 法语 | 法国 |
| 歌德学院 (Goethe-Institut) | 德语 | 德国 |
| 塞万提斯学院 (Instituto Cervantes) | 西班牙语 | 西班牙 |
| 孔子学院 / 中文联盟 | 汉语 | 中国 |
| 但丁协会 (Società Dante Alighieri) | 意大利语 | 意大利 |
| 卡蒙斯学院 (Instituto Camões) | 葡萄牙语 | 葡萄牙 |
| 俄语世界基金会 (Русский мир) | 俄语 | 俄罗斯 |

## 语言规范化机构（标准语制定者）

许多语言有权威的规范机构，相当于"语言的裁判"，常见于有标准语传统的语言：

| 机构 | 语言 | 说明 |
|------|------|------|
| 法兰西学院 (Académie française) | 法语 | 官方语言规范机构 |
| 皇家西班牙语学院 (RAE) 与美洲西语学院协会 (ASALE) | 西班牙语 | 美洲各国学院联合制定规范 |
| 葡萄牙语国际学院 (IILP) | 葡萄牙语 | 葡萄牙语正字法协定（1990）的协调机构 |
| 中国国家语言文字工作委员会 | 汉语 | 普通话、规范汉字、汉语拼音方案的管理机构 |
| 日本文化厅・国语审议会 | 日语 | 常用汉字表等规范的制定者 |
| 朝鲜/韩国国语院 | 韩语 | 韩文规范与外来语标记法的制定者 |
